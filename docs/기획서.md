# 저편의 정원 사이트 재제작 기획

Nov 9, 2026 · @나노나노

## 개요

Unity 게임은 아주 나중으로 미루고, **지금의 사이트를 처음부터 다시 만든다.** 목표는 메인 스토리(다섯 마인)를 끝까지 플레이할 수 있는 구조, 매일 할 거리가 끝나지 않는 콘텐츠, 그리고 기존 플레이어의 캐릭터를 조정해서 이어받는 것이다. 이 문서는 계획 단계이며, 아직 사이트는 만들지 않는다.

**원칙**

- **제1원칙: 오류 없이, 플레이어가 편하게 돌아가야 한다.** 이 기획의 의의이자 가장 중요한 것. 모든 설계와 코드 구성은 이것을 먼저 따른다(데이터 구조 섹션의 「오류 없는 코드 원칙」). 세계는 자동으로 돌아가고, GM은 메인 스토리 스위치만 쥔다.
- 정의 데이터·세계 상태·캐릭터 상태·규칙을 처음부터 나눈다.
- 능력치 성장은 하루 제한, 모험과 생활은 끝없이.
- 전투는 주사위가 아니라 손이 정한다. 운은 효과로만 남긴다.
- 구조는 다섯 장 전부를 담게 짜되, 제작은 1장(그르지엔)을 끝까지 먼저 완성하고 나머지는 같은 틀에 내용만 채운다. 배포는 기술 나무와 적 종류를 전부 확정하고, 1장까지 그 앞의 이야기와 전투를 모두 구현한 완전한 상태로 한다.
- Unity 기획서의 원칙(정의와 저장 분리, 하나의 진짜 상태, 대본 형식 대화, 무기별 기술 나무)은 그대로 가져온다.

## 운영과 시간

### 자동 세계 + GM 스위치

일상, 의뢰, 일반 전투, 성장, 상시 콘텐츠는 모두 사이트가 혼자 처리한다. GM은 **메인 스토리의 장 진행 스위치**만 쥔다. GM이 단계를 올리면 그 단계에 맞는 소식지, 의뢰, NPC 대사, 연출, 레이드가 자동으로 바뀐다. GM이 매일 판정할 일은 없다.

### 세계 시계 + 행동 저장 (C안)

- **세계 달력**은 현실 하루마다 한 달씩 넘어간다. 모두가 같은 달에 있어서 소식지, 계절, 메인 스토리, 레이드가 같은 때에 일어난다.
- 11달이 지나면 이름 없는 다섯 날에 한 해를 정리하고 한 살을 먹는다(현실 12일 = 한 해).
- **하루 제한은 성장 행동에만**: 배우기, 일하기, 사람 만나기, 쉬기처럼 능력치·숙련도·인맥이 오르는 행동. 한 달에 주 행동 4 + 작은 행동 2.
- **남은 행동 저장**: 그달에 다 못 쓴 행동은 잃지 않고 쌓인다. 주 행동은 최대 4개까지 저장하고, 그 이상 밀리면 자동으로 일하기·쉬기로 처리한다.
- 기존 규칙 중 유지하는 것: 경력은 한 달 최대 2, 같은 기술 배우기는 세 번째부터 −10, 네 번째 −20처럼 감점이 쌓임, 일터 밖에서는 일하기 불가.

## 캐릭터

### 성장기 (0\~15세)

옛 사이트의 성장기(나이마다 사건, 판정, 기억 표시)를 이어받아 넓힌다. 모든 굴림은 생성 씨앗에서 나와서 새로고침해도 같다. 숫자와 확률은 임시.

**흐름**

1. **태어남(0세)**: 지역·장소와 함께 **집안**을 굴린다. 출생 사건 하나.
2. **다섯 시기**마다 무작위 사건 하나 + 교육 선택 하나: 유년(1\~4세), 아이(5\~9세), 소년기(10\~12세), 청소년(13\~14세), 열다섯(15세).
3. 사건은 공통 표 + 지역 표 + 집안 표에서 뽑고, 판정이 있는 사건은 능력치·재능으로 성공 기준이 바뀐다.
4. 결과로 능력치 ±, 숙련도 +, **기억 표시**, 인물, 숨은 재능의 단서가 쌓인다.
5. **태어난 해의 역사**와 이어진다. 15년 전부터 지금까지의 실제 사건(491년 정복전쟁, 498년 뮈르가스트 현현회 은신처 급습, 511\~512년 북부 공성 등)이 그 시기·지역의 아이에게 사건으로 나온다.

**교육 선택** (시기와 집안에 따라 보이는 것이 다름)

- 아이: 가업 돕기 / 성당 학교 / 동네 아이들과 놀기 / 숲과 들에서 놀기
- 소년기: 도제로 들어가기 / 학당 준비 / 시동으로 들어가기(기사 가문) / 배 타기(뱃사람) / 거리에서 살기(빈민)
- 청소년: **시작 직업 고르기**(도제·견습이면 그 직업 1단계로 시작) / 혼자 떠돌기(직업 없이 숙련도를 고르게)

**열다섯의 결과**

- 시작 직업(또는 날품), 숙련도 몇 개(각 0\~20), 능력치 보정, 기억 표시 2\~4개, 인물 2\~4명.
- 기억 표시는 재능이 아니라 기록이지만, 이후 장면에서 선택지를 열거나 바꾼다(예: 「개를 무서워함」이면 사냥개 동료 장면이 다르게, 「추방을 목격함」이면 이단 관련 선택지가 하나 더).
- 중앙대륙 밖 출신은 순례자·이단 심문관 사건이 나오지 않는다. 적국(브라켄, 라이젠부르크, 아스텔라)에서도 태어날 수 있고, 출신(제국·팔군도·적국)에 따라 검문·세금·직업 길·NPC 반응이 달라지고, 팔군도·적국 출신은 제국 거주민이 될 수 있다(명세서 「출신」).

#### 지역 성장기 이야기

성장기는 지역마다 **하나의 이야기 줄기**로 흐른다. 다섯 시기마다 짧은 비주얼노벨 장면 하나(대사 10\~20줄)와 선택 하나. 위의 사건 표는 줄기 사이에 가끔 끼어드는 양념이다.

- **소꿉친구**가 지역마다 한 명. 처음부터 끝까지 같이 자라고, 열다섯이 되면 인물 목록에 남아 나중에 동료나 의뢰로 다시 만난다(이름과 성별은 생성 씨앗으로 정해짐).
- 같은 이야기라도 **집안에 따라 보는 자리가 다르다.**
- 앞의 선택이 뒤 장면을 바꾸고, 기억 표시·능력치·숙련도·시작 직업으로 남는다.
- 태어난 해에 맞춰 역사 사건이 끼어든다. 514년에 열다섯이면 499년생. 나중에 태어나는 캐릭터는 그만큼 뒤의 역사를 겪는다.
- 마인과 유일물의 떡밥이 어린 눈으로 살짝 보인다(그 장이 열리기 전엔 정체는 드러나지 않음).

### 능력치와 기록

- 능력치 다섯(건강·정신력·재력·인맥·평판, 0\~100, 보통 50)은 그대로. 건강 0이면 삶이 끝나고 도서관으로 돌아간다.
- 재력은 지갑 돈과 따로 움직이는 **신용**이다(경제 섹션).
- 「난산을 겪음」 같은 **기억 표시**와 **평판 꼬리표**는 재능이 아니라 기록으로 따로 둔다.

### 유물 적성 (후천)

현현회 경전의 "손을 대는 자는 시험을 받고, 버틴 자가 선택받은 자가 된다"를 그대로 규칙으로 만든다. 두 축은 「마공학 유물 감정록」을 따른다: **신체 적성**(몸이 감당하는가), **마력 친화**(힘이 스며드는가).

1. **접촉**: 유적이나 사건에서 유물을 처음 만진다.
2. **시험**: 건강과 정신력으로 판정. 실패하면 부상이나 폭주(건강·정신력 손실). 성공하면 두 축 중 하나를 얻고, 자신에게 맞는 유물 형태(검·도끼·망치·곡괭이 등 50종 이상)가 하나 드러난다.
3. **적응**: 유물을 쓸수록 적응도 0\~100이 오르고, 단계마다 효과가 커진다.
4. **완전한 적성**: 두 축을 모두 얻고 적응도를 끝까지 올렸을 때만. 가장 강하지만 대가가 따른다.

### 동화도 (완전한 적성의 대가)

먹빛신앙(자신을 완전히 잃고 유물의 의무만 남은 존재)을 향해 가지만 끝까지 가지는 않는 정도로 잡는다. 완전한 적성을 얻는 순간부터 생기고, 유물 기술을 쓸 때마다 오른다.

| 동화도 | 일어나는 일 |
| --- | --- |
| 0\~30 | 변화 없음. 가끔 유물이 먼저 반응하는 묘사 |
| 30\~60 | 정신력 최대치 −10. 친밀도가 한 달에 1씩 저절로 줄어듦 |
| 60\~90 | 정신력 최대치 −20. 일부 사람 사이 선택지(구혼, 위로하기 등)가 닫힘. NPC가 낯설어함 |
| 90\~100 | 경계 사건 |

- **버티는 법**: 유물을 안 쓴 달에는 조금씩 내려간다. 친밀도 70 이상인 사람이 있으면 덜 오른다. 사람과의 관계가 사람으로 붙잡아 두는 닻이다.
- **경계 사건**: 내려놓기(완전한 적성을 잃고 한 단계 아래로, 동화도 초기화) 또는 넘어가기(고유 칭호와 아주 강한 효과, 대신 정신력 최대치 감소와 닫힌 선택지가 영구히). 어느 쪽이든 캐릭터를 빼앗지 않는다.

## 전투

전투는 새로 만든다. 기존 합 전투는 재미는 있었지만 세 가지가 문제였다: **강한 기술 하나만 반복**(매 턴 아무거나 다시 쓸 수 있어서), **운에 맡기는 느낌**(위력이 거의 주사위 합), **싸운다는 느낌 부족**(적이 뭘 할지 몰라 판단이 없음). 턴의 뼈대와 "맞붙어 이기면 상대 기술이 깨진다"는 합의 정체성만 남기고, 실행은 손으로 한다.

### 한 턴의 흐름

1. **적의 의도가 뜬다**: 적마다 이번 턴 쓸 기술, 위력(하나의 값), 노리는 대상이 미리 보인다.
2. **내 차례: 고른다**: 기본 공격·기본기 셋·보조 칸·공용 행동 중 하나. 쿨다운 중인 기술은 못 고른다.
3. **내 차례: 손으로 친다**: 기술마다 타수가 있고(베기 1타, 연속 베기 3타), 타마다 타이밍 바를 누른다. 빗나감 / 보통 / 좋음 / 완벽으로 위력이 정해진다. 숙련도가 높을수록 판정 칸이 넓고 기본 위력이 높다.
4. **합**: 적의 의도 공격에 맞붙이면, 내가 친 위력 합계와 적 위력을 비교해 이긴 쪽이 상대 기술을 깬다.
5. **적 차례: 막는다**: 막기(넓은 칸, 피해 감소) / 받아치기(아주 좁은 칸, 성공하면 피해 없음 + 반격 + 적 흐트러짐 크게) / 피하기(큰 공격에만, 짧은 탄막 미니게임).

### 운은 효과로만

주사위 굴림은 없애고, 무작위는 판정에 끼어드는 효과로만 남긴다.

| 효과 | 판정에 하는 일 |
| --- | --- |
| 공포 | 판정 칸이 흔들림 |
| 집중 | 판정 칸이 넓어짐 |
| 위압 | 상대의 판정 칸이 좁아짐 |
| 침식 | 완벽 칸이 사라짐 |
| 그 밖 | 출혈 발동 확률처럼 일부 효과에만 무작위 |

기존 효과(출혈·화상·독·공포·침식·속박·취약 / 사기·자신감·위압·수호·신속·집중·결의·낭독)와 GM 커스텀 효과(아드레날린·관성·잔상)는 새 판정 방식에 맞게 수치를 다시 잡아 옮긴다.

### 쿨다운, 연계, 흐트러짐, 상성

- **쿨다운**: 강한 기술일수록 쓴 뒤 쉬는 턴이 길다. 그 사이를 약한 기술로 메워야 한다. 기본 공격과 공용 행동은 쿨다운 없음.
- **연계**: 기술마다 여는 / 잇는 / 끝내는 표시. 순서대로 이으면 위력과 효과가 붙는다(검술: 베기 → 연속 베기 → 검풍).
- **흐트러짐**: 적마다 자세 게이지. 합 승리나 상성 좋은 공격으로 깎이고, 0이 되면 한 턴 무력화 + 받는 피해 크게 증가. 체력보다 자세를 무너뜨리는 순간이 전투의 절정.
- **상성 표시**: 적의 자상·관통·파열 저항을 화면에 보여준다.
- **기력**: 기술마다 기력을 쓰고, 막기·피하기로 조금 회복(기존 규칙 유지).

### 광역기

| 범위 | 대상 | 위력 |
| --- | --- | --- |
| 단일 | 한 명 | 100% |
| 휩쓸기 | 고른 적과 양옆 | 고른 적 100%, 나머지 60% |
| 전체 | 적 모두 (비기·극한기 급만) | 고른 적 100%, 나머지 50% |

- 합은 고른 적의 의도 공격과만. 나머지 적에겐 일방적으로 들어간다. 위험한 큰 공격을 깨는 데는 단일기가 여전히 낫다.
- 흐트러짐은 고른 적만 온전히, 나머지는 절반.
- 쿨다운이 길고 기력을 많이 쓴다. 대부분 연계의 끝내는 기술 자리.
- 타이밍 결과는 한 번이 모두에게 적용된다.
- 적도 광역기를 쓴다(그르지엔 「눈 감은 늪」). 파티원은 각자 자기 막기·피하기를 입력한다.

### 진형

아군과 적 모두 **앞줄 3칸 + 뒷줄 3칸**.

- 근접 기술은 앞줄만 칠 수 있다. 앞줄이 비면 뒷줄에 닿는다.
- 원거리 기술은 어느 칸이든 치지만 위력이 조금 낮다.
- 뒷줄은 근접 공격을 안 받는 대신 근접 기술을 못 쓴다.
- 자리 옮기기: 자기 차례에 기력 조금 쓰고 기술 대신. 밀치기(둔기·방패), 끌어당기기(해적 「갈고리 걸기」), 앞줄이 쓰러지면 뒷줄이 앞으로.

| 무기 | 범위 모양 |
| --- | --- |
| 검 | 휩쓸기: 앞줄 가로 세 칸 |
| 창 | 꿰뚫기: 같은 칸 앞줄 + 뒷줄 |
| 둔기·도끼 | 충격: 맞은 칸 + 뒤로 밀어냄 |
| 활·석궁 | 아무 칸, 뒷줄 노리기 |
| 단검 | 파고들기: 한 턴 동안 뒷줄까지 근접 |
| 방패 | 지키기: 옆이나 뒤 동료 대신 맞음 |

| 이야기 동료 | 사건·의뢰로 합류 (군터 모어 등) | 고유 서사와 대사, 친밀도로 기술·이야기가 열림 |
| 신분 동료 | 직업 단계가 오르면 | 기사단장의 종자, 카포의 할콘 부하, 극단장의 단원 |
| 내 사람 | 인물 목록에서 친밀도 높은 사람을 부름 | 플레이어가 만든 인물(토마소 칼다레, 사르리따 쿠오 등)이 함께 싸움 |
| 짐승 | 조련·사냥 기술로 길들임 | 사냥개, 매, 군마 |
| 일꾼 (비전투) | 고용 | 짐꾼·길잡이. 던전 보상 늘림, 길 잃을 확률 줄임 |

- 아군 여섯 칸을 플레이어와 동료가 나눠 쓴다. 혼자면 동료 최대 2명, 파티면 플레이어 한 명당 1명.
- 준비 단계에서 파티원은 앞줄·뒷줄 희망만 표시하고, **파티장이 동료까지 최종 배치**한다. 전투 중 자기 자리 옮기기는 자유.
- 동료는 자동으로 싸우고, 전투 전에 성향 하나(공격 / 지키기 / 지원)를 정한다.

**동료는 각자 자기 장비를 들고 다닌다.** 플레이어가 장비를 바꿔주지 않는다. 동료마다 기본 기술 셋, 친밀도·신뢰 단계가 오를 때마다 하나씩 더 열린다. 여러 명을 거느릴 수 있다.

**미리 짜둔 내 사람**

- **토마소 칼다레** (볼카누스의 삼촌이자 스승): 앞줄의 거구 대검사, 그라비다드 칼다레 **정통**. 엘 파로(볼카누스를 먼저 지키는 수비 자세), 카이다 데 히에로, 센티넬라, 친밀도가 오르면 임팩토 아솔루토(전투에 한 번). 볼카누스가 쓰러질 위기면 대신 맞는다(지키지 못한 부채감). 카르텔 사건이 있는 날엔 못 따라온다. 함께 싸운 기록이 쌓이면 「토마소를 넘어서는 사건」이 열리고, 볼카누스가 「꺾이지 않는 마음」을 얻을 수 있다. 친밀도는 이전 때 65 → **70으로 조정**(삼촌이자 스승이라 처음부터 동료).
- **사르리따 쿠오** (전바섬의 형 같은 사람, 친밀도 80): 16년 전 타지 않는 왕에게 부족의 땅이 불탄 날, 정찰 중이던 전바섬의 아버지가 제국으로 데려온 테산가 출신 척후병. 전바섬에게 투척을 가르쳤다. 뒷줄 척후로 투척 연발, 정찰(첫 턴에 숨은 적과 가려진 의도를 드러냄), 덫 놓기, 친밀도가 오르면 「초원의 눈」(뒷줄 저격). 테산가에 데려가면 특별 대사와 사건. 테산가 장(아젠타르)의 핵심 인물이라 1장에선 떡밥만.

**이야기 동료 퀘스트**

이야기 동료마다 짧은 이야기가 친밀도 단계(20 / 40 / 70 / 90)를 따라 흐른다. 단계마다 장면 하나와 기술 하나가 열리고, 90에서 **고유 기술**(그 동료만 쓰는 궁극기급)과 결말 선택이 나온다. 일부 단계는 장 진행이나 지역 조건이 함께 붙는다.

| 동료 | 이야기 | 20 | 40 | 70 | 90 (고유 기술) |
| --- | --- | --- | --- | --- | --- |
| 군터 모어 | 첫 휴가 | 휴가 중 술 한 잔, 북쪽 마을의 집 이야기 | 그가 챙기던 신병이 탈영병 속에 있었다는 것. 처벌받게 둘지, 감쌀지 | 휴가가 끝나고 전선 복귀 명령. 보내줄지, 붙잡을지 | 공성의 끝을 함께 맞음. 「마지막 창벽」. 결말: 전선으로 돌아가거나, 제대해 곁에 남음 |

### 부상

플레이어도 동료도 죽지 않고 다친다(플레이어 사망은 건강 0일 때만).

| 쓰러진 정도 | 회복 | 치료하면 |
| --- | --- | --- |
| 경상 (체력 0, 흐트러짐 없음) | 다음 날 초기화 때 | 약초·음식으로 바로 |
| 중상 (흐트러진 상태에서 쓰러짐, 또는 보스 광역기) | 현실 사흘 | 의원(돈)이나 의술 기술로 하루로 |

- 같은 동료가 짧은 기간에 중상을 두 번 입으면 **흉터**: 능력치가 살짝 떨어지고 고유 대사나 칭호가 붙는다.
- 용병은 중상을 입으면 위로금을 요구하거나, 신뢰가 낮으면 떠난다. 이야기 동료와 내 사람은 떠나지 않는다.
- 플레이어 건강은 기존 규칙(임시로 깎이고, 기간 안에 치료 안 하면 굳음)을 유지한다.

### 자동 전투

이미 이긴 적이 있는 쉬운 전투는 타이밍 입력 없이 자동으로 넘길 수 있다. 보상은 조금 줄어든다. 상시 콘텐츠를 여러 번 돌 때 손이 피곤하지 않게.

### 적의 행동

**의도 보여주기**: 매 턴 시작에 적마다 기술 이름, 위력(하나의 값), 노리는 대상, 범위 모양이 뜬다. 기본은 다 보이고, 일부 적만 가린다.

- 교활한 적(도적, 해적 일부): 대상만 보이고 기술은 "???"
- 안개 속 적(늪 계열): 대상이 "???"
- **큰 기술 예고**: 강한 기술은 한두 턴 전에 "힘을 모은다"로 알린다. 그 사이 흐트러뜨리면 끊을 수 있다.

**원형별 성향** (적은 지금 코드처럼 "원형 + 지역표 + 등급(1\~5)"으로 만든다)

| 원형 | 누구를 노리나 | 특징 |
| --- | --- | --- |
| 짐승 | 체력이 가장 낮은 쪽 | 무리 연계(하나가 물면 옆 놈이 추가타). 흐트러지면 도망 |
| 도적 | 뒷줄 | 파고들기, 돈 훔치기. 체력이 낮으면 항복(칼등으로 생포하기 좋음) |
| 병사 | 앞줄 | 진형 유지, 방패병이 지키기, 석궁병은 뒷줄. 자상에 강함 |
| 광신도 | 가장 가까운 쪽 | 체력이 낮을수록 강해짐, 공포가 안 먹힘 |
| 늪 | 무작위 | 침식·독, 의도 대상 가림 |
| 얼음 | 기술을 가장 많이 쓴 쪽 | 속박, 쿨다운 늘리기 |
| 벌레 | 무작위 | 약하지만 턴마다 수가 늘어남. 광역기가 빛나는 상대 |
| 잠식된 자 | 앞줄 | 그르지엔의 안개에 병들어 정신을 잃은 사람·짐승. 공포가 안 먹히고, 닿으면 쇠약이 쌓임. 뮈르가스트에서만 |
| 해적 | 뒷줄 | 끌어당기기, 자리 바꾸기, 불리하면 도망 |
| 카르텔 | 가장 강한 쪽 | 일대일을 노림, 위압. 우두머리가 있으면 다 같이 강해짐 |

**행동 고르기**: 적 정의 데이터에 "행동 목록 + 조건(체력 50% 이하 등) + 무게"를 적는다. 일반 적은 무게에 따라 고르고, **보스는 정해진 순서로** 돌아 패턴을 읽는 맛이 나게 한다.

**보스 짜는 틀**: 체력 구간마다 바뀌는 **단계**(보통 2\~3), 그 보스만의 **고유 장치** 하나, 특정 때만 크게 흐트러지는 **약점 순간**.

그르지엔 예시:

1. 1단계: 안개로 의도 대상을 가림. 안개 팔(발톱 자국) 공격.
2. 2단계: 3턴마다 「눈 감은 늪」 광역기 예고. 썩은 물방울은 피하기 미니게임(나뭇가지 발판).
3. 3단계: 죽기 직전의 각성. 안개가 처음 걷히고 목의 포엽이 등 뒤로 타이탄아룸처럼 만개하며, 청록색 눈이 핏빛으로 바뀐다. 그 눈을 정확히 치면 크게 흐트러짐(그르지엔은 평생 각성하지 못하다 죽기 직전에만 각성한다, 설정집 기준). 파티가 전멸 직전이면 라디아타 개입 연출.
4. 먹빛신앙의 낭독이 정신력 버프로 침식을 버티게 해준다.

### 적 도감

처음 만난 적은 정보가 가려져 있고, 싸울수록 도감이 채워지며 드러난다. 사냥꾼 직업이나 학식·예민한 감각 재능이 있으면 한 단계씩 빨리 열린다.

| 단계 | 조건 | 드러나는 것 |
| --- | --- | --- |
| 처음 봄 | 만남 | 이름과 모습. 의도엔 기술 이름만, 위력·저항은 "???" |
| 1단계 | 1번 이김 | 위력, 피해 저항 |
| 2단계 | 5번 이김 | 행동 성향, 약점, 드롭 목록 |
| 3단계 | 15번 이김 | 서식지와 도서관 책 같은 설명문. 완성 보상 |

### 1장 범위의 적

원형 10개**(옛 언데드는 「잠식된 자」로 바꿈)에 유물 기계 원형을 더한다. 설정집 원칙대로 8군도에는 마수·초자연 요소를 두지 않고, 초자연은 마인과 첫 문명의 유물에서만 온**다. 유물 기계는 흐트러짐이 안 되는 대신 과열·고장 같은 고유 규칙이 있고 파열에 약하다. 이동이 자유라 1장 동안에도 세계 전체에 적이 있다. 2\~5장 마인과 얽힌 적은 그 장이 열릴 때까지 숨기고, 그 지역들의 던전은 각 장에서 연다. 적국은 군적이 없으면 전선 사흘 거리 안에 들어갈 수 없다.

| 지역 | 일반 적 | 정예 | 던전 보스 |
| --- | --- | --- | --- |
| 황도 (지하수로) | 시궁쥐 떼, 소매치기 패, 지하 밀수꾼, 수로의 광신도 | 밀수 두목 | 수로의 늙은 악어 |
| 북쪽 팔 (국경 숲길) | 늑대, 탈영병(방패 앞줄 + 석궁 뒷줄), 산적, 라이젠부르크 척후병 | 탈영병 두목 | 굶주린 늑대왕 |
| 동쪽 팔 (해안) | 밀수꾼, 해적 척후, 바위게 | 밀수선 선장 |  |

## 기술

Unity 기획서의 "무기마다 나무 한 그루, 기본기 셋, 둘 중 하나 갈래" 구조를 턴제로 옮긴다.

### 전투 칸

| 칸 | 내용 | 쿨다운 |
| --- | --- | --- |
| 기본 공격 | 무기마다 하나. 언제나 쓸 수 있는 여는 기술 | 없음 |
| 기본기 셋 | 무기 나무의 기본기 넷 중 셋. 유일 기술은 이 중 한 칸을 차지 | 있음 |
| 궁극기 | 끝까지 키운 루트에서 열린 궁극기 중 하나 | 김 |
| 보조 칸 | 보조 나무에서 하나 | 김 |
| 공용 행동 | 막기·받아치기·피하기·자리 옮기기 | 없음 |

### 나무 규칙

나무는 아래에서 위로 **뿌리 → 줄기 → 가지 → 꽃(끝갈래) → 궁극기**로 자란다.

- **줄기(입문)**: 점수 없이 숙련도로 열린다. 기본 공격과 기본기가 단계에 따라 차례로 열리고, 숙련도 50에 기본 공격 변형 택1.
- **뿌리(능력치 갈래)**: 그 무기를 들 때만 적용되는 작은 강화. 네 갈래 × 4칸, 칸당 3\~5%, 끝칸에 작은 효과.
- **가지(기본기)**: 나무마다 **기본기 4개**, 전투엔 셋을 들고 간다.
- 기본기 하나의 루트는 이렇게 생겼다. 끝까지 가면 9칸.

```
기본기
 ○ 보완  ○ 보완
갈림길 1 (A / B)
 ○ 보완  ○ 보완
갈림길 2 (끝갈래 넷: A-1, A-2, B-1, B-2)
 ○ 보완
★ 궁극기 (끝갈래마다 하나)
```

- **분기점**(기본기, 갈림길, 끝갈래, 궁극기)은 이름과 개성이 있는 칸. **보완 칸**(○)은 그 루트 기술에만 붙는 작은 강화로, 기준표에서 고른다(위력 +5%, 판정 칸, 기력 −1, 조건부 쿨다운 −1, 효과 +1 등). 일부 보완 칸은 둘 중 하나를 고르는 작은 선택.
- 갈림길은 둘 중 하나. 한쪽을 찍으면 다른 쪽은 잠긴다.
- **궁극기는 끝갈래마다 하나**라서 기본기 하나에 넷, 나무 하나에 16개. 루트를 끝까지 찍으면 열리고, 전투엔 하나만 든다.
- 기본기 하나 = 21칸, 나무 하나 = 80칸 남짓 + 줄기·뿌리·숨은 갈래. 줄이지 않는다.
- 갈래가 바꾸는 것: 효과, 수치, 범위 모양, **연계 역할**(여는·잇는·끝내는), **피해 타입**, 쿨다운. 어떤 기본기 셋을 골라도 연계를 갖출 길이 있게 짠다.
- **초기화**: 마을에서 돈을 내고 전부 되돌린다.

### 기술 기준표

기술마다 숫자를 직접 적지 않고, **단계 · 위력 성격 · 타수 · 범위 · 효과**만 적으면 숫자가 아래 표에서 계산된다. 나중에 직접 쳐보고 "전체가 세다" 싶으면 기준값만 고친다. 가문 갈래, 궁극기, 역이용 갈래, 유일 기술처럼 튀어야 하는 기술은 **개성 보정**(예: "위력 +20%")으로 기준을 일부러 깰 수 있다. 빌드의 개성은 숫자가 아니라 갈래가 바꾸는 규칙, 효과 조합, 조건부 기술, 고유 자원, 여러 나무·재능·장비의 조합에서 나온다. 모든 숫자는 임시.

| 단계 | 기준 위력 | 쿨다운 | 기력 |
| --- | --- | --- | --- |
| 기본 공격 | 6 | 0 | 0 |
| 1단계 | 8 | 1턴 | 1 |
| 2단계 | 11 | 2턴 | 2 |
| 3단계 | 15 | 3턴 | 3 |
| 궁극기 | 24 | 5턴 | 5 |

| 항목 | 규칙 |
| --- | --- |
| 위력 성격 | 약함 ×0.75 / 보통 ×1.0 / 강함 ×1.3 (강함은 쿨다운 +1) |
| 타수 | 총 위력을 타수로 나눔. 2타는 총 ×1.1, 3타는 ×1.2 (많이 누를수록 이득이지만 빗나갈 위험도 큼) |
| 범위 | 단일 ×1.0 / 휩쓸기 ×0.9, 쿨다운 +1 / 전체 ×0.8, 쿨다운 +2 |
| 효과 예산 | 가벼운 효과(출혈 2, 사기 1 등) 하나당 위력 −10%, 무거운 효과(속박, 흐트러짐 크게) −20% |
| 판정 배율 (타마다) | 빗나감 0 / 보통 ×0.7 / 좋음 ×1.0 / 완벽 ×1.3 |
| 기력 | 최대 10, 턴마다 +2, 막기·피하기 성공 시 +1 |

예: 검풍(3단계 · 보통 · 1타 · 휩쓸기 · 효과 없음) → 위력 15 × 0.9 ≈ 13.5, 쿨다운 3 + 1 = 4턴, 기력 3.

### 가문 갈래

- 두 번째 갈림길에 숨은 세 번째 선택지로 생기는 갈래(그 끝갈래의 궁극기도 따로 있다). 모든 나무에 있을 필요는 없다. 힘은 다른 끝갈래와 같은 수준이고, 이름·이펙트 색·대사가 그 가문의 것이다.
- 잠겨 있을 때는 **덮개 씌운 가지**로만 보인다. 이름·효과·꽃 모양은 가려지고 "???"와 열쇠 표시만.
- 여는 조건: **그 가문 출신** / **전수**(가문 사람과 친밀도를 쌓고 전수 의뢰를 마침) / **조직 가입**(카르텔·극단 같은 조직 갈래).
- 전수는 플레이어도 할 수 있다. 볼카누스가 칼다레 가주가 되면 다른 플레이어에게 그라비다드 칼다레를 가르칠 수 있다.

**라인펠트 기사 가문 갈래: 일각 일점 황홀경(恍惚境) 찌르기 (세검 나무)**

전바섬(진백둥이)의 가문. 상징은 일각고래. 진백둥이 님과 떠올린 "모든 초식이 결국 한 점으로 귀결되어 한 점을 꿰뚫는 검술"을 판정 바 자체로 보여준다.

- **점(點)**: 이 갈래를 찍으면 세검 기술로 같은 적을 연달아 칠 때마다 그 적에게 점이 쌓인다. 다른 적을 치면 흩어진다.
- 점이 쌓일수록 그 적을 칠 때 **판정 칸이 점점 좁아져**, 결국 한 점이 된다.
- **마무리 초식**: 점이 일정 이상이면 쓸 수 있는 찌르기. 판정 칸은 바늘 끝만 한 한 점. 맞히면 쌓인 점만큼 방어·저항을 무시하는 관통 피해로 뒷줄까지 꿰뚫고(일각고래의 엄니), 놓치면 점이 모두 사라진다.
- 세검 나무 마무리 기본기의 숨은 세 번째 선택지로 두고, 「점」 쌓기는 세검 전체에 적용. 전바섬은 가문 출신이라 처음부터 열림. 「실버 스러스트」, 「카운터 리포스트」가 이 갈래로 이어진다.
- 이름: 「일각 일점 황홀경(恍惚境) 찌르기」. 진백둥이 님이 지음.

**라인펠트 갈래 강화**: 칼다레(나무 한 그루)나 잔향(조직 나무)에 비해 갈래 하나뿐이라 약해 보이지 않도록, 이 갈래는 "단일 기술"로서 확실한 이점을 준다.

- **모든 찌르기가 한 점으로**: 「점」은 세검뿐 아니라 **모든 나무의 관통 기술**(검술 찌르기, 창, 단검, 궁술, 석궁, 투척)로도 쌓인다. 같은 적이면 무기를 바꿔도 점이 흩어지지 않는다. 여러 무기를 고루 익힌 전바섬의 빌드가 전부 이 한 점으로 모인다.
- **판정 칸이 좁아지는 대신** 점마다 완벽 배율이 +0.1씩 오른다.
- **마무리 초식은 개성 보정으로 궁극기급**: 위력 기준 24에 점 하나당 +15%, 방어·저항·지키기·수호 무시, 뒷줄까지 관통.
- **마무리 초식 자체가 이 갈래의 궁극기 ★일각 일점 황홀경 찌르기다. 갈래 이름과 궁극기 이름이 같다**.

### 역이용 갈래

나무마다 갈림길 하나에 숨은 세 번째 선택지로, 원래 쓰임을 거꾸로 쓰는 **뒤틀린 쪽**이 있다. 원래 갈래보다 기묘하거나 더 세지만 대가가 있고, **대가는 전투 안에서만** 끝난다. 처음엔 "???"로 가려두고 그 기술을 일정 이상 키우면 드러난다.

| 나무 | 역이용 갈래 | 하는 일 | 대가 |
| --- | --- | --- | --- |

### 진화는 재능으로

기존 진화 시스템(백병술, 웨폰 마스터, 검무 등)은 **얻은 재능**으로 흡수한다. 나무는 "무엇을 쓰나", 재능은 "어떤 사람이 되었나".

| 진화 | 재능 효과 | 추가 보상 |
| --- | --- | --- |
| 1차 진화 (백병술, 사격술, 기수, 음유 등) | 해당 계열에 작은 효과 (예: 백병술 = 모든 근접 판정 칸 조금 넓어짐) | 관련 나무 하나에 점수 +1 |
| 조합 진화 (검무, 기마 궁술, 기창술, 그림자 칼 등) | 두 계열을 잇는 효과 | 두 나무를 잇는 **교차 갈래**가 열림 (검무 = 검술 나무에 춤 갈래) |
| 최종 진화 (웨폰 마스터, 명장, 대학자) | 큰 효과 | 점수 +2 + 교차 갈래 |

### 검술 나무 (확정 초안)

한손 장검. 가장 기본이 되는 **균형형** 나무로, 넓게 베기·받아치기·연계·진형 다루기를 고루 쓴다. 피해는 자상이 기본이고, 관통은 돌진 베기의 찌르기 루트와 밀어붙이기 택1에서만(병사처럼 자상에 강한 적을 뚫을 길). 파열은 둔기 몫으로 남긴다. ○ 보완 칸, ★ 궁극기.

**줄기: 검술 입문**

| 숙련도 | 열리는 것 |
| --- | --- |
| 1 | 기본 공격 「베기」(1타 · 단일 · 여는 · 자상), 기본기 ① 연속 베기, ④ 돌진 베기 |
| 10 | 기본기 ③ 되받아치기 |
| 30 | 기본기 ② 검풍 |
| 50 | 베기 변형 택1: 가벼운 베기(2타, 연계 시작 보너스) / 무거운 베기(1타, 흐트러짐 +) |

| --- | --- | --- |

#### ① 연속 베기

1단계 · 약함 · 3타 · 단일 · 잇는 · 자상. 앞 두 타에 출혈 1씩(아무 갈래 없이도 한 번에 출혈 2).

- ○ 판정 칸 조금 넓게 · ○ 출혈 지속 +1턴
- **A. 쌓기**: 세 타 모두 출혈 1, 완벽이면 2
  - ○ 위력 +5% · ○ 택1: 출혈 최대치 +2 / 기력 −1
  - **A-1 흐름**: 연계 중이면 출혈 2배 → ○ 연계 보너스 +10% → ★ **핏빛 실타래**: 6타. 이번 전투에서 연계를 이은 횟수만큼 타마다 출혈이 늘어남
  - **A-2 홀로**: 연계 없이 쓰면 4타 → ○ 혼자 쓸 때 쿨다운 −1 → ★ **천번베기**: 8타, 판정 바가 빨라짐. 마지막 세 타는 완벽이면 출혈 2배
- **B. 터뜨리기** (끝내는 기술로 바뀜): 마지막 타에 앞 두 타의 출혈과 이미 있던 출혈을 전부 피해로. 다른 출혈원(단검, 동료)과 엮으면 크게 터짐
  - ○ 터뜨린 출혈 하나당 피해 +5% · ○ 택1: 터뜨린 뒤 출혈 절반 남김 / 터뜨린 만큼 흐트러짐
  - **B-1 확실**: 판정 칸이 넓어짐 → ○ 마지막 타 판정 칸 더 넓게 → ★ **피의 결산**: 전체. 모든 적의 출혈을 한꺼번에 터뜨림
  - **B-2 도박**: 완벽이면 2배, 빗나가면 출혈 사라짐 → ○ 완벽 칸 조금 넓게 → ★ **단 한 번의 매듭**: 1타, 바늘만 한 칸. 완벽이면 출혈 ×3 피해와 흐트러짐 즉시 0. 빗나가면 내가 출혈 3

#### ② 검풍

3단계 · 보통 · 1타 · 휩쓸기 · 끝내는 · 자상. 위력 약 13.5, 쿨다운 4, 기력 3.

- ○ 위력 +5% · ○ 기력 −1
- **A. 넓게**: 나머지 대상도 80%
  - ○ 나머지 대상에게도 흐트러짐 온전히 · ○ 택1: 휩쓸기가 뒷줄 한 칸까지 / 쿨다운 −1
  - **A-1 끈질김**: 전투가 길수록 위력 증가 → ○ 증가 최대치 + → ★ **멎지 않는 바람**: 3턴 동안 매 턴 시작에 앞줄을 약하게 휩쓸고, 마지막 턴에 큰 검풍
  - **A-2 마무리**: 하나라도 쓰러뜨리면 쿨다운 절반 → ○ 쓰러뜨리면 기력 +1 → ★ **풀베기**: 앞줄 전체. 쓰러뜨릴 때마다 한 번 더 휩씀(최대 3번)
- **B. 깊게**: 단일기로, 위력 ×1.4, 흐트러짐 크게
  - ○ 흐트러짐 +10% · ○ 택1: 판정 칸 조금 넓게 / 위력 +5%
  - **B-1 빠르게**: 쿨다운 −2 → ○ 같은 적을 연속으로 치면 기력 −1 → ★ **칼바람 한 줄기**: 쿨다운이 짧은 궁극기. 약하지만 전투에 여러 번
  - **B-2 무겁게**: 흐트러진 적에게 2배 → ○ 흐트러진 적에게 판정 칸 넓게 → ★ **산 가르기**: 흐트러진 적에게만. 아주 큰 위력, 뒷줄까지 갈라짐
  - **??? 칼등** (숨은 역이용): 피해 크게 감소, 흐트러짐 2배, 쓰러뜨리면 생포(현상금·심문 보상) → ○ 생포 보상 증가 → ★ **역날의 마음**: 체력이 일정 이하인 적 전원을 기절시켜 생포

#### ③ 되받아치기

2단계 · 보통 · 자세 · 단일 · 여는 · 자상. 내 차례에 자세를 잡아, 그 턴 나를 노린 공격의 받아치기 칸을 넓히고 성공하면 위력 11로 반격. 적이 나를 안 노리면 헛수고라 적의 의도를 보고 쓴다(공용 받아치기는 적 차례의 아주 좁은 반응이라 구분됨).

- ○ 자세 중 받는 피해 −10% · ○ 반격 위력 +5%
- **A. 받아치기**: 칸이 더 넓어짐
  - ○ 받아치기 성공 시 기력 +1 · ○ 택1: 자세가 한 턴 더 유지 / 반격이 2타
  - **A-1 나**: 성공하면 집중 2 → ○ 집중 최대치 + → ★ **명경지수**: 3턴 동안 나를 노린 모든 공격에 넓은 받아치기 칸, 성공할 때마다 집중
  - **A-2 동료**: 옆 칸 동료를 노린 공격도 받아칠 수 있음 → ○ 동료 대신 받을 때 피해 −10% → ★ **기사의 맹세**: 한 턴 동안 아군 전체를 노린 공격을 혼자 받아침. 성공한 수만큼 아군 사기
- **B. 밀어붙이기**: 자세를 잡으면서 약하게 한 번 찌름
  - ○ 찌르기 위력 +10% · ○ 택1: 찌르기가 관통 피해 / 찌르기에 흐트러짐
  - **B-1 깎기**: 찌른 적에게 취약 → ○ 취약 지속 +1턴 → ★ **틈을 여는 검**: 반격에 성공하면 그 적의 모든 저항이 2턴 동안 0
  - **B-2 키우기**: 자세 중 자신감 쌓임 → ○ 자신감 최대치 + → ★ **흔들리지 않는 자**: 자신감을 모두 써서 다음 3번의 공격 판정 칸을 최대로

#### ④ 돌진 베기

2단계 · 강함 · 1타 · 단일 · 여는 · 자상. 위력 약 14, 쿨다운 3, 기력 2.

- ○ 위력 +5% · ○ 앞줄에 있을 때 기력 −1
- **A. 뚫기**: 맞은 적을 뒷줄로 밀어내고 그 뒤 적을 앞으로 끌어냄
  - ○ 밀려난 적 흐트러짐 + · ○ 택1: 밀려난 적 한 턴 속박 / 끌려 나온 적 취약
  - **A-1 연타**: 밀려난 적과 끌려 나온 적 둘 다 한 번씩 → ○ 두 번째 타 위력 +10% → ★ **진형 붕괴**: 적 앞줄 셋을 모두 뒷줄과 자리 바꾸며 한 번씩 벰
  - **A-2 일격** (끝내는 기술로 바뀜): 밀어내지 않고 흐트러짐 크게 → ○ 방패를 든 적에게 위력 + → ★ **성벽 부수기**: 지키기·방패를 무시하고 흐트러짐을 즉시 절반으로
- **B. 찌르기** (관통으로 바뀜): 이번 턴만 뒷줄까지 닿음
  - ○ 관통 위력 +5% · ○ 택1: 찌른 뒤 원래 자리로 돌아옴 / 찌른 적과 자리 바꿈
  - **B-1 조건**: 대상이 원거리 적이면 2배 → ○ 원거리 적을 찌르면 기력 +1 → ★ **천적사냥**: 적 뒷줄 전원을 차례로 돌진해 찌름
  - **B-2 상시**: 뒷줄 위력 감소 없음 → ○ 판정 칸 조금 넓게 → ★ **꿰뚫는 돌격**: 앞줄과 그 뒤 뒷줄을 한 줄로 관통

**그 밖**: 가문 갈래 자리는 비어 있음(라인펠트 가문 검술은 세검 나무로). 연계 역할은 터뜨리기·일격 갈래가 끝내는 기술로 바뀌어서, 어떤 기본기 셋을 골라도 여는·잇는·끝내는을 갖출 수 있다.

### 나머지 무기 나무 (확정 초안)

검술과 같은 틀이다. 아래에는 분기점과 궁극기만 적고, **보완 칸은 각 루트에 기준표 기본 세트**(위력, 판정 칸, 기력, 효과 +1)를 루트 성격에 맞춰 붙인다. 적는 법: 기본기 (단계 · 성격 · 연계 역할): 첫 갈래 → 두 번째 갈래 ★궁극기. 숨은 갈래는 "숨은"으로 표시. 각 나무는 12개 축을 한 번씩 쓴다.

#### 세검

레이피어·펜싱. 정밀한 찌르기와 받아치기, 발놀림. 관통. 라인펠트 가문 갈래 「일각 일점 황홀경 찌르기」가 숨어 있다.

- 줄기: 1 기본 「찌르기」, 실버 스러스트, 발레스트라 / 10 카운터 리포스트 / 30 플레슈 / 50 변형 왼손 단검(막기) · 망토(시야 가리기)
- 뿌리: 검끝(판정 칸) · 손목(완벽 배율) · 발(이동) · 예법(일대일일 때 강화)

- ④ **플레슈** (3단계 · 강함 · 1타 · 끝내는 · 관통): 온몸을 던지는 돌진 찌르기. 넓게(앞줄과 뒷줄 세로로) → 쌓기 ★꿰어 잇기 / 터뜨리기 ★관통하는 섬광 | 깊게(한 명에게 모든 것을) → 끈질김 ★물러서지 않는 칼끝 / 마무리 ★마지막 화살처럼 / 숨은 가문 갈래 **일각 일점 황홀경 찌르기** (마무리 초식 자체가 궁극기 ★일각 일점 황홀경 찌르기)

#### 방패

파티의 벽. 파열. 방패는 왼손 장비라서, **방패를 들면 기본기 셋을 주무기 나무와 방패 나무에서 섞어 고를 수 있다.**

- 줄기: 1 기본 「방패 밀기」, 방패 치기, 지키기 / 10 방패벽 / 30 방패 돌진 / 50 변형 둥근 방패(받아치기) · 큰 방패(지키기)
- 뿌리: 두께 · 팔 · 발 버팀 · 맹세
- ① **방패 치기** (1단계 · 보통 · 1타 · 여는 · 파열, 밀치기): 뚫기 → 연타 ★연속 방패 치기 / 일격 ★코 깨기 | 노리기 → 깎기 ★무장 털기 / 키우기 ★기세 꺾기
- ② **지키기** (1단계 · 자세): 옆이나 뒤 동료 대신 맞음. 나 → 받아치기 ★되돌려 주는 방패 / 밀어붙이기 ★한 걸음도 | 동료 → 끈질김 ★끝까지 지킨다 / 마무리 ★쓰러지기 전에 | 숨은 역이용 **방패 휘두르기**(지키기를 버리고 공격) ★방패가 무기다
- ③ **방패벽** (2단계 · 자세 · 아군 수호): 넓게(아군 전체) → 흐름 ★거북 등 / 홀로 ★홀로 선 성문 | 깊게(한 명 철벽) → 확실 ★흔들림 없음 / 도박 ★마지막 성벽
- ④ **방패 돌진** (3단계 · 강함 · 1타 · 끝내는 · 파열): 막은 피해를 쌓았다 돌려줌. 쌓기 → 빠르게 ★쌓인 분노 / 무겁게 ★성벽 무너뜨리기 | 터뜨리기 → 조건 ★되갚기 / 상시 ★반격의 돌진

- 줄기: 1 기본 「쏘기」, 연사, 조준 사격 / 10 화살비 / 30 꿰뚫는 화살 / 50 변형 불화살 · 긴 활
- 뿌리: 시위 · 눈 · 화살통 · 발걸음
- ① **연사** (1단계 · 약함 · 3타 · 잇는 · 관통): 연타 → 빠르게 ★화살 폭풍 / 무겁게 ★한 대 더 | 일격 → 흐름 ★시위 노래 / 홀로 ★외톨이 사수
- ② **조준 사격** (2단계 · 강함 · 한 턴 조준 후 1타 · 여는): 확실 → 조건 ★표적 / 상시 ★바람 읽기 | 도박 → 깎기 ★약점 노출 / 키우기 ★한 발의 내기
- ③ **화살비** (2단계 · 약함 · 전체): 넓게 → 끈질김 ★끝없는 비 / 마무리 ★하늘이 검게 | 깊게(한 곳 집중 포화) → 쌓기 ★집중 포화 / 터뜨리기 ★소나기

### 가문·조직 전용 나무

일반 나무와 같은 틀(줄기·뿌리·기본기 4·궁극기)이지만, **조건을 채운 사람만** 열리고 잠겨 있을 땐 이름도 보이지 않는다.

#### 그라비다드 칼다레 (가문 무기 전용)

- **여는 조건**: 칼다레 가문 출신이거나 가문 사람에게 전수받고, \*\*가문 무기(칼다레가의 대검)\*\*를 들었을 때만. 대검 나무와는 별개.
- **줄기**: 피오레·리히테나워 기초는 반드시 거치는 바탕이라 줄기에서 자동으로 익힌다(피오레: 집중·결의 / 리히테나워: 자세로 위압). 1 기본 「무게 싣기」, 엘 파로, 카이다 데 히에로 / 10 센티넬라 / 30 오비타.
- **고유 자원 「아드레날린」**: 막기·합에서 쌓이고, 소모하면 파괴력이 폭발한다.
- ① **엘 파로** (수비 자세 · 여는): 받아치기(체란도) → 나 ★돌탑 / 동료 ★가문의 심장 | 밀어붙이기 → 깎기 ★눈부신 등불 / 키우기 ★꺼지지 않는 등대 | 숨은 일루시오네스 **가르보 수엘토**(수비) ★잔상의 춤
- ② **카이다 데 히에로** (2단계 · 강함 · 내려찍기 · 끝내는 · 파열): 빠르게 → 연타 ★쇠비 / 일격 ★모루 | 무겁게 → 확실 ★죽은 무게 / 도박 ★**임팩토 아솔루토**(가문 정통 궁극기) | 숨은 일루시오네스 **온다 데 비에른토** ★바람의 물결
- ③ **센티넬라** (자세 · 공간 점유·위압): 넓게 → 쌓기 ★피의 경계 / 터뜨리기 ★아드레날린 폭발 | 깊게 → 조건 ★한 발짝도 / 상시 ★불침번 | 숨은 일루시오네스 **데스비오 플루이도**(수비) ★흘려보내기
- ④ **오비타** (회전 · 잇는): 끈질김 → 흐름 ★끝없는 궤도 / 홀로 ★홀로 도는 별 | 마무리(피날레) → 뚫기 ★대단원 / 노리기 ★마지막 궤도 | 숨은 일루시오네스 **라스 솜브라스** ★그림자들

**일루시오네스 (숨은 갈래, 역이용 성격)**: 작은 체구로 거검을 다루려고 볼카누스가 만든 비전. 무거운 검을 무겁게 쓰지 않는다는 점에서 가문 검술을 거꾸로 쓰는 갈래다.

- **여는 조건**: 볼카누스 본인, 또는 볼카누스에게 전수받고 곡예 숙련도가 일정 이상.
- 네 기본기 각각의 숨은 세 번째 선택지로 들어간다(가르보 수엘토, 온다 데 비에른토, 데스비오 플루이도, 라스 솜브라스).
- **고유 자원**: 수비로 「잔상」, 공격으로 「관성」이 쌓인다. 잔상이 차면 기본 공격이 **파소 데 아라냐 → 비상**으로, 관성이 차면 **라소 펜길로 → 템페스타**로 강화된다.
- **★ 임팩토 세로**: 일루시오네스 숨은 갈래 둘 이상을 끝까지 키우면 열리는 최상위 궁극기.

#### 잔향 (잔향극단 조직 나무)

- **여는 조건**: 잔향극단 소속(정동 팔머) 또는 극단에 들어감. 보조 칸에 들어가고, 아래 고유 자원은 어떤 무기를 들어도 적용된다.
- **고유 자원 「잔향」**: 서로 다른 기술을 쓸 때마다 하나씩 쌓이고, 같은 기술을 반복하면 흩어진다. 소모하면 지난 턴 기술을 메아리로 다시 펼친다(위력 60%). 강한 기술 하나만 반복하지 않게 하는 전투 규칙과 딱 맞는 무대 기술이다.
- 줄기: 1 기본 「인사」(아군 사기·적 시선 끌기), 공중제비, 불 뿜기 / 10 줄타기 / 30 대단원 / 50 변형 가면(적 공포) · 종(아군 정신력)
- 뿌리: 박자 · 객석 · 무대 · 메아리
- ① **공중제비** (곡예 · 피하기·이동 · 여는): 나 → 확실 ★허공의 무희 / 도박 ★목숨 건 공중돌기 | 동료 → 흐름 ★인간 탑 / 홀로 ★그네 타는 손
- ② **불 뿜기** (연희 · 범위 화상 · 잇는): 넓게 → 쌓기 ★불의 고리 / 터뜨리기 ★용의 숨 | 깊게 → 빠르게 ★불꽃 저글링 / 무겁게 ★태양 삼키기
- ③ **줄타기** (뒷줄로 이동 · 조롱으로 적의 의도 대상을 바꿈): 뚫기 → 깎기 ★광대의 조롱 / 키우기 ★줄 위의 왕 | 노리기 → 조건 ★아찔한 낙하 / 상시 ★보이지 않는 줄 | 숨은 역이용 **앙코르 강요**(적이 방금 쓴 기술을 다시 쓰게 고정, 실패하면 적 사기 상승) ★한 번 더!
- ④ **대단원** (끝내는): 잔향을 모두 써서 이번 전투에 쓴 기술들을 차례로 재연. 끈질김 → 받아치기 ★커튼콜 / 밀어붙이기 ★끝나지 않는 공연 | 마무리 → 연타 ★총연습 / 일격 ★막이 내린다

### 보조 나무 (확정 초안)

무기 나무보다 작은 같은 틀이다.

- **기본기 3개**, 바탕 기술 숙련도 1 / 10 / 30에 차례로 열림. 전투엔 그중 하나를 보조 칸에 든다.
- 루트 모양은 무기 나무와 같고(기본기 → 갈래 둘 → 끝갈래 넷 → 끝갈래마다 궁극기), **보완 칸은 각 단계 뒤 하나씩**이라 루트 하나가 7칸. 보조 궁극기도 궁극기 칸에 들 수 있다.
- **뿌리 2갈래 × 3칸**. 점수는 무기 나무와 같은 규칙(가지 4마다 1, 뿌리 10마다 1).
- 12개 축 중 9개를 한 번씩 쓴다. 역이용은 숨은 세 번째 선택지.

#### 곡예 (곡예)

- ① **몸 비틀기** (피하기 칸 넓힘 · 여는): 나 → 확실 ★흔들리는 잎 / 도박 ★칼끝 위의 춤 | 동료 → 흐름 ★합동 곡예 / 홀로 ★독무대
- ② **뛰어넘기** (자리 옮기기 공짜 · 적 사이 파고들기): 뚫기 → 빠르게 ★적진 횡단 / 무겁게 ★내려 밟기 | 노리기 → 조건 ★등 뒤 착지 / 상시 ★높은 도약
- ③ **균형 잡기** (자세 · 흐트러짐 회복): 끈질김 → 쌓기 ★오래 버티는 몸 / 터뜨리기 ★반동 | 마무리 → 받아치기 ★공중 반격 / 밀어붙이기 ★착지의 일격 | 숨은 역이용 **넘어지는 척** ★엄살쟁이의 반격

#### 말 (웅변·화술·설득)

- ② **위협** (적 공포·흐트러짐): 깎기 → 조건 ★약점 들추기 / 상시 ★차가운 시선 | 키우기 → 흐름 ★기세 / 홀로 ★홀로 선 자의 외침
- ③ **설득** (적 의도 바꾸기·항복 권유): 연타 → 쌓기 ★말의 홍수 / 터뜨리기 ★논파 | 일격 → 받아치기 ★말꼬리 잡기 / 밀어붙이기 ★최후통첩 | 숨은 역이용 **이간질** ★분열

- ① **행진곡** (여러 턴 아군 버프): 끈질김 → 흐름 ★끝나지 않는 행진 / 홀로 ★홀로 부르는 노래 | 마무리 → 넓게 ★합창 / 깊게 ★한 사람을 위한 노래
- ② **진혼곡** (정신력 회복·공포 제거): 나 → 확실 ★고요한 숨 / 도박 ★목이 쉬도록 | 동료 → 쌓기 ★위로의 화음 / 터뜨리기 ★눈물의 해방
- ③ **전쟁가** (적 약화 광역): 깎기 → 조건 ★적의 장송곡 / 상시 ★북소리 | 키우기 → 빠르게 ★빠른 박자 / 무겁게 ★느린 진군 | 숨은 역이용 **불협화음** ★부서진 선율

#### 기도 (신학)

- ① **결의의 기도** (결의·공포 막기): 나 → 끈질김 ★꺾이지 않는 믿음 / 마무리 ★마지막 기도 | 동료 → 넓게 ★회중의 기도 / 깊게 ★한 영혼을 위하여
- ② **낭독** (여러 턴 정신력 버프, 먹빛신앙과 같은 계열): 흐름 → 쌓기 ★성전 낭독 / 터뜨리기 ★아멘 | 홀로 → 확실 ★묵상 / 도박 ★금식 기도
- ③ **축복** (회복·정화): 빠르게 → 조건 ★응급 축도 / 상시 ★매일의 기도 | 무겁게 → 받아치기 ★방패의 기도 / 밀어붙이기 ★심판의 기도 | 숨은 역이용 **이름 부르기**(이름 없는 다섯 날의 금기를 깸, 자기 정신력 손실) ★대답하는 것

#### 의술 (의술·약초)

- ① **응급 처치** (치료): 빠르게 → 연타 ★전장 의무병 / 일격 ★한 번의 지혈 | 무겁게 → 확실 ★완벽한 봉합 / 도박 ★대수술
- ② **해독** (독·출혈 멈춤): 나 → 끈질김 ★내성 / 마무리 ★역류 | 동료 → 넓게 ★약초 연기 / 깊게 ★해독제 한 병 | 숨은 역이용 **독으로 단련** ★극약 처방
- ③ **약 투여** (버프·각성): 쌓기 → 조건 ★응급 각성 / 상시 ★강장제 | 터뜨리기 → 흐름 ★연쇄 투약 / 홀로 ★한 알의 기적 | 숨은 역이용 **잘못된 처방** ★양귀비 잠

#### 지휘 (정무·법도)

- ① **진형 명령** (진형 바꾸기): 뚫기 → 빠르게 ★돌격 나팔 / 무겁게 ★방진 | 노리기 → 확실 ★집중 사격 명령 / 도박 ★기습 명령
- ② **동료 강화** (동료 NPC): 키우기 → 흐름 ★연계 작전 / 홀로 ★장군의 위엄 | 깎기 → 조건 ★약점 보고 / 상시 ★정찰
- ③ **작전** (한 턴의 행동 순서 조정): 끈질김 → 쌓기 ★장기전 / 터뜨리기 ★총공세 | 마무리 → 넓게 ★포위 섬멸 / 깊게 ★목 베기 명령 | 숨은 역이용 **미끼** ★희생의 계책

#### 뒷골목 (잠입·독)

- ② **기습** (첫 턴): 조건 → 확실 ★그림자에서 / 도박 ★단 한 번의 기회 | 상시 → 빠르게 ★날쌘 손 / 무겁게 ★뒤통수
- ③ **속임수** (물건 훔치기·적 기술 봉인): 깎기 → 받아치기 ★손버릇 / 밀어붙이기 ★무장 빼앗기 | 키우기 → 나 ★주머니 털기 / 동료 ★한패 | 숨은 역이용 **잡힌 척**(일부러 붙잡혀 적 진형 안으로, 다음 턴 큰 기습) ★덫이 된 미끼

#### 기마 (승마, 야외 전투만)

- ① **돌진** (앞줄 뚫기): 뚫기 → 연타 ★기병 돌격 / 일격 ★창끝 돌진 | 노리기 → 조건 ★측면 돌파 / 상시 ★말 위의 사냥
- ② **말 다루기** (회피·이동): 빠르게 → 흐름 ★질주 / 홀로 ★외로운 기수 | 무겁게 → 받아치기 ★짓밟기 / 밀어붙이기 ★앞발 들기
- ③ **교감** (말 동료 강화): 나 → 끈질김 ★지치지 않는 말 / 마무리 ★마지막 질주 | 동료 → 넓게 ★기병대 / 깊게 ★한 몸 | 숨은 역이용 **말을 버리다**(뛰어내려 큰 일격, 말 부상) ★낙마의 일격

- ③ **보살핌** (짐승 회복·강화): 끈질김 → 쌓기 ★함께 자란 시간 / 터뜨리기 ★야성 해방 | 마무리 → 빠르게 ★마지막 사냥 / 무겁게 ★포효 | 숨은 역이용 **굶긴 짐승** ★굶주림

### 유일물과 유일 기술

**규칙** (Unity 기획서의 공식 그대로)

- 하찮아 보이는 물건·기술을 오래 쓰거나 특이한 행동을 쌓으면, 숨은 조건을 **처음 다 채운 한 사람**에게만 정체가 드러나 유일물이 된다. 하찮은 물건은 여러 개라 누구나 얻을 수 있고, 누군가 정체를 밝히는 순간 다른 사람 것은 평범한 물건이 된다.
- 조건의 3분의 1, 3분의 2에서 작은 반응(소리, 빛, 대사 한 줄). 드러나면 숨은 장면과 단서가 열린다.
- 한 사람이 들 수 있는 건 **장비 하나 + 기술 하나**(장신구는 장비로 셈). 유일 기술은 기본기 칸 하나를 차지한다.
- **유일물 등록부**(세계 상태): 유일물 ID → 주인, 얻은 때, 주인의 마지막 접속. 도서관에는 한 번이라도 누가 찾아낸 유일물만 이름이 오르고(찾기 전엔 ???), 주인은 숨기고 소문만 돈다.
- 그르지엔은 1장 보스라 유일물에 안개 효과를 넣지 않는다. 2\~5장 마인과 직접 얽힌 유일물은 그 장이 열릴 때 추가한다.
- 정체는 네 종류: 사자의 흔적(꽃), 마공학 유물, 역사 속 인물의 유품, 마인과 얽힌 것.

## 콘텐츠 두 겹

게임은 **하루 제한이 있는 성장**과 **끝없는 모험·생활** 두 겹으로 돈다. 기존 사이트에서 진백둥이 님이 할 게 없어 아쉬워했던 문제를 두 번째 겹이 푼다.

### 1. 달 행동 (하루 제한)

배우기, 일하기, 사람 만나기, 쉬기 같은 성장 행동. 능력치·숙련도·인맥은 여기서만 오른다(전투 숙련도 예외는 아래).

### 2. 상시 콘텐츠 (끝없음)

언제든 몇 번이든 할 수 있다. 보상은 **능력치가 아니라 물건·돈·기록**이라, 하루 종일 하는 사람과 가끔 하는 사람의 성장 차이가 크게 벌어지지 않는다.

| 갈래 | 내용 | 나오는 것 |
| --- | --- | --- |
| 탐험 | 숲·늪·갱도 같은 던전. 층마다 방이 무작위. 혼자 또는 파티 | 재료, 장비, 낮은 확률로 유물 |
| 사냥·채집·낚시 | 지역별 미니게임 | 고기, 가죽, 약초, 물고기 |
| 제작·요리 | 재료로 장비 만들기·강화, 음식 | 전투용 물건, 일시 버프 |
| 훈련장·투기장 | 허수아비, 교관 대련, 플레이어 결투, 순위표 | 칭호, 상금 |
| 반복 레이드 | 지역 보스를 주마다 교대로. 파티용 | 보스 전용 재료와 장비 |
| 수집 | 적 도감, 물건 도감, 지역 소문, 단서 수첩 | 다 모으면 칭호나 숨은 장면 |
| 거처와 꾸미기 | 여관방 → 셋집 → 집. 가구, 정원, 의상, 스탠딩 꾸미기, 친구 초대 | 감성 보상 |

**고리**: 탐험·사냥에서 재료 → 제작으로 장비 → 더 어려운 던전·레이드 → 더 좋은 재료와 꾸밀 거리 → 집과 도감이 채워짐. 싸움을 좋아하면 앞쪽을, 꾸미기를 좋아하면 뒤쪽을 계속 돌 수 있다.

**전투 숙련도**는 지금처럼 "이긴 전투에서 쓴 기술 +1, 한 달에 기술마다 최대 +1" 상한을 유지해서 상시 전투를 아무리 해도 성장이 폭주하지 않는다.

### 부드러운 제한

콘텐츠 갈래마다(탐험 / 사냥·채집·낚시 / 훈련장·투기장 / 반복 레이드) 따로 센다. 한 갈래 보상이 줄면 다른 갈래로 넘어가면 다시 100%다.

| 그날 몇 번째 | 보상 |
| --- | --- |
| 1\~3번째 | 100% |
| 4\~6번째 | 70% |
| 7\~10번째 | 40% |
| 11번째부터 | 20% (0이 되진 않음) |

- **줄어드는 것**: 돈, 재료 수량, 드롭 확률.
- **안 줄어드는 것**: 도감 첫 발견, 첫 클리어 보상, 업적·칭호, 제작과 꾸미기 그 자체.
- 현실 하루마다(세계 달력이 넘어갈 때) 초기화.
- 화면에 "오늘의 피로"로 지금 몇 번째인지 보여준다. 세계관 안에선 하루 동안 쌓인 피로.
- 기존의 "걸음"(아예 못 하게 막는 제한)은 이것으로 대체한다.

### 상시 콘텐츠 상세

| 갈래 | 내용 |
| --- | --- |
| 탐험 (던전) | 지역마다 던전(1장까지: 국경 숲길, 황도 지하수로, 카른브룸 서쪽 갱도, 뮈르가스트 늪 가장자리, 소프레고 화산 동굴 등). 3\~5층, 격자 방을 탐사(아래 「던전 탐사」). 층 끝 정예, 마지막 보스. 한 번 들어가면 체력·기력이 이어짐. **쓰러지면 그 탐험에서 얻은 것의 절반을 잃는다** |
| 사냥·채집·낚시 | 사냥은 흔적 추적 → 짧은 전투나 한 발 사격. 채집은 지도 위 지점에서 캐기 + 비슷한 독초 가려내기. 낚시는 찌 타이밍 + 줄 당기기. 세계 달력의 계절에 따라 나오는 것이 바뀜 |
| 제작·요리 | 대장간(장비 제작·강화), 약방(약), 부엌(요리 버프). 레시피는 책·스승·조합 시도로 발견. 품질 = 숙련도 + 재료 등급 + 타이밍 미니게임(망치질 등). 플레이어끼리 거래 |
| 훈련장·투기장 | 허수아비(내 숫자 확인), 교관 대련(숙련도 벽 시험과 연결), 결투(상대가 접속 안 해도 그 빌드를 자동 전투로 불러옴), 계절마다 순위표 |
| 반복 레이드 | 이야기 밖 지역 보스(산적왕, 거대 늑대, 갱도 골렘 등)가 주마다 교대. 2\~6인 |
| 수집 | 적·물건·물고기·약초 도감, 지역 소문, 칭호 |
| 거처와 꾸미기 | 다섯 단계, 여러 지역에 집을 둘 수 있음(아래 「거처」). 격자에 가구 배치, 정원(씨를 심으면 세계 달력에 맞춰 자라 재료가 됨), 손님 초대와 방명록. 거처가 좋을수록 쉬기 효율과 보관함 증가. 의상은 겉모습만 |

### 던전 탐사

아이작식 격자 탐사. 방 안 전투는 턴제.

**들어가기 전**: 혼자 또는 파티(아군 여섯 칸을 플레이어와 동료가 나눔). 장비, 물약·음식, 그 던전의 소모품(갱도 등불 기름, 화산 물)을 챙긴다. 가방 칸이 정해져 있어 많이 챙기면 주울 자리가 준다.

**층의 모양**

- 층마다 방 8\~15개가 상하좌우로 붙은 격자(깊을수록 많음). 들어갈 때마다 새로 짜인다.
- 처음엔 시작 방만 보이고, 들어간 방과 그 옆방의 윤곽만 작은 지도에 밝혀진다. 지도 아이템이나 길잡이 동료가 있으면 층 전체가 보인다.
- 지나온 방으로 자유롭게 되돌아갈 수 있다.

| 방 | 하는 일 |
| --- | --- |
| 전투방 | 들어가면 문이 닫히고 이겨야 열림 |
| 정예방 | 층 끝의 문지기. 이겨야 다음 층 계단이 열림 |
| 보물방 | 잠겨 있어 열쇠가 필요 |
| 비밀방 | 벽 뒤에 숨음. 폭약이나 둔기 「벽 부수기」로 열고, 눈치가 높으면 수상한 벽이 보임. 유일물·이야기 단서는 주로 여기에 |
| 쉼터방 | 층마다 하나. 쉬기(체력·기력 일부 회복) / 손질(수리, 요리 버프) / 귀환 중 한 번 |
| 상점방 | 떠돌이 상인, 비쌈 |
| 사건방 | 비주얼노벨 장면과 선택지 |
| 함정방 | 피하기 미니게임으로 넘기거나 체력·소모품을 냄 |
| 보스방 | 마지막 층 끝 |

- **열쇠와 폭약**은 던전 안에서 줍는다. 열쇠는 보물방·잠긴 상자, 폭약은 비밀방·금 간 벽. 수가 적어 어디에 쓸지가 고민거리.
- **이어지는 것**: 체력·부상·상태이상은 방 사이에 그대로. 기력은 전투가 끝나면 일부만 찬다. 체력은 쉼터나 약으로만 회복.
- **던전 장치 = 시간 압박**: 되돌아갈 수 있으니, 방을 옮길 때마다 던전이 조금씩 나빠진다. 지하수로는 물이 차올라 낮은 방부터 잠기고, 갱도는 일부 문이 무너지고 등불 기름이 줄고, 늪은 안개가 짙어져 지도에 밝혀지는 범위가 줄고, 화산은 옮길 때마다 기력이 깎인다.
- **쓰러지면**: 한 명만 쓰러지면 나머지가 계속 간다(쓰러진 사람은 다음 쉼터에서 일으키거나 여명기도로). 전멸하면 밖으로 쫓겨나고 이번에 얻은 것의 **절반**을 잃는다. 쉼터에서 귀환하면 **전부** 가져간다.
- **멈추기**: 방과 방 사이에서는 접속을 꺼도 저장. 파티는 다 같이 있어야 진행. 현실로 하루가 지나면 자동 귀환(이때는 전부 가져감).
- 한 층에 10\~15분 정도.

| 1장 던전 | 층 | 고유 장치 | 보스 | 특산 |
| --- | --- | --- | --- | --- |
| 국경 숲길 | 3 (입문) | 덫, 사냥꾼 오두막(쉼터) | 굶주린 늑대왕 | 가죽, 목재, 약초 |
| 황도 지하수로 | 3 | 물이 차오름, 밀수 창고 방 | 수로의 늙은 악어 | 밀수품, 오래된 동전 |
| 카른브룸 갱도 | 5 | 무너짐, 등불 기름 | 갱도 골렘 | 철광석, 보석, 낮은 확률로 유물 조각 |
| 뮈르가스트 늪 가장자리 | 4 | 짙어지는 안개, 쇠약 누적 | 늪의 밀렵꾼 두목 | 늪 약초, 갈대, 1장 단서 |
| 소프레고 화산 동굴 | 4 | 열기(물로 버팀), 설 수 없는 용암 칸 | 밀거래단 두목 | 화산 유리, 유황, 향신료 원료 |

### 거처

| 단계 | 생활비 | 할 수 있는 것 |
| --- | --- | --- |
| 여관 공동 침상 | 가장 쌈 | 작은 가방만, 꾸미기 없음 |
| 여관 독방 | 조금 | 보관함, 침대·탁자 정도 꾸미기 |
| 셋집 | 보통 | 방 1\~2개 격자 배치, 창가 화분, 손님 초대 |
| 집 | 비쌈(구입 + 재산세) | 방 여러 개, 텃밭 정원, 작업대(제작 보너스), 서늘한 창고 |
| 저택 | 아주 비쌈, 신용 높아야 | 큰 정원, 동료 숙소(동료 회복 빠름), 하인(일꾼) |

- 단계가 오를수록 쉬기 효율·보관함·꾸밀 칸이 커진다.
- **여러 지역에 집을 둘 수 있다.** 집마다 생활비·재산세가 따로 나간다. 집이 있는 지역은 여관비가 들지 않고 창고가 생겨, 무역 거점이 된다.
- 훈련장·투기장: 라인펠트 아랫마을 훈련장(늙은 교관, 벽 시험), 황도 훈련장, 브라켄 투기장(순위표).

## 경제와 이동

화폐(베아트 1 = 성은 10 = 잎전 100)와 도서관 책의 물가표를 기준값으로 쓴다. 원칙은 **버는 곳은 적게, 쓰는 곳은 많게**.

### 돈과 신용

- **지갑**: 실제 돈.
- **재력 = 신용**: 돈과 따로 움직이는 "얼마나 믿을 만한 부자인가". 대출 한도(이자 있음), 어음·외상 거래, 상인 할인, 귀족·길드의 반응, 길드 가입 조건, 검문 뇌물에 쓰인다.
- **들어오는 곳**: 일하기(직업·단계별 월급, 직업서의 벌이를 따름), 전리품·재료 판매, 의뢰 보상, 현상금, 제작품 판매, 무역 차익.
- **나가는 곳**: 거처 등급별 생활비(달마다 자동), 장비 구매·수리·강화(Unity 기획서의 +10 강화표와 꼬챙이칼 이스터에그), 동료 계약금·치료비, 교본·스승, 나무 초기화, 가구·집, 세금.

### 경제 시뮬레이션

- **상품** 20가지 안팎: 식량(곡식·빵·고기·생선), 재료(철·가죽·목재·약초), 사치품(향신료·술·비단), 군수품(무기·갑옷·말·군량), 얼음 등.
- **시장**: 지역마다 하나. 상품별 재고와 수요.
- **하루(세계 한 달)마다 계산**: 생산(지역 특성 × 계절 × 사건) − 소비(인구 기본 수요 + 전쟁 수요 + 플레이어 구매) + 플레이어 판매. 플레이어가 판 물건은 그 시장 공급에 들어가서, 같은 물건을 쏟아내면 값이 떨어진다.
- **가격** = 기준가 × 수요·공급 비율. 기준가의 0.5\~3배 안, 하루 ±15%까지. 생필품은 덜 흔들림.
- **NPC 상단**이 항로를 따라 싼 곳에서 비싼 곳으로 물건을 옮겨 가격 차이를 메운다. 해적·전쟁 사건이 길을 막으면 물가가 튄다.
- **이야기와 맞물림**: 결과가 월보 기사로 자동 생성되고("향신료 값 두 배"), GM 사건과 메인 스토리 단계가 시뮬레이션에 들어간다(갱도 붕괴 → 철 생산 감소, 뮈르가스트 안개 → 늪 지역 교역 차단).
- **안전장치**: GM 패널의 가격 고정·사건 투입·되돌리기. 장터 게시판에 지역별 시세표와 가격 그래프.

### 무역, 세금, 밀수

- **무역**: 상인·항해사의 핵심 콘텐츠. 짐은 맨몸 → 노새 → 수레 → 배 순으로 늘어난다. 한 번에 많이 팔수록 그 자리에서 값이 떨어져 여러 시장에 나눠 파는 게 이득. 의뢰 게시판에 시뮬레이션 상황에 맞춘 대량 납품 의뢰. 길 위 산적·해적 사건으로 짐을 잃을 수 있고, 용병 호위로 위험을 줄인다.
- **세금**: 성문·다리·검문소 통행세, 항구 입항세, 팔군도 물건의 품목별 관세(513년 관세안이 실제 세율로), 제국 안 인두세(한 해 성은 3닢), 집 재산세, 장터 위탁 수수료, 길드 회비. 기사 인두세 면제, 순례자의 패 같은 설정상 예외를 그대로.
- **밀수**: 제국 금지품(유물, 이단 서적, 일부 약)과 고관세 물건. 이중 바닥 수레·숨은 칸 배로 숨기고(뒷골목 보조 나무와 연결), 검문에서 눈치·언변·신용(뇌물)으로 판정. 걸리면 압수·벌금·평판 하락. 코스타 노스트라·해적단·카르텔이 밀수 의뢰와 판로를 준다.

### 신선도

| 분류 | 예 | 상하는 속도 |
| --- | --- | --- |
| 아주 빨리 | 생선, 고기, 우유 | 이동 몇 시간에도 눈에 띄게 |
| 빨리 | 과일, 채소, 빵 | 며칠 |
| 천천히 | 치즈, 생약초, 술(익어가며 값이 오르는 것도) | 몇 달 |
| 안 상함 | 곡식, 소금, 철, 말린 약초 | 없음 |

- **이동 중엔 이동 시간만큼, 가만히 둔 물건은 세계 하루마다** 줄어든다. 못 들어온 날 가방이 다 썩지는 않는다.
- 보존법: 소금 절이기, 훈제, 말리기(가공하면 안 상하는 대신 값과 쓰임이 바뀜), 얼음 상자(스카르하임 얼음이 무역품), 거처의 서늘한 창고.
- 신선도가 떨어지면 값과 요리 효과가 줄고, 다 상하면 정원 거름으로만. 산 가축과 말은 먹이가 필요하다.

### 이동

이동은 달 행동이 아니라 **상시 콘텐츠**다. 대신 **현실 시간이 걸린다.** (기존의 "이동은 주 행동, 떠나기 2주" 규칙을 대체한다.)

| 길 | 기본 시간 (현실) |
| --- | --- |
| 이웃 지역 | 30분 |
| 한 팔의 끝에서 끝 | 1\~2시간 |
| 대륙 가로지르기 | 3시간 |
| 동쪽 항구 → 베르가나 | 3시간 |
| 베르가나 → 코르사렌 | 6시간 |

| 탈것 | 속도 | 짐 | 필요한 것 |
| --- | --- | --- | --- |
| 걸어서 | 기본 | 적음 | 없음 |
| 노새 | 기본 | 보통 | 노새 |
| 말 | 빠름 | 적음 | 승마 |
| 수레 | 느림 | 많음 | 수레 + 짐승 |
| 마차 | 보통 | 많음 | 승마 일정 이상 |
| 작은 배 / 상선 / 큰 배 | 배마다 다름 | 많음\~아주 많음 | 항해술, 해운 길드 면허·등록 |

- **자동 이동**: 출발하면 타이머가 돌고, 접속을 꺼도 계속된다. 도착하면 알림.
- **길 위 사건**(떠돌이 상인, 산적, 소문, 바퀴 고장): 지역마다 사건 표가 다르다(북부 군용로 징발대·검문, 성지 가도 순례자·안전, 뮈르가스트 안개에 길 잃기). 사건이 터지면 **그 자리에서 멈추고 다음 접속 때 직접 고른다.** 멈춘 동안 타이머도 멈춘다.
- **검문 지점**에서 통행세와 밀수 판정.

**직접 몰기** (원하면, 최대 절반까지 시간 단축. 승마·항해술 숙련도는 한 달 +1까지)

- **수레·말**: 옆으로 흐르는 길, 세 줄 사이를 오가며 구덩이·쓰러진 나무·양떼 피하기. 속도 게이지를 올릴수록 빠르지만 흔들림 게이지가 차서 깨지는 물건이 상하고 신선도가 더 떨어진다. 갈림길에서 지름길(빠르지만 산적 확률 높음)과 큰길 선택. 비 오는 날은 미끄럽다. 긴 길은 여러 구간, 언제든 자동으로 전환.
- **항해**: 위에서 내려다보는 바다. 바람 화살표에 맞춰 돛 각도, 키로 방향. 암초·소용돌이 피하기, 폭풍 구간은 파도 타이밍, 밤엔 별자리로 항로 확인(틀리면 길을 잃어 시간 증가). 해적을 만나면 싸우기 / 바람 타고 도망 / 통행료 중 선택. 배마다 회전·속도·안정성이 다르고, 테세우스 호 같은 유물 배는 바람을 거슬러 달리지만 다루기가 아주 어렵다.
- 배는 **선장 혼자** 몬다. 동승자는 길 위 사건의 선택지에만 참여.
- **면허 시험**: 해운 길드에서 정해진 항로를 항해 미니게임으로 돌고 점수로 합격. 작은 배 → 상선 → 큰 배, 등급이 오를수록 코스가 어렵다(폭풍, 밤 항해). 응시료 성은 20닢.

### 지도 밝히기

| 단계 | 상태 | 이동 |
| --- | --- | --- |
| 1. 모르는 영역 | 안개로 덮임. 갈 수는 있음 | 시간 2배, 길 잃을 확률, 위험한 사건이 잦음. 직접 몰기 불가 |
| 2. 지도만 있는 영역 | 대략적인 위치와 큰길만 | 시간 1.3배, 큰길로만. 직접 몰기 가능 |
| 3. 직접 가본 영역 | 길·지름길·검문·쉬는 곳까지 | 기본 시간, 지름길 사용 |

- 2단계로: 지도 상인에게 사기, 길잡이 고용, 소문·의뢰 보상, 다른 플레이어가 그린 지도(학자·필사가가 지도를 그려 팔 수 있음).
- 3단계로: 직접 그 길을 지나가기.
- 태어난 곳과 살아온 곳은 처음부터 3단계. 기존 캐릭터는 가본 곳을 3단계로 옮긴다. 지역을 모두 밝히면 칭호.

### 세계 지도와 구역

지도는 세 겹이다.

1. **세계 지도**: 지역(중앙대륙 다섯, 팔군도 여덟, 적국 셋). 지역 사이 이동은 「이동」 규칙(현실 시간, 탈것, 직접 몰기).
2. **지역 지도**: 지역 안의 **장소** 4\~7곳(도시, 마을, 요새, 명소, 던전 입구). 장소 사이 이동은 짧은 길(현실 5\~15분), 낮은 확률로 도적·짐승. 달 행동은 쓰지 않는다.
3. **구역**: 장소 안의 자리. 대화·일터·상점·퀘스트가 모두 구역 단위로 돌아간다. 구역 사이 이동은 즉시.

**구역 틀** (장소 크기에 따라)

| 장소 | 기본 구역 |
| --- | --- |
| 도시 | 장터 광장, 여관, 성당(섬은 그 땅의 신앙 장소), 대장간, 의원, 관청·길드, 뒷골목, 거처 거리, 성문. 해안이면 항구, 일부는 훈련장 |
| 마을 | 광장(장터 겸), 여관, 성당 또는 마을 회관, 대장간 또는 일터, 밭·숲 어귀 |
| 요새·명소 | 구역 1\~3 |
| 던전 입구 | 입구 구역 하나 |

구역마다 정의 데이터에 **할 수 있는 것**(상점 종류, 의뢰 게시판, 어떤 직업의 일터인지, 던전·훈련·제작 장소)과 **머무는 NPC**를 적는다.

## 스토리 뼈대

메인 스토리는 **프롤로그 → 1장 그르지엔 → 2\~5장 나머지 마인 → 종장**이다. 모든 장이 같은 틀을 써서, 1장을 완성하면 나머지는 내용만 채운다.

| 장 | 무대 | 메모 |
| --- | --- | --- |

### 이야기 장면 (비주얼노벨)

메인 스토리, 의뢰, 던전 사건, 동료 이야기 등 모든 스토리 장면은 예전 메신저식 대신 **비주얼노벨 방식**으로 보여준다.

- **화면**: 지역 배경 위에 스탠딩 일러스트 최대 셋(왼쪽·가운데·오른쪽). 말하는 사람은 밝게, 나머지는 살짝 어둡게. 아래 대사창에 이름표와 대사. 탭하면 다음 줄, 자동 넘기기·건너뛰기·지난 대사 보기. 선택지는 대사창 위 버튼.
- **연출**: 등장·퇴장, 표정 바꾸기, 화면 흔들림, 배경 전환, 효과음, 컷인 그림. 예전 메신저식의 글씨 색·투명도·크기, NPC가 물건·버프를 건네는 연출은 대사창 안 연출로 이어감. 라디아타 등장(붉은 금이 가며 깨지는 화면) 같은 큰 장면은 전용 연출.
- **대본**: 장면은 "누가, 어떤 표정으로, 무슨 말을, 어떤 연출과 함께"를 한 줄씩 적는 대본 파일로 쓴다. GM 편집기에서 쓰면서 바로 미리보기. 선택지 결과는 친밀도·단서 수첩·일생 기록에 남는다.
- **일러스트**: 스탠딩은 전신이 아니라 **허벅지까지의 반신**으로 그린다(효율). 인물마다 표정 4개(기본·웃음·화남·놀람)면 충분. 일러스트가 없는 인물(플레이어 캐릭터 포함)은 **회색 실루엣에 얼굴 윤곽만 잡힌 반신 기본 스탠딩**으로 나온다. 체형은 남자·여자·아이·큰 체격 정도로 나눈다. 나중에 그림을 넣으면 모든 장면에서 자동으로 바뀐다.

### 구역 대화

플레이어끼리의 대화도 스토리 장면과 같은 방식으로 보여준다.

- **구역**: 지역 안의 장소 단위(황도라면 장터 광장, 여관, 대성당 앞, 학당 거리 등). **같은 구역에 있는 플레이어끼리만** 말할 수 있다. 파티원도 마찬가지.
- 파티가 같이 움직이는 동안(같은 던전 층, 같은 배, 같은 길 위)은 같은 구역으로 친다. 흩어지면 끊긴다.
- **보이는 방식**: 구역 배경 위에 대화 중인 사람들의 스탠딩(없으면 회색 실루엣), 한 말이 이름표와 함께 대사창에 차례로. 말한 사람은 밝게. 스탠딩은 최근에 말한 세 사람, 나머지는 화면 가장자리에 작은 얼굴.
- "/웃음" 같은 짧은 명령으로 표정 바꾸기(일러스트가 있을 때). 같은 구역의 한 사람에게만 하는 귓속말.
- 구역에 들어오면 최근 대화 몇 줄을 지난 대사로 볼 수 있다.
- 멀리 있는 사람과는 편지로. 거리감이 살아 있게.
- GM은 대화 기록을 볼 수 있고, 말 막기·신고 기능이 있다.

### 1장: 뮈르가스트 (그르지엔)

총람의 뮈르가스트 설정(영매, 안개는 조상의 숨결, 동쪽 늪의 쇠약병, 오스트렌의 볼프람과 리젤)을 뼈대로 한다. 세계 달력 514년부터 그르지엔 사냥 517년 후반까지, 현실로 40일 남짓.

**들어가기**

- 새 플레이어: 도서관에서 깨어나 태어나기 → 성장기 → 15세부터 시작.
- 기존 플레이어: 도서관에서 다시 눈을 뜨고, 사서가 "책장이 새로 정리되었다"고 알리며 **지난 삶을 요약한 책**을 건넨다. 옛 데이터의 전투·스토리·월간 기록에서 뽑은 일생 요약(태어난 곳, 겪은 사건, 만난 사람, 이룬 것)을 책장처럼 넘겨 본 뒤 현재 시점으로 돌아간다.

**레이드 규칙**

- 열린 뒤 정해진 기간(임시로 현실 14일) 동안, 캐릭터마다 5번까지(판에 들어가면 파티원 모두 1번씩 씀) 도전할 수 있고, **첫 성공으로 끝난다.**
- **기여도 = 한 번의 도전에서 낸 최고 성적**. 여러 번 도전해도 더해지지 않는다. 성적은 준 피해, 흐트러짐, 지키기·치료·버프로 아군이 덜 받은 피해, 받아치기·피하기 성공을 함께 본다(지원 역할도 손해 보지 않게).
- 기여도 등급(금·은·동·참가)에 따라 도전한 모든 사람에게 보상. 성공 파티에는 칭호 「안개를 걷은 자」.
- **늪 등불**(유일물)은 성공한 파티 안에서 기여도가 가장 높은 사람에게.

* **라디아타**: 파티원 전원이 5번째 도전인 판이 지기 직전에만 나타나, 그 판을 부상 없이 구한다. 레이드는 기간 동안 계속된다. 기간이 끝날 때까지 성공 파티가 없으면 **토벌 실패**: 라디아타가 그르지엔을 처치하는 장면, 칭호 없음, 기여 보상은 그대로, 늪 등불은 주인 없이 노인의 오두막에 꺼진 채 놓인다.

자세한 규칙은 [시스템 명세서](https://claude.ai/artifact/LtLkcURQqntEULvZGhgCNc)를 따른다.

**누가 그르지엔을 쓰러뜨렸나** (설정집의 "마인이 마인을 죽이면" 규칙)

- **플레이어가 토벌에 성공**: 그르지엔의 에너지가 온전히 원탁으로 돌아가, 구약나물이 진 자리에 새 마녀가 **정상으로** 태어난다.
- **토벌 실패(라디아타가 처치)**: 라디아타가 그르지엔의 원념 일부를 흡수하고, 새 마녀는 **약하게** 태어난다. 라디아타는 그만큼 강해진다.
- 이 결과는 세계 표시로 남아 원탁 쪽 이야기(아르카디아가 "유독 약하게 태어난 신생 마녀"에게 위화감을 느끼는 인터루드)와 이후 장의 라디아타의 강함에 쓰인다. 장마다 같은 규칙이 반복되므로, 플레이어가 마인을 몇이나 직접 토벌했는지가 최종장의 원탁과 라디아타를 바꾼다.

### 퀘스트 창

- 여러 퀘스트를 받아두고 한 곳에서 확인한다. 탭: 메인 / 가문 / 의뢰 게시판 / 동료.

| 4막 과거 | 가문의 비밀이나 상처 | 메인 스토리가 일정 장 이상 진행된 뒤에만 열림 |

- 막마다 비주얼노벨 장면과 작은 보상(칭호, 숨은 칸 등). 5막을 넘어야 이야기 재능.
- 4막이 장 진행에 묶여 있고 5막이 80 벽이라 현실로 최소 두세 달. 1장 안에는 끝낼 수 없다.
- 실패해서 영영 막히진 않지만, 결투에서 지면 다시 준비해야 한다.

### 가문 퀘스트 상세

막 보상은 작게(칭호, 외형, 작은 점수·신용), 이야기 재능은 그 캐릭터의 빌드에만 크게 듣게 잡는다. 숫자는 모두 임시. 장 순서: 1장 뮈르가스트(그르지엔) → 2장 카른브룸(바이스가르드) → 3장 코르사렌(마르텐 리드) → 4장 테산가(아젠타르) → 5장 베르가나(레오나르 뒤샹) → 최종장 라디아타. 4막은 1장 뒤 볼카누스·아스테리스, 2장 뒤 정동 팔머·제르노바엘, 3장 뒤 카멜·하우레스, 4장 뒤 전바섬, 5장 뒤 메멜 순으로 열린다.

**소프레고의 두 얼굴**: 볼카누스 4막과 아스테리스 4막은 **같은 사건을 양쪽에서** 본다. 칼다레 가를 친 두 테니엔테와, 그 일을 눈감아 준 시장의 비밀 계약이 이어져 있다. 한 사람이 찾은 것이 세계 표시로 남아 다른 사람의 단서가 되고, 각자 혼자서도 끝까지 갈 수 있다.

#### 볼카누스 칼다레 · 「토마소를 넘어서」

| 막 | 내용 | 넘어가는 조건 | 막 보상 |
| --- | --- | --- | --- |
| 1. 너무 무거운 검 | 밤마다 자기보다 큰 검을 끌어안고 수련하는 볼카누스, 묵묵히 한숨을 삼키는 토마소 | 그라비다드 칼다레 30 + 토마소와 함께 이긴 전투 10번 | 칭호 「칼다레의 조카」 |
| 2. 일루시오네스 | 정통이 아닌 자기만의 검을 토마소 앞에 처음 내보임 | 일루시오네스 숨은 갈래 둘을 끝까지 + 토마소와 대련(이기지 않아도 됨, 일루시오네스 기술로 토마소의 흐트러짐을 0으로) | 토마소 친밀도 +10, 토마소 대사가 바뀜 |

**「아버지의 무게」**

- 그라비다드 칼다레 나무 기술의 기력 소모 −1(0까지), 판정 바 속도 −10%. 거검이 더는 버겁지 않다.
- **두 검의 이음**: 한 전투에서 일루시오네스 기술과 정통 기술을 번갈아 이을 때마다 위력 +10%(최대 +50%). 같은 쪽을 두 번 이으면 처음으로.
- 잔상이나 관성이 가득 찰 때마다 아드레날린 +1.

- 성직자 NPC의 반응이 달라지고, 고해 선택지가 생긴다.

#### 카멜 · 「지워진 구절」

몬티 가는 한때 황실성전 필사를 맡던 이름 있는 필사가 가문. 지금은 황도 필사공방 거리 구석의 작은 공방에서 근근이 산다(옛 데이터: 16살, 일 없음, 재력 10, 재능 손재주·매력·학식). 부모는 에르제오와 마리아, 할아버지는 세르조 몬티(몰락 전의 공방을 기억하는 늙은 필사가, 2막 장부의 열쇠, 이름은 임시). 검정이 님이 다시 플레이할 때 함께 다듬는다.

| 막 | 내용 | 넘어가는 조건 | 막 보상 |
| --- | --- | --- | --- |
| 1. 몬티 공방의 아이 | 가난한 필사 공방의 일 | 학문·필사 30 + 공방 필사 의뢰 3개 | 칭호 「몬티의 필사가」 |
| 2. 장부 속 이름 | 공방 장부에서 몬티 가가 성전을 필사했던 기록을 찾음 | 필사공방 조합 시험 + 장부 장면 | 기록의 깃펜 유일물 조건 반응이 한 번 미리 보임(단서) |
| 3. 자리 | 조합의 장인 등급, 또는 황도 학당 입학 | 직업 단계 승진 또는 학당 추천서 | 황도 학당·필사공방의 의뢰가 열림 |
| 4. 필사가의 죄 | 몬티 가는 성전을 필사하다 원본과 다른 구절을 남겼고, 정화기에 그 일로 무너졌다. 그 구절은 여명기도와 베아트릭스에 닿아 있다 | 3장(코르사렌) 이후 열림. 지워진 구절을 찾아냄 | 금서고와 이어지는 단서 |
| 5. 다시 쓰는 성전 | 지워진 구절을 다시 세상에 쓸지, 다시 묻을지 | 학문·필사 80 벽 + 선택 사건 | 재능 「지워지지 않는 잉크」 |

**「지워지지 않는 잉크」**

- 적 도감이 한 단계 빨리 열린다(사냥꾼·재능 보너스와는 겹치지 않음).
- 한 번 싸워본 적은 다음 전투부터 의도의 위력이 처음부터 보인다.
- 장면에서 거짓을 꿰뚫는 선택지가 하나 더 생긴다(학식 기준을 넘을 때).

#### 메멜 · 「그림자 장부」

북쪽 팔 출신. 장부와 승마를 익혔고, 의원 프리츠에게 일을 배웠다. 아버지 루모스는 바빠서 아직 어색하고, 어머니 네메스는 가장 의지하는 사람. 제국의 뒷세계를 알아보며 **정보 길드**를 세우려 한다(옛 기록).

| 막 | 내용 | 넘어가는 조건 | 막 보상 |
| --- | --- | --- | --- |
| 1. 장부 쓰는 아이 | 북쪽 팔에서 장부를 맡으며, 사람들의 말과 숫자 사이의 틈을 보기 시작함 | 장부 30 + 정보 의뢰 3개(소문 모으기, 장부 맞추기) | 칭호 「장부쟁이」 |
| 2. 잠행 | 젊은 시절 정보 길드에 있었다는 노인에게 잠행을 배움 | 뒷골목 보조 루트 하나 끝까지 + 노인의 시험(들키지 않고 정보 빼내기) | 지역 소문이 하나씩 더 들림 |
| 3. 첫 연락망 | 제국 안 세 지역에 정보원을 심음 | 직업 단계 승진 + 세 지역에서 정보원 의뢰 완료 + 신용 기준 | 정보 길드 창설(작은 조직), 정보원 편지로 먼 지역 소문을 받음 |
| 4. 프리츠의 환자 | 프리츠가 살리려던 환자 명부에 숨은 것: 정화기 뒤에도 몰래 사라진 사람들. 정보가 사람을 살리기도 죽이기도 한다는 것 | 5장(베르가나) 이후 열림. 명부의 진실을 밝힘 → 선택: **이그니스 사크라에 팔기** / **사라진 사람들의 가족에게 알리기** / **묻어두기** | 선택에 따라 정보 길드의 성격(빛·그림자)과 5막 의뢰인이 달라짐 |
| 5. 그림자 장부 | 길드의 이름을 걸고 큰 비밀 하나를 거래함 | 장부 80 벽 + 큰 정보 거래 사건 | 재능 「모든 것을 적는 자」 |

**「모든 것을 적는 자」**

- 지역 소문과 단서 수첩이 두 배로 빨리 찬다.
- 전투 첫 턴, 적 하나의 다음 두 턴 의도가 보인다.
- 정보 길드 의뢰(소문 팔기)가 열리고, 시세표가 다른 사람보다 하루 빨리 보인다.

#### 하우레스 · 「늑대발의 노래」

스카르하임 늑대발 씨족. 아버지 시구르는 조용히 손을 움직이는 사람, 어머니 아스트리드는 노래를 흥얼거리는 버릇이 있다. 약혼자 잉그리드 파도는 엄격하지만 속정이 깊다. 씨족 연합이 한 씨족 아래 왕국이 되어가는 때.

| 막 | 내용 | 넘어가는 조건 | 막 보상 |
| --- | --- | --- | --- |
| 1. 늑대발의 밭 | 얼음 바다 곁 씨족의 짧은 여름, 밭을 일구는 나날과 어머니의 노래 | 농사 30 + 씨족 의뢰 3개 | 칭호 「늑대발의 아이」 |
| 2. 첫 노래 | 씨족 잔치에서 처음으로 옛 노래를 부름. 노래가 사람을 움직인다는 것을 앎 | 노래 보조 루트 하나 끝까지 + 잔치 공연(리듬게임) | 스카르하임 NPC 친밀도 +5 |
| 3. 두 씨족 사이 | 늑대발 씨족과 파도 씨족(잉그리드의 집안) 사이의 다툼을 노래와 말로 잇는 스칼드가 됨 | 직업 단계 승진(음유) + 잉그리드 친밀도 80 + 씨족 회의 협상 전투 | 씨족 선단 배를 탈 수 있음(북쪽 바다 겨울 항로) |
| 4. 바다의 빚 | 씨족 선단이 남쪽 바다 해적들과 얽힌 옛 빚. 왕 후보인 고래 씨족의 늙은 고래잡이는 모르는 채, 그를 앞세워 이익을 보려는 원로들이 그 빚을 덮으려 함 | 3장(코르사렌) 이후 열림. 빚의 진실을 노래로 남길지 → 선택: **노래하기**(원로들과 맞서고, 늙은 고래잡이에게 스스로 바로잡을 기회를 줌) / **침묵하기**(씨족을 지킴) | 선택에 따라 5막의 청중과 잉그리드의 마지막 장면이 달라짐 |
| 5. 왕의 잔치 | 새 왕을 세우는 잔치에서 씨족들의 역사를 노래함 | 노래 80 벽 + 왕의 잔치 대공연(리듬게임 큰 곡과 협상) | 재능 「씨족의 목소리」 |

**「씨족의 목소리」**

- 노래 보조 기술의 효과가 아군 전체로 넓어진다(단일 버프 → 전체, 효과는 70%).
- 말·노래로 치르는 협상 전투에서 흐트러짐 피해 +30%.
- 스카르하임에서 씨족 선단 배를 무료로 탄다.

## 데이터 구조

지금 사이트는 모든 것이 `store` 한 바구니에 문자열로 섞여 있고(273개 항목, 약 830KB), 그중 대부분이 지난 전투·스토리 기록이다. 한 사람 정보도 6\~7군데로 쪼개져 있다. 새 사이트는 처음부터 네 칸으로 나눈다.

| 칸 | 내용 | 바뀌는 때 |
| --- | --- | --- |
| 정의 데이터 | 기술 나무, 적(원형 + 지역표), 물건, 효과, 재능 목록, 동료, 대사 대본, 던전 | GM이 편집할 때만 |
| 세계 상태 | 세계 달력, 메인 스토리 단계, 유일물 등록부, 소식지, 지역 게시판, 반복 레이드 차례 | 하루마다, GM 스위치로 |
| 캐릭터 상태 | 한 사람의 모든 것을 한 덩어리로(기본 정보, 능력치, 재능, 기술·나무, 가방·지갑, 인물, 동료, 거처, 진행 기록) | 플레이할 때 |
| 규칙 | 판정, 전투 계산, 보상 곡선, 진화 조건처럼 위 세 칸을 읽어 결과를 내는 코드 | 코드를 고칠 때 |

- **기록은 요약만 남긴다.** 전투 한 판, 스토리 한 판의 전체 상태를 통째로 저장하지 않는다. 끝나면 결과 한 줄만 캐릭터의 일생 기록에 남기고, 이 기록이 나중에 「이방인들의 서가」의 책 재료가 된다.
- **적은 공식으로.** 지금 코드의 "원형 10종 × 지역표 × 등급(1\~5)" 방식을 그대로 정의 데이터로 옮긴다. 적을 하나씩 만들지 않아도 지역마다 수십 종이 생긴다.
- **그림은 따로.** 스탠딩 일러스트(혼자 64KB)는 데이터베이스가 아니라 별도 저장소에 두고 주소만 적는다.
- **로그인은 새 방식으로.** 캐릭터 암호 해시는 옮기지 않는다.
- 캐릭터 덩어리의 정확한 모양은 아직 정할 것에 남겨둔다.

### 저장 모양

```
정의 데이터 (GM만 편집)
  나무·기술·효과·재능·아이템·레시피
  적(원형 + 지역표)·던전·동료
  길·시장(상품, 지역 생산표)·장면 대본

세계 상태 (모두 공유)
  달력·메인 스토리 단계·유일물 등록부
  시장(지역별 재고·수요·가격)·NPC 상단
  월보·게시판·레이드 차례

캐릭터 (한 사람 한 덩어리)
  기본: 이름·성별·나이·고향·외형·스탠딩
  능력치: 건강·정신력·신용·인맥·평판
  재능: 청한 3 / 타고난(공개 여부) / 얻은
  숙련도: 기술별 값, 벽 통과 여부
  나무: 찍은 칸, 남은 가지·뿌리 점수
  장비 칸: 기본기 3·궁극기·보조·무기·방어구
  가방·지갑 (물건마다 수량·신선도·품질)
  인물·동료 (친밀도, 부상, 흉터)
  거처 (등급, 가구 배치, 정원, 창고)
  지도 (지역별 1~3단계)·도감·칭호
  유물 (적성 축, 적응도, 동화도)
  이번 달 (남은 행동, 저장 행동, 오늘의 피로)
  이동 중 (경로, 도착 시각, 멈춘 사건)
  스토리 (진행 표시, 단서 수첩)
  일생 기록 (한 줄 요약들)

진행 중 임시 (전투·던전·파티)
  끝나면 지우고 결과만 일생 기록으로

계정
  로그인 → 내 캐릭터 목록, GM 권한
```

- 캐릭터는 한 덩어리지만, 자주 바뀌는 칸(이번 달, 이동 중)과 큰 칸(거처 배치, 일생 기록)은 따로 떼어 필요한 것만 읽고 쓴다.
- 정의 데이터는 이름이 아니라 **ID로** 가리킨다. 기술 이름을 바꿔도 캐릭터 데이터가 깨지지 않는다.
- 데이터에 **버전 번호**를 붙여 나중에 구조가 바뀌어도 옮기기 쉽게 한다.
- 내 캐릭터는 나만, 정의·세계는 GM만 고칠 수 있게 보안 규칙으로 막는다.
- **매일 돌아가는 세계 계산**(경제 시뮬레이션, 달력 넘기기, 레이드 교대, 월보 자동 기사, 매일 백업)은 **GitHub Actions 예약 실행**으로 돌린다. 플레이어 브라우저에서 돌리지 않아 조작될 수 없고, 아무도 안 들어온 날에도 돌아간다.

### 오류 없는 코드 원칙

- **규칙은 화면과 분리**: 판정·전투 계산·보상 곡선·시뮬레이션은 화면 코드와 떨어진 순수한 계산 함수로 만들고, **자동 테스트**로 매번 확인한다.
- **저장 전 검사**: 모든 저장은 정해진 모양(스키마)을 통과해야 한다. 잘못된 값, 빠진 칸, 음수 돈은 저장 단계에서 거부된다.
- **주고받기는 한 번에**: 돈·아이템 거래, 보상 지급, 제작은 "전부 되거나 전부 취소"되는 트랜잭션으로. 복사되거나 사라지는 버그를 막는다.
- **조작 방지**: 중요한 계산은 서버 쪽(GitHub Actions)과 보안 규칙에서 확인하고, 화면이 보낸 결과를 그대로 믿지 않는다.
- **시험용 사이트와 실제 사이트 분리**: 새 기능은 시험용 사이트에서 먼저 돌려보고 배포한다.
- **멈추지 않는 화면**: 오류가 나도 플레이어 화면이 멈추거나 하얗게 되지 않게, 안내를 띄우고 자동으로 오류를 기록한다. 기록은 GM 패널에서 본다.
- **매일 백업**과 되돌리기.
- **작게 만들고 하나씩 검증**: 큰 기능도 작은 단위로 나눠 만들고, 각 단위를 확인한 뒤 다음으로 간다.

## 기존 데이터 이전

옛 데이터(Firebase 내보내기, 2026년 11월)는 읽기 전용 보관함으로 얼려두고, 한 번만 도는 **변환 스크립트**로 새 캐릭터를 만든다. 캐릭터는 8명, 사이트 리뉴얼 전에 참여한 사람은 **모두 창립 멤버**.

| 보관만 | 전투 106건, 스토리 진행 52건, 월간 제출 42건 → 사람마다 일생 기록 요약으로 만들어 도서관 책 재료로 |
| 버림 | 접속 표시, 채팅, 파티, 결투 신청, 지역 게시판(새로 생성), 암호 해시(새 로그인 방식으로) |

- 옮기면서 생기는 손해는 창립 특전으로 메운다.
- 옮긴 뒤 첫 한 번은 **나무 초기화 무료**. 새 나무를 보고 빌드를 다시 고를 수 있게.
- 세계 달력은 사이트 기준 514년 은방울꽃의 달이고, 캐릭터마다 마지막 진행 달이 513년 2월\~514년 1월로 벌어져 있다. 이전할 때 모두 세계 달력에 맞춘다.

### 재능 (구글 시트 각 캐릭터 탭 + 사이트 GM 데이터)

| 캐릭터 (플레이어) | 청한 재능 | 타고난 재능 |
| --- | --- | --- |
| 올렁덩콴 전바섬 (진백둥이) | 민첩 · 강건 · 직관 | 없음 |
| 제르노바엘 오렐리 (쩡) | 직관 · 기억력 · 예민한 감각 | 꿰뚫는 눈 (드묾), 비공개 |

| 아스테리스 소프레고 (고먐미) | 민첩 · 예민한 감각 · 직관 | 질긴 목숨 (드묾) |

| 메멜 | 예민한 감각 · 직관 · 눈치 | 약초의 코 (흔함) |

- 볼카누스: 시트의 「꺾이지 않는 마음」은 타고난 재능이 아니라 **얻은 재능 후보**로 돌린다(토마소를 넘어서는 사건 등).
- 카멜과 정동 팔머의 청한 재능은 둘 다 손재주·매력·학식이다(확인됨).
- 쩡 님 캐릭터는 시트 기준 \*\*제르노바엘 오렐리(세스티나, 오렐리 가)\*\*로 잇는다. 사이트에 남은 "브라켄 사제 수련자"는 잘못 남은 데이터로 본다.

### 캐릭터별 나무 점수

옛 숙련도는 빠른 곡선으로 쌓인 것이라 새 곡선에 맞게 **환산**한다: 옛 0\~30 → 새 0\~25, 30\~60 → 25\~45, 60\~80 → 45\~60, 80\~100 → 60\~75(60 벽은 넘은 것으로 인정). 점수는 환산값 기준으로 가지 4마다 1, 뿌리 10마다 1(가지/뿌리로 표기). 보조 나무는 뿌리가 아직 정해지지 않아 가지 점수만. 전바섬은 검술 하나만 높고 나머지가 낮아 볼카누스와 비슷한 체급이라 추가 조정은 하지 않는다.

| 캐릭터 | 무기·전용 나무 (환산 숙련도, 가지/뿌리) | 보조·재능·생활 기술 |
| --- | --- | --- |
| 올렁덩콴 전바섬 | 검술 96→72 (18/7, 60 벽 통과), 세검 22 (5/2, 라인펠트 갈래 열림), 곡도 21 (5/2), 창술 19 (4/1), 궁술 18 (4/1), 투척 17 (4/1), 단검 11 (2/1) | 기마 4(승마 18), 의술 1(약학 4). 사냥 14, 항해술 13 |
| 볼카누스 칼다레 | 그라비다드 칼다레 68→51 (12/5), 일루시오네스 열림 | 얻은 재능 「백병술」(41), 「검무」. 예법 20 |
| 아스테리스 소프레고 | 검술 40→32 (8/3) | 지휘 7(정무 30), 말 4(언변 17) |
| 정동 팔머 | 맨손 격투(기본), 잔향 3(곡예 12) | 말 3(웅변·화술 합산 14). 고대 글자 12 |
| 제르노바엘 오렐리 | 없음 (사제 수련자로 전향) | 기도 5(신학 22). 철학 21, 설득 4 |
| 카멜 | 없음 | 없음 |
| 메멜 · 하우레스 | 없음 | 기마 2(승마 8), 장부 12 / 농사 12 |

볼카누스의 옛 최종 진화 「그라비다드 칼다레 - 일루시오네스」는 **기술(나무)만 옮긴다.** 그 조건 사건 "토마소 칼다레를 뛰어넘다"와 가주 계승은 아직 일어나지 않은 일로 보고, 가문 퀘스트 5막으로 남긴다.

## Claude Code 작업 가이드

이 섹션은 사이트를 실제로 만들 Claude Code에게 주는 안내다. 저장소에 `CLAUDE.md`로 복사해 두고 매 작업의 기준으로 삼는다.

### 너에게 맡기는 일

저편의 정원 사이트를 이 기획서대로 처음부터 다시 만든다. 기존 사이트(GitHub 저장소 garden → uni-nano.github.io/garden, Firebase 프로젝트 hortus-qui-est-ultra, Realtime Database)를 대체한다. 목표는 1장(그르지엔)까지 그 앞의 이야기와 전투를 모두 구현한 **완전한 상태로 배포**하는 것이다.

### 제1원칙

**오류 없이, 플레이어가 편하게 돌아가야 한다.** 빠르게 만드는 것보다 틀리지 않는 것이 먼저다. 확실하지 않으면 추측해서 만들지 말고 물어본다. 「오류 없는 코드 원칙」(데이터 구조 섹션)을 모든 작업에 적용한다.

### 일하는 방식

- **기능을 넣기 전에 먼저 계획을 짧게 보여주고 확인을 받는다.** 요청하지 않은 기능을 먼저 만들어 넣지 않는다(사용량을 아끼기 위해).
- 보고는 **개요만 짧게**. 세부 설정을 하나하나 나열하지 않는다.
- 큰 일은 작은 단위로 나누고, 단위마다 테스트를 통과한 뒤 다음으로 간다.
- 이 기획서와 다르게 해야 할 이유가 생기면 바꾸기 전에 말한다.

### 기술 선택 (권장, 첫 작업에서 확인받을 것)

- 화면: GitHub Pages에 올라가는 정적 사이트. 타입 오류를 미리 잡기 위해 TypeScript와 빌드 도구 사용을 권장.
- 저장: Firebase Realtime Database + Firebase 인증. 보안 규칙으로 "내 캐릭터는 나만, 정의·세계는 GM만".
- 매일 계산: GitHub Actions 예약 실행(경제 시뮬레이션, 달력 넘기기, 레이드 교대, 월보 자동 기사, 백업).
- 검사: 모든 저장 데이터에 스키마 검사. 계산 규칙(판정, 전투, 보상 곡선, 시뮬레이션)은 화면과 떨어진 순수 함수로 두고 자동 테스트.
- 시험용 Firebase 프로젝트를 따로 두고, 실제 사이트에는 시험을 통과한 것만 배포.

### 만드는 순서

1. 저장소 정리, 시험용·실제 환경 분리, 테스트 환경
2. 정의 데이터 형식과 검사기, 기술 기준표 계산
3. 캐릭터 저장 모양, 보안 규칙, 주고받기 트랜잭션
4. 기존 데이터 변환 스크립트(환산 규칙, 재능, 나무 점수, 지난 삶 요약)
5. 전투 계산(순수 함수 + 테스트) → 전투 화면 → 자동 전투
6. 세계 시계, 달 행동, 행동 저장, GitHub Actions 일일 작업
7. 비주얼노벨 장면 엔진과 대본 형식, 구역 대화
8. 상시 콘텐츠(던전 → 사냥·채집·낚시 → 제작 → 훈련장·투기장 → 반복 레이드 → 수집 → 거처)
9. 경제 시뮬레이션, 무역·세금·밀수, 신선도, 이동과 직접 몰기, 지도
10. 1장 콘텐츠(적·의뢰·대본 데이터)와 GM 패널(스토리 스위치, 편집기, 오류 기록)
11. 시험 운영 → 배포

### 참고 자료

문서들은 claude.ai에 있어서 Claude Code가 직접 열 수 없다. 저장소의 `docs/` 폴더에 내려받아 둔다.

| 파일 | 무엇 | 언제 읽나 |
| --- | --- | --- |
| `docs/명세서.md` | 시스템 명세서. 규칙의 기준 | 시스템을 만들 때마다 그 섹션을 먼저 |
| `docs/기획서.md` | 이 문서. 의도와 콘텐츠 목록 | 무엇을 왜 만드는지 볼 때 |
| `docs/대본집.md` | 장면 대본. 형식 그대로 파서가 읽는다 | 장면·대사 기능을 만들 때 |
| `docs/총람.md` | 세계관 총람(원본 설정집 포함) | 콘텐츠를 채울 때만 |
| `docs/ui/` | UI 시안 HTML (PC 1280×720) | 화면을 만들 때. 모바일은 명세서 「UI와 모바일」 규칙으로 |
| `docs/old/` | 옛 사이트 소스, Firebase 내보내기 | 데이터 이전 때만, 읽기 전용 |

- 규칙이 서로 다르면 **명세서**가 이긴다. 세계관이 다르면 총람의 \*\*「원본 설정집에서 옮긴 것」\*\*이 이긴다.
- 숫자는 모두 임시다. 정의 데이터의 기준값으로만 두고 코드에 쓰지 않는다.
- 문서에 없는 결정이 필요하면 짐작하지 말고 멈춰서 묻는다.
