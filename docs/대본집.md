# 저편의 정원 대본집

Nov 11, 2026 · @나노나노

모든 장면(메인·가문·동료·의뢰·성장기)의 대본을 모으는 곳. 형식은 아래 「대본 형식」을 따르고, 사이트는 이 글을 그대로 읽어 비주얼노벨 장면으로 보여준다. 규칙은 [시스템 명세서](https://claude.ai/artifact/LtLkcURQqntEULvZGhgCNc)의 「퀘스트·장면·구역 대화」를 따른다.

## 대본 형식

**머리** (장면마다 맨 위)

```
# 장면: 장면 ID
배경: 배경 이름
음악: 곡 이름 (없으면 생략)
```

**대사**

- `이름(표정): 대사` — 표정은 기본·웃음·화남·놀람. 일러스트가 없으면 회색 실루엣.
- `서술: 글` — 이름표 없이 대사창에 나오는 글.
- `{나}`는 플레이어 캐릭터 이름, `{소꿉친구}`처럼 중괄호는 그 캐릭터의 값으로 바뀐다.
- 글씨 연출은 `〔빨강〕…〔/〕`, `〔작게〕…〔/〕`, `〔흐리게〕…〔/〕`, `〔떨림〕…〔/〕`.

**연출** (대괄호 한 줄)

| 명령 | 뜻 |
| --- | --- |
| `[등장 이름 자리 표정]` | 자리는 왼쪽·가운데·오른쪽 |
| `[퇴장 이름]` |  |
| `[표정 이름 표정]` |  |
| `[배경 이름]` | 배경 바꾸기 |
| `[흔들림 약/중/강]` | 화면 흔들림 |
| `[효과음 이름]` |  |
| `[컷인 그림]` | 한 장짜리 그림 |
| `[암전]`, `[밝아짐]` |  |

**선택지와 갈래**

```
> 선택
  - 보이는 말 → 갈래이름
  - 보이는 말 → 갈래이름 ?조건
@갈래이름
(이 갈래의 대사들)
[합류 갈래이름]
```

- `?조건`이 붙은 선택지는 조건을 채울 때만 보인다(예: `?표시:다섯 날의 아이`, `?학식 60`, `?재능:지워지지 않는 잉크`).
- `[만약 조건]` … `[아니면]` … `[만약 끝]`으로 대사를 나눌 수 있다.

**결과** (장면이 끝날 때 한 번에 적용, 중간에 닫으면 아무것도 적용 안 됨)

| 명령 | 뜻 |
| --- | --- |
| `[표시 키]` | 기억 표시·이야기 표시 남기기 |
| `[친밀도 이름 +5]` |  |
| `[단서 ID]` | 단서 수첩 |
| `[주기 물건 수량]` | 「주고받기」로 지급 |
| `[퀘스트 ID 진행]` |  |
| `[끝]` | 장면 끝 |

## 쓸 순서

1. 들어가기: 「새 책장」(기존 플레이어), 「도서관에서 깨어남」(새 플레이어)
2. 1장 메인 의뢰 9개
3. 가문 퀘스트 1막 8개
4. 지역 성장기 16곳 × 5장면
5. 1장 곁가지 의뢰 10개, 이야기 동료 20단계
6. 반복 의뢰 대사 틀, 월보 514\~517년

## 「새 책장」 (기존 플레이어 도입, 견본)

```
# 장면: intro_new_shelf
배경: 도서관_홀_밤
음악: 책장의_숨

[암전]
서술: 종이 냄새가 먼저 돌아왔다.
서술: 그다음은 촛불, 그다음은 멀리서 책장이 삐걱이는 소리.
[밝아짐]
[등장 사서 가운데 기본]
사서(기본): 깨셨군요, {나}.
사서(기본): 잠시 소란이 있었어요. 책장이 새로 정리되었거든요.
서술: 둘러보니 늘 있던 서가가 한 칸씩 자리를 옮겨 서 있다.
서술: 빈자리는 없다. 다만 모든 것이 조금씩 다른 곳에 있다.

> 선택
  - 무슨 소란이었는데요? → 소란
  - 제 책은요? → 책
  - (말없이 서가를 둘러본다) → 침묵

@소란
사서(웃음): 책들은 가끔 이래요. 자기 자리가 마음에 들지 않으면.
사서(기본): 걱정 마세요. 잃어버린 건 없어요. 조금 무거워졌을 뿐이죠.
[합류 책]

@침묵
서술: 가장 안쪽, 촛불이 닿지 않는 칸에 책 한 권이 비스듬히 기대어 있다.
서술: 등에 적힌 이름은 당신의 것이다.
[합류 책]

@책
사서(기본): 여기 있어요. 당신이 지금까지 살아온 날들.
[효과음 책장_넘김]
[일생 요약]
사서(기본): 다 읽으셨으면 덮어도 돼요. 이 책은 아직 끝나지 않았으니까요.

[만약 표시:가문_퀘스트_있음]
사서(기본): 그리고 하나 더.
사서(기본): 당신의 이름 아래에, 아직 쓰이지 않은 장이 하나 있더군요.
서술: 책의 마지막 장은 비어 있다. 맨 위에 한 줄만 희미하게.
서술: 〔흐리게〕{가문_퀘스트_이름}〔/〕
[만약 끝]

사서(기본): 세상은 그대로예요. 다만 시간이 조금 흘렀죠.
사서(기본): 지금은 성력 {연도}년, {달}의 달.
[퇴장 사서]
서술: 문이 열린다. 바깥은 {지역}의 공기다.

[표시 새_책장을_봄]
[퀘스트 가문_1막 진행]
[끝]
```

`[일생 요약]`은 데이터 이전 때 만든 지난 삶 요약을 책장 넘기기 화면으로 끼워 넣는 특별 명령이다.

## 「도서관에서 깨어남」 (새 플레이어 도입)

```
# 장면: intro_awaken
배경: 도서관_홀_밤
음악: 책장의_숨

[암전]
서술: 아무것도 없다.
서술: 이름도, 기억도, 몸도.
서술: 다만 어딘가에서 종이를 넘기는 소리가 들린다.
[밝아짐]
서술: 끝이 보이지 않는 서가. 천장까지 닿은 책들 사이로 촛불이 흔들린다.
서술: 당신은 그 한가운데, 열람대 앞의 빈 의자에 앉아 있다.
[등장 사서 가운데 기본]
사서(기본): 아, 오셨군요.
사서(기본): 놀라지 않으셔도 돼요. 여기 오는 분들은 다들 처음엔 그 얼굴을 하세요.

> 선택
  - 여기가 어디죠? → 어디
  - 당신은 누구죠? → 누구
  - …제가 누구죠? → 나

@어디
사서(기본): 도서관이에요. 세계수의 그늘 아래, 모든 이야기가 꽂히는 곳.
사서(웃음): 지도에는 없어요. 찾아서 오는 곳이 아니라, 때가 되면 오게 되는 곳이라서요.
[합류 이방인]

@누구
사서(기본): 저는 이곳을 지키는 사람이에요.
사서(기본): 이름은… 글쎄요. 너무 오래 불리지 않아서 잊어버렸어요.
사서(웃음): 그냥 사서라고 불러주세요. 다들 그래요.
[합류 이방인]

@나
사서(기본): 그건 아직 아무도 몰라요. 당신도요.
사서(기본): 괜찮아요. 그걸 알아가는 게 이 다음의 일이니까요.
[합류 이방인]

@이방인
사서(기본): 당신 같은 분을 저희는 이방인이라고 불러요.
사서(기본): 저 바깥, 세계수가 내려다보는 땅에서 아직 태어나지 않은 사람.
서술: 사서가 열람대 위에 얇은 카드 한 장을 내려놓는다. 이름 칸이 비어 있다.
사서(기본): 열람증이에요. 여기 계시는 동안은 이게 당신이에요.

사서(기본): 서두르실 필요는 없어요. 책장을 둘러보셔도 좋고요.
사서(기본): 일 층에는 저 바깥 세상의 이야기가 있어요. 사람들이 무엇을 믿고, 어떻게 셈하고, 어디로 길을 내는지.
서술: 가까운 서가에서 낡은 책등 몇 개가 눈에 들어온다. 「황실성전」, 「대륙지리학개론」, 「아이들을 위한 세계수 이야기」.

> 선택
  - 책을 조금 읽어보고 싶어요 → 열람
  - 바로 나가고 싶어요 → 청하기

@열람
사서(웃음): 그럼요. 다 읽고 오시면 불러주세요. 저는 여기 있을게요.
[화면 열람실]
사서(기본): …어떠셨어요. 조금은 그 세상 냄새가 나죠.
[합류 청하기]

@청하기
사서(기본): 그럼 몸을 청하셔야 해요.
사서(기본): 이름 하나, 그리고 당신이 가지고 태어나고 싶은 것 셋.
사서(기본): 다만 어디서 태어날지는 고를 수 없어요. 그건 세계가 정하는 일이라서요.
서술: 사서가 깃펜을 내민다. 잉크가 촛불에 검게 빛난다.
[화면 캐릭터_생성]

사서(기본): {나}.
서술: 사서가 열람증에 그 이름을 천천히 옮겨 적는다.
사서(웃음): 좋은 이름이에요. 저 바깥에서도 누군가 그렇게 불러줄 거예요.
사서(기본): 이제 조금만 기다려 주세요. 당신이 들어갈 자리를 세계가 찾는 동안.
[대기 GM_승인]

사서(기본): 자리가 났어요.
사서(기본): 문을 나서면 처음부터 시작이에요. 첫 울음부터, 첫걸음부터.
사서(기본): 그리고 언젠가, 아주 오랜 뒤에 다시 여기로 돌아오시면
사서(웃음): 그때는 당신의 책을 제가 꽂아드릴게요.
[퇴장 사서]
[효과음 문_열림]
[암전]
서술: 빛이 쏟아진다.

[표시 도서관에서_깨어남]
[주기 도서관_열람증 1]
[끝]
```

이 장면에서 새로 쓰인 특별 명령:

- `[화면 이름]`: 장면을 잠시 멈추고 그 화면(열람실, 캐릭터 생성 등)을 연다. 닫으면 다음 줄부터 이어진다.
- `[대기 GM_승인]`: GM이 승인할 때까지 이 줄에서 멈춘다. 그동안 도서관 홈에 머물 수 있고, 승인되면 알림과 함께 이어진다.
- 이 장면이 끝나면 성장기(태어남)로 넘어간다.

## 지역 안내 NPC 첫 의뢰

지역마다 안내 NPC가 첫 의뢰를 주고, 그 의뢰로 시스템 하나를 익힌다. 15세에 세계에 나오면 **고향의 첫 의뢰**가 퀘스트 창에 들어오고, 다른 지역에 처음 가면 그곳 의뢰를 받을 수 있다. 의뢰마다 **시작 장면**과 **완료 장면** 둘.

- `[안내 이름]`: 그 시스템의 짧은 설명 카드를 띄운다(한 번 본 카드는 다시 안 뜸, 설정에서 다시 보기).
- `[퀘스트 ID 시작]`: 퀘스트 창에 의뢰가 들어간다. 목표는 의뢰 정의에 적는다.

| 지역 | 안내 NPC | 의뢰 | 익히는 것 |
| --- | --- | --- | --- |
| 황도 | 마르타 엘른 (여관 여주인) | 바쁜 여관의 하루 | 달 행동(일하기), 구역 옮기기 |
| 북쪽 팔 | 오토 뷜러 (보급관 하사) | 보급 창고의 쥐 | 전투 기초(판정 바, 막기) |
| 동쪽 팔 | 레니 카스 (환전소 직원) | 셈이 맞지 않는 돈 | 사고팔기, 화폐, 시세 |
| 서쪽 팔 | 브람 사제 | 대신 쓰는 편지 | 의뢰 게시판, 퀘스트 창, 편지 |
| 남쪽 팔 | 이셀 (구호소 수녀·약초사) | 비 오기 전의 약초 | 채집, 신선도 |
| 스카르하임 | 시그리드 | 회관의 내기 | 진형, 동료 |
| 카른브룸 | 토르벤 (견습 대장장이) | 식어가는 쇠 | 제작, 강화 |
| 뮈르가스트 | 에다 (영매) | 등불 셋 | 장면 선택, 단서 수첩, 장소 사이 이동 |
| 베르가나 | 노엘 (길드 서기·아이리스 딜러) | 같은 물건, 다른 값 | 무역, 장터 게시판 |
| 로베인 | 오딜 할멈 (농부) | 씨 뿌리는 날 | 정원, 농사 미니게임 |
| 소프레고 | 피코 (시장 짐꾼) | 밤이 오기 전에 | 거리 위험 전투, 피로 |
| 테산가 | 아마니 (교역 포구 안내인) | 첫 사냥 | 사냥, 도감 |
| 코르사렌 | 벤 (뱃사람) | 작은 배 한 척 | 이동, 항해 |
| 브라켄 | 카스파 (용병 길드 접수원) | 하루짜리 계약 | 용병 동료, 투기장 |
| 라이젠부르크 | 율리아 (서약의 전당 시종) | 첫 서약 | 결투, 받아치기 |
| 아스텔라 | 세르 (별 신전의 노래꾼) | 별을 세는 밤 | 보조 기술(노래·기도) |

### 황도 · 마르타 엘른 「바쁜 여관의 하루」

```
# 장면: guide_hwangdo_start
배경: 황도_여관
[등장 마르타 가운데 웃음]
마르타(웃음): 거기, 문간에 서 있지 말고 들어와요. 바람 들어와.
마르타(기본): 일 찾는 얼굴이네. 맞죠? 이 시간에 여관 문 여는 사람은 손님 아니면 일꾼이거든.
마르타(기본): 마침 잘 왔어. 순례 철이라 손이 열 개라도 모자라요.
> 선택
  - 할게요. 뭐부터 하면 돼요? → 수락
  - 품삯은 얼마나 줘요? → 품삯
@품삯
마르타(웃음): 하루 성은 한 닢. 밥은 내가 먹이고. 황도에서 이만한 데 없어요.
[합류 수락]
@수락
마르타(기본): 이 달 안에 여기서 두 번만 일해 줘요. 장작 패고, 침상 털고, 그거면 돼요.
마르타(기본): 아, 장터에서 빵도 좀 받아 오고. 장터는 문 나가서 바로예요.
[안내 달_행동]
[안내 구역_옮기기]
[퀘스트 guide_hwangdo 시작]
[끝]
```

```
# 장면: guide_hwangdo_done
배경: 황도_여관

마르타(기본): 다음 달에도 바쁘면 불러도 되죠? 여기, 약속한 거.
[주기 잎전 100]
[친밀도 마르타 +10]
[끝]
```

#### 「현현회의 사도」 (선택 사건)

깊은 늪 쪽 던전 방에서 낮은 확률로 마주친다. 한 사람(파티)에게 한 번.

```

배경: 깊은늪_가라앉은_돌무더기

서술: 누군가 맨손으로 그것을 파내고 있다. 손가락 끝이 다 갈라져 피가 맺혀 있다.
[등장 사도 가운데 웃음]
사도(웃음): 쉿. 빛이 깨어나는 중이에요.
사도(기본): 저는 읽는 손이라 불려요. 이건 사자가 인간에게 건넨 빛의 한 조각. 제국은 훔친 거라 하지만, 우리는 받은 거라고 믿죠.

> 선택
  - 그만둬요. 그건 위험해요. → 막기
  - 반을 받는다. → 받기
  - (모른 척 지나간다) → 지나감
@막기
사도(기본): 그렇군요. 당신은 아직 빛을 무서워하는 쪽이네요.
[전투 ch1s_apostle → 이김:막음 짐:놓침]
@막음
서술: 사도는 피 묻은 손으로 금속 조각을 안고 안개 속으로 사라졌다. 남은 건 갈라진 손톱 조각 하나.

[표시 현현회_사도를_막음]

@놓침

[합류 끝]
@받기
서술: 손바닥만 한 금속 조각이 손에 놓인다. 차갑지 않다. 오히려, 조금 따뜻하다.

[표시 현현회와_나눔]
[안내 유물_접촉]
[합류 끝]
@지나감
[합류 끝]
```


## 지역 성장기

지역마다 다섯 장면(유년·아이·소년기·청소년·열다섯). 소꿉친구는 생성 씨앗으로 이름과 성별이 정해지고 `{친구}`로 쓴다. 집안에 따라 갈리는 줄은 `[만약 집안:농가]`처럼.

성장기 전용 결과 명령:

- `[숙련 기술 +n]`: 숙련도(성장기라 1장 이후의 곡선과 상관없이 그대로 더함, 한 기술 최대 20)
- `[능력치 이름 ±n]`
- `[인물 이름 관계]`: 인물 목록에 더함
- `[시작직업 직업 단계]`: 열다섯 장면에서만. 고르지 않으면 날품

## 반복 의뢰 대사 틀

반복 의뢰의 장면은 조각을 이어 붙여 만든다. 의뢰인마다 **말투** 하나가 정해져 있고, 의뢰 **종류**의 본문과 **지역** 작별 인사가 붙는다. 같은 조각 안에서는 씨앗으로 하나를 고른다.

**조립 순서**

- 받을 때: 말투의 인사 → 종류의 시작 본문 → 말투의 맺음 → 지역 작별 인사
- 완료할 때: 종류의 완료 본문 → 말투의 감사 → (후속 의뢰가 있으면) 후속 연결
- 실패할 때: 말투의 실패

**빈칸**: `{의뢰인}` `{대상}` `{수량}` `{장소}` `{지역}` `{기한}` `{보상}` `{물건}` `{받는이}`

## 월보

하루(세계의 한 달)에 한 호. 짧고 간단하게, 핵심만.

**한 호의 모양**: 머리기사 한두 문장 / 짧은 소식 셋(한 줄씩) / 장터 한 줄 / 소문 한 줄. 날짜(성력 몇 년, 무슨 꽃의 달)는 자동으로 붙는다.

**누가 쓰나**: 대부분은 아래 **자동 기사 틀**로 하루 계산 때 만든다. 손으로 쓰는 것은 **스토리 단계가 바뀌는 호**뿐이고, 그날은 손으로 쓴 머리기사가 자동 머리기사 자리를 대신한다. 짧은 소식·장터·소문 칸은 자동으로 채운다.

### 1장 손으로 쓰는 호

**① 새 책장** (새 사이트 첫날)

- 머리기사: 세계수 도서관의 책장이 새로 정리되었다. 이방인들이 다시 세상으로 돌아오고 있다.
- 소문: 도서관 사서가 웃는 것을 보았다는 사람이 있다.

**② 동쪽 늪의 이상한 병** (0단계)

- 머리기사: 뮈르가스트 동쪽 늪가 마을에서 열도 기침도 없이 사람이 바래 가는 병이 번진다. 약초상들은 처음 보는 병이라고 입을 모은다.
- 소문: 오스트렌의 영매 하나가 동쪽 안개가 "숨을 참고 있다"고 했다.

**③ 네벨하임의 발표** (0단계)

- 머리기사: 네벨하임 영매 연맹이 동쪽 안개를 "조상의 노여움"으로 규정했다. 연맹은 달래는 의식을 늘리라고 권했다.
- 소문: 연맹 안에 반대한 영매가 한 명 있었다고 한다. 변두리에 사는 사람이라고.

**④ 변방의 고아원** (0단계)

- 머리기사: 중앙대륙 변방의 한 고아원에서 원장이 갑자기 세상을 떠났다. 원인은 밝혀지지 않았다.
- 소문: 그 뒤로 한 소년이 보이지 않는다. 그 아이를 거둔 집마다 초상이 났었다는 말이 있다.

**⑤ 돌아오지 않는 사냥꾼들** (1단계 시작)

- 머리기사: 오스트렌의 늪 사냥꾼 셋이 동쪽 늪에서 열흘째 돌아오지 않는다. 사냥꾼 회관이 수색을 의뢰했다.
- 짧은 소식: 동쪽 길이 안개로 막혀 베스트하펜 약값이 세 배로 올랐다.
- 소문: 늪에서 죽은 사람의 목소리가 들린다고 한다.

**⑥ 삼켜진 등불** (가을, 안개맞이 축제)

- 머리기사: 그로스모어의 안개맞이 축제에서 동쪽으로 띄운 등불들이 한꺼번에 사라졌다. 축제 담당은 "올해는 동쪽으로 띄우지 말라"고 당부했다.
- 소문: 리히트펜 등불도 동쪽 안개에서는 꺼진다고 한다.

**⑦ 오스트렌의 사냥꾼 두목** (볼프람 정예전 결과)

- (생포) 머리기사: 오스트렌의 사냥꾼 두목 볼프람이 안개 속에서 붙잡혔다. 그는 살아 있다. 영매 에다는 "아직 돌아올 수 있다"고 했다.
- (쓰러짐) 머리기사: 오스트렌이 사냥꾼 두목 볼프람을 잃었다. 마을은 그를 안개로 보냈다. 앓아누운 딸 하나가 남았다.

**⑧ 늪의 주인이 깨어나다** (레이드 개방)

- 머리기사: 뮈르가스트의 모든 등불이 같은 밤에 흔들렸다. 동쪽 늪에서 안개가 일어섰다. 영매들은 이제 그것을 "안개의 주인"이라 부른다.
- 짧은 소식: 이방인들이 깊은 늪으로 모여든다. 해골 얼굴의 수도사가 그들 곁에서 책을 읽는다고 한다.

**⑨ 토벌** (레이드 결과)

- (성공) 머리기사: 안개의 주인이 쓰러졌다. 그것을 쓰러뜨린 것은 이방인들이었다. 안개가 걷힌 늪 위로 처음 보는 하늘이 열렸다.
- (실패) 머리기사: 레이드가 닫힌 다음 날 새벽, 늪 깊은 곳에서 붉은 빛이 번쩍였다. 해가 떴을 때 안개는 없었다. 오스트렌 사람들은 그날을 "붉은 새벽"이라 부른다.
- 소문(실패일 때만): 붉은 꽃을 꽂은 넓은 모자의 아이를 보았다는 사람이 있다.

**⑩ 안개가 걷힌 뒤** (2장으로 넘어가는 호)

- 머리기사: 동쪽 늪의 쇠약병이 물러가고 있다. 베스트하펜의 약값도 제자리를 찾았다.
- 짧은 소식: 카른브룸 공방들이 외지인 몇에게 처음으로 초대장을 보냈다.
- 소문: 카른브룸의 망치 소리가 백 년째 같은 박자라고 한다.
