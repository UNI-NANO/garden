# 저편의 정원 시스템 명세서

Nov 10, 2026 · @나노나노

## 이 문서 읽는 법

[사이트 재제작 기획서](https://claude.ai/artifact/PQkWiJzT1smaUwfkn93Qw6)가 "무엇을, 왜"라면, 이 문서는 **각 시스템이 정확히 어떻게 돌아가는지**다. Claude Code는 코드를 짤 때 이 문서를 그대로 따른다. 둘이 다르면 규칙은 이 문서가, 의도는 기획서가 우선이고, 다른 점은 바로 알린다.

**시스템마다 같은 여덟 칸**

1. **목적**: 한 줄
2. **저장하는 값**: 이름, 범위, 처음 값
3. **시작되는 때**: 플레이어 행동 / 하루 계산 / GM
4. **규칙**: 순서대로 한 단계씩
5. **결과**: 무엇이 바뀌는지
6. **경계 상황**: 값이 0이거나 최대일 때, 접속이 끊길 때, 두 사람이 동시에 할 때, 같은 요청이 두 번 올 때, 하루가 넘어가는 순간
7. **연결**: 영향을 주고받는 시스템
8. **표시**: 확정 / 숫자만 임시 / 미정

**공통 원칙**

- 숫자는 코드에 직접 쓰지 않고 정의 데이터의 기준값에서 읽는다. 표시가 "숫자만 임시"인 값은 시험 운영 뒤에 바뀔 수 있다.
- 시각은 모두 UTC로 저장하고, 화면에는 한국 시간으로 보여준다.
- 플레이어의 요청에는 모두 **요청 ID**가 붙고, 같은 ID가 두 번 오면 두 번째는 무시한다.
- 저장되는 모든 값은 정해진 모양(스키마)과 범위를 통과해야만 저장된다.

## 용어집

한 단어는 한 뜻만 가진다. 코드의 이름도 이 표를 따른다.

**시간**

| 말 | 뜻 |
| --- | --- |
| 하루 | **한국 시간 자정(UTC 15:00)부터 다음 날 자정**까지. 세계 계산이 이때 한 번 돈다 |
| 달 | 게임 속 한 달. **하루 하나 = 달 하나** |
| 주 | 한 달을 넷으로 나눈 단위. 달 행동의 단위로만 쓴다 |
| 해 | 열한 달 + 이름 없는 다섯 날. 이름 없는 다섯 날은 **하루 하나**를 쓴다. 그래서 해 하나 = 하루 12개 |
| 턴 | 전투 안의 한 바퀴. 아군 차례와 적 차례를 합친 것 |

**행동과 자원**

| 말 | 뜻 |
| --- | --- |
| 주 행동 | 성장 행동 하나(배우기, 일하기, 사람 만나기, 쉬기 등). 한 달에 4개 |
| 작은 행동 | 가벼운 성장 행동. 한 달에 2개 |
| 저장 행동 | 쓰지 못하고 넘어간 주 행동. 최대 4개 |
| 기력 | **전투 안의 자원만** 가리킨다. 기술을 쓰면 줄고 턴마다 찬다 |
| 피로 | 상시 콘텐츠 보상이 줄어드는 정도. 하루마다 초기화. (기획서의 "오늘의 기력"을 이 이름으로 바꾼다. 전투의 기력과 헷갈리지 않게) |
| 콘텐츠 분야 | 피로를 따로 세는 상시 콘텐츠 묶음: 탐험, 사냥·채집·낚시, 훈련장·투기장, 반복 레이드, 의뢰. (기획서의 콘텐츠 "갈래"를 이 이름으로 바꾼다. 나무의 갈래와 헷갈리지 않게) |

**전투**

| 말 | 뜻 |
| --- | --- |
| 타 | 기술 하나 안의 한 번의 공격. 타마다 판정 바를 한 번 누른다 |
| 판정 | 타이밍 바를 누른 결과: 빗나감 / 보통 / 좋음 / 완벽 |
| 위력 | 판정 배율까지 곱한 한 타의 힘 |
| 피해 | 위력에서 저항과 방어를 거쳐 실제로 깎이는 체력 |
| 합 | 내 기술을 적의 의도 공격에 맞붙이는 것 |
| 의도 | 적이 이번 턴에 할 행동. 턴 시작에 공개 |
| 흐트러짐 | 적의 자세 게이지. 0이 되면 무력화 |
| 아군 | 전투에 들어간 플레이어와 동료 전부 |

**사람과 장소**

| 말 | 뜻 |
| --- | --- |
| 계정 | 로그인하는 사람 |
| 캐릭터 | 계정이 가진 이방인 하나 |
| 파티 | 함께 움직이는 캐릭터들(동료 제외) |
| 지역 | 지도 위의 큰 칸(황도, 북쪽 팔, 베르가나 등) |
| 구역 | 지역 안의 장소(장터 광장, 여관 등). 대화와 만남의 단위 |
| 퀘스트 | 모든 임무의 이름. 메인 / 가문 / 의뢰 / 동료로 나뉜다 |
| 의뢰 | 게시판에서 받는 퀘스트 |
| 탐험 | 던전에 한 번 들어가서 나올 때까지 |

**데이터**

| 말 | 뜻 |
| --- | --- |
| 정의 데이터 | GM만 고치는 카드들(기술, 적, 아이템 등) |
| 세계 상태 | 모두가 함께 보는 값(달력, 시장, 스토리 단계 등) |
| 캐릭터 상태 | 한 캐릭터의 저장 데이터 |
| 진행 중 임시 | 전투·탐험·파티처럼 끝나면 지우는 데이터 |
| 장부 | 돈·물건·점수가 바뀔 때마다 남는 한 줄 기록 |

## 세계 시계와 달 행동

**1. 목적**: 모두가 같은 달에 살게 하고, 성장 행동을 하루에 묶는다.

**2. 저장하는 값**

| 어디 | 값 | 범위 · 처음 값 |
| --- | --- | --- |
| 세계 | 연도(성력) | 514부터 |
| 세계 | 달 순번 | 0\~11. 0\~10은 열한 달, 11은 이름 없는 다섯 날 |
| 세계 | 마지막으로 처리한 날짜 키 | 현실 날짜(예: 2026-12-01) |
| 세계 | 계산 중 표시 | 참/거짓 |
| 캐릭터 | 이번 달 키 | 연도 + 달 순번 |
| 캐릭터 | 남은 주 행동 | 0\~4, 달이 바뀌면 4 |
| 캐릭터 | 남은 작은 행동 | 0\~2, 달이 바뀌면 2 |
| 캐릭터 | 저장 행동 | 0\~4 |
| 캐릭터 | 이번 달 경력 | 0\~2 |
| 캐릭터 | 이번 달 배우기 횟수 | 기술별 숫자 |
| 캐릭터 | 이번 달 전투 숙련 오름 | 기술별 0\~1 |
| 캐릭터 | 오늘의 피로 | 콘텐츠 분야별 횟수 |

**3. 시작되는 때**: 하루 경계 시각에 GitHub Actions의 하루 계산. 플레이어가 주 행동·작은 행동을 쓸 때.

**4. 규칙**

*하루 계산 (세계)*

1. 계산 중 표시를 켠다. 이 동안 화면은 "세계의 시간이 흐르는 중"을 띄우고 달 행동 요청을 받지 않는다.
2. 마지막으로 처리한 날짜 키부터 오늘까지 **빠진 날을 하나씩 차례로** 처리한다(Actions가 하루 이상 멈췄던 경우를 위해).
3. 하루마다 달 순번 +1. 10 다음은 11(이름 없는 다섯 날), 11 다음은 다음 해 0.
4. 달 순번이 11이 되는 날: 한 해 정리(모든 캐릭터 나이 +1, 한 해 세금, 연간 기록 정리).
5. 모든 캐릭터에 대해 아래 *달 넘어감*을 처리한다.
6. 같은 날 다른 하루 계산들(시장, 레이드 교대, 월보)을 돈다.
7. 날짜 키를 오늘로 쓰고 계산 중 표시를 끈다.

*달 넘어감 (캐릭터)*

1. 남은 주 행동을 저장 행동에 더한다. 4를 넘는 몫은 **자동 처리**: 일터가 있으면 일하기, 없으면 쉬기, 하나씩 번갈아(일하기부터).
2. 남은 작은 행동은 버린다.
3. 남은 주 행동 4, 남은 작은 행동 2, 이번 달 경력·배우기 횟수·전투 숙련 오름·오늘의 피로를 0으로.
4. 이번 달 키를 새 달로.

*행동 쓰기 (플레이어)*

1. 요청에 이번 달 키가 붙어 온다. 세계의 달과 다르면 거절하고 화면을 새로고침시킨다.
2. **저장 행동부터** 쓰고, 다 쓰면 이번 달 몫을 쓴다(오래된 것부터).
3. 배우기: 같은 기술 이번 달 세 번째부터 감점(세 번째 −10, 네 번째 −20처럼 쌓임). 일하기: 일터 안에서만, 이번 달 경력 2를 넘으면 경력은 안 오르고 돈만.
4. 결과는 「주고받기 공통 규칙」으로 저장한다.

**5. 결과**: 달력이 넘어가고, 모든 캐릭터의 행동 수가 새로 찬다.

**6. 경계 상황**

- Actions가 실패하거나 늦으면: 다음 실행이 빠진 날을 차례로 메운다. 같은 날짜 키는 두 번 처리되지 않는다.
- 계산 중에 들어온 행동 요청: 거절, 계산이 끝나면 다시.
- 달이 바뀌기 직전에 보낸 요청이 바뀐 뒤 도착: 이번 달 키가 달라서 거절.
- 한 달 중간에 새로 태어난 캐릭터: 그 달 몫을 온전히 받는다.
- 며칠 안 들어온 캐릭터: 매일 달 넘어감이 처리되어 저장 행동 4 + 자동 처리로 쌓인다.
- 이름 없는 다섯 날(달 순번 11): **달 행동이 없다.** 대신 한 해 정리 장면. 장터·상점·성당 닫힘, 던전·사냥·낚시·이동은 가능. (숫자만 임시)

**7. 연결**: 숙련도, 경제(하루 계산), 레이드 교대, 월보, 피로, 나이·성장기.

**8. 표시**: 확정. 단 **하루 경계 시각은 한국 시간 자정(UTC 15:00)**, 이름 없는 다섯 날의 닫히는 범위는 숫자만 임시.

## 주고받기 공통 규칙

**1. 목적**: 돈·물건·점수가 복사되거나 사라지지 않게 한다. 모든 시스템이 이 규칙으로만 값을 바꾼다.

**2. 저장하는 값**

| 어디 | 값 | 비고 |
| --- | --- | --- |
| 캐릭터 | 지갑 | 잎전 단위 정수, 0 이상 (베아트·성은은 화면 표시만) |
| 캐릭터 | 가방 | 묶음 물건(재료 등: 물건 ID → 수량, 신선도)과 낱개 물건(장비·유일물: 고유 ID마다 하나) |
| 캐릭터 | 받은 보상 목록 | 보상 출처 ID (같은 보상 두 번 방지) |
| 캐릭터 | 우편함 | 가방이 넘쳐 못 받은 물건, 7일 보관 |
| 세계 | 장부 | 바뀐 것 한 줄씩: 언제, 누구, 무엇이, 얼마나, 왜(출처), 요청 ID |
| 진행 중 임시 | 거래 | 두 사람 사이 거래 하나의 상태 |

**3. 시작되는 때**: 보상 지급, 구매·판매, 제작, 강화, 거래, 세금, 생활비, 계약금 등 값이 바뀌는 모든 때.

**4. 규칙**

*한 번의 변경*

1. 요청 ID를 확인한다. 이미 처리한 ID면 그때 결과를 그대로 돌려주고 끝.
2. 바뀔 값을 모두 미리 계산한다(지갑, 가방, 받은 보상 목록, 장부 한 줄).
3. 하나라도 규칙을 어기면(지갑이 0 아래, 가방 칸 초과, 이미 받은 보상, 없는 물건) **전부 취소**하고 이유를 알린다.
4. 통과하면 모든 값을 **한 번에** 쓴다(여러 경로를 한꺼번에 쓰는 원자적 쓰기). 반쯤만 쓰이는 일은 없다.

*보상*

- 보상마다 출처 ID(예: 「의뢰 X 완료」, 「레이드 1회차 기여 보상」)가 있고, 받은 보상 목록에 이미 있으면 다시 주지 않는다.
- 가방이 넘치면 넘친 몫은 우편함으로. 7일 안에 꺼내지 않으면 사라지고, 사라지기 하루 전에 알림.

*플레이어끼리 거래*

1. 같은 구역에서 거래를 연다. 각자 올릴 물건·돈을 고른다.
2. 올린 것은 그 순간 **맡겨둔 상태**가 되어 다른 곳에 쓸 수 없다.
3. 둘 다 "확정"을 누르면 한 번에 서로 바뀐다. 한쪽이라도 내용을 바꾸면 둘 다의 확정이 풀린다.
4. 한쪽이 취소하거나, 구역을 떠나거나, 10분 동안 아무 일이 없으면 거래가 닫히고 맡긴 것은 그대로 돌아간다.

*검증* (서버 함수 없이 무료로)

1. 화면은 결과와 함께 **결과를 만든 입력**(씨앗, 고른 기술, 타마다의 판정, 요청 ID)을 저장한다.
2. 보안 규칙이 범위 밖 값을 막는다: 지갑·수량 음수 금지, 한 번에 늘 수 있는 양의 상한, 남의 캐릭터 쓰기 금지, 세계·정의 데이터는 GM만.
3. 파티 전투는 파티원 화면이 같은 입력으로 각자 다시 계산해 결과가 같은지 확인한다.
4. 하루 계산(GitHub Actions)이 그날의 장부와 입력 기록을 같은 계산 코드로 다시 돌려 비교한다. 다르거나 비정상적으로 많이 늘어난 값은 GM 패널에 띄운다. 자동으로 되돌리지 않고 GM이 판단한다.
5. 그래서 **계산 코드는 화면과 하루 계산이 같은 파일을 함께 쓴다.**

**5. 결과**: 값이 바뀌고 장부에 한 줄이 남는다.

**6. 경계 상황**

- 같은 요청이 두 번(버튼 두 번 누름, 다시 보내기): 요청 ID로 한 번만.
- 쓰는 도중 접속이 끊김: 원자적 쓰기라 다 되거나 하나도 안 됨. 다시 들어오면 결과를 확인해 보여준다.
- 두 기기에서 같은 캐릭터로 동시에: 나중에 온 쪽이 이전 값을 기준으로 계산했으면 거절하고 새로고침.
- 거래 중 하루 계산이 시작됨: 거래는 계속 열려 있고, 생활비 같은 자동 지출은 맡겨둔 것을 건드리지 않는다.
- 돈이 모자라 생활비를 못 냄: 「거처」의 밀린 돈 규칙대로.
- 하루 계산 때 장부를 훑어, 하루에 비정상적으로 많이 늘어난 돈·물건을 GM 패널에 표시한다.

**7. 연결**: 거의 모든 시스템.

**8. 표시**: 확정. 단 **검증 방식은 아래 「검증」대로**, 우편함 7일과 거래 10분은 숫자만 임시.

## 전투

**1. 목적**: 고르는 판단과 손으로 치는 타이밍으로 이기는 턴제 전투. 운은 효과로만.

**2. 저장하는 값** (진행 중 임시, 전투가 끝나면 결과만 남기고 지움)

| 값 | 내용 |
| --- | --- |
| 전투 ID, 종류 | 일반 / 정예 / 보스 / 레이드 / 결투 |
| 씨앗 | 이 전투의 모든 무작위가 이 값에서 나온다 |
| 턴 번호, 단계 | 턴 시작 / 아군 차례 / 적 차례 / 턴 끝 |
| 아군 칸 6, 적 칸 6 | 앞줄 3 + 뒷줄 3. 칸마다 누가, 체력, 기력, 흐트러짐(적), 상태이상·버프, 쿨다운 |
| 적 의도 | 적마다 이번 턴 기술, 위력, 대상, 범위 |
| 행동 기록 | 이번 턴 각자 고른 기술과 타마다의 판정 |
| 기여 기록 | 사람마다 준 피해, 흐트러짐, 막아준 피해, 받아치기·피하기 성공 |

**3. 시작되는 때**: 의뢰·던전 방·거리 위험·레이드·결투에 들어갈 때.

**4. 규칙**

*한 턴*

1. **턴 시작**: 적마다 의도를 정해 공개한다(보스는 정해진 순서, 일반 적은 조건과 무게). 시작 때 터지는 상태이상을 처리한다.
2. **아군 차례**: 플레이어 모두가 동시에 기술을 고르고 판정 바를 친다. 실행은 **확정한 순서대로**. 동료는 플레이어가 다 끝난 뒤 성향에 따라 자동으로.
3. **적 차례**: 합으로 깨지지 않은 의도가 앞줄부터 차례로 실행된다. 대상 플레이어는 막기 / 받아치기 / 피하기(큰 공격만) 중 입력. 시간 안에 입력이 없으면 그냥 맞는다.
4. **턴 끝**: 지속 피해(출혈·독·화상), 버프·약화 남은 턴 −1, 쿨다운 −1, 기력 +2, 흐트러짐에서 회복할 적은 게이지를 다시 채운다.

*계산* (숫자는 모두 기준표의 임시값)

- **판정 칸**: 바 길이 100. 좋음 칸 폭 = 기본값 + 숙련도에 비례, 완벽 칸은 좋음 칸 가운데의 좁은 칸, 보통 칸은 좋음 칸 양옆. 바 속도는 기술마다. 효과(공포·집중·위압·침식)가 칸 폭이나 흔들림을 바꾼다.
- **한 타의 위력** = 기준표의 타 위력 × 판정 배율(빗나감 0, 보통 0.7, 좋음 1.0, 완벽 1.3) × (1 + 버프 − 약화) × 개성 보정.
- **피해** = 위력 × 저항 배율(강함 0.5 / 보통 1 / 약함 1.5) − 방어. 빗나감이면 0, 맞으면 최소 1.
- **흐트러짐 피해** = 위력 × 타입 계수(파열 1.2, 관통 1.0, 자상 0.8). 0이 되면 다음 턴 행동 불가 + 받는 피해 ×1.5, 그다음 턴 끝에 게이지가 다시 찬다.
- **합**: 내 기술의 모든 타 위력 합 vs 적 의도의 위력.
  - 내가 크면: 적 기술 취소, 내 기술은 그대로 들어가고 흐트러짐 추가.
  - 적이 크면: 내 기술 취소, 적 기술은 내 위력만큼 줄어서 들어간다.
  - 같으면: 둘 다 취소.
- **적의 위력**은 범위가 아니라 **하나의 값**으로 정해져 의도에 표시된다(도감 1단계 전엔 "???"). 적 쪽에도 굴림이 없어서 같은 판단이면 같은 결과가 나온다.
- **기력**: 최대 10, 전투 시작 때 가득. 턴 끝 +2, 막기·피하기 성공 +1. 모자라면 그 기술을 고를 수 없다.

*끝*

- **승리**: 적이 모두 쓰러지거나 생포됨. **패배**: 아군 플레이어가 모두 쓰러짐.
- **도망**: 행동 하나로 시도. 일반 전투만, 정예·보스·레이드는 불가.
- **쓰러짐**: 체력 0 → 흐트러진 상태였거나 보스 광역기면 중상, 아니면 경상(부상 규칙).
- **생포**: 적 체력이 최대의 20% 이하 + 흐트러진 상태에서 속박 효과가 들어가면 생포.
- **정산**: 승리하면 적 드롭표의 전리품, 이번 전투에서 쓴 기술 숙련도 +1(이번 달 기술마다 1까지), 도감 처치 수, 레이드면 기여 기록. 모두 「주고받기 공통 규칙」으로.

*자동 전투*

- 같은 적 조합을 한 번 이상 이겼고, 일반 전투일 때만.
- 판정은 모두 "좋음"으로 친다. 고르는 순서: 쓸 수 있는 연계를 먼저, 그다음 위력이 가장 큰 기술, 체력 30% 이하면 막기. 보상 ×0.8.

**5. 결과**: 체력·부상·전리품·숙련도·도감이 바뀌고, 전투 데이터는 지운 뒤 일생 기록에 한 줄.

**6. 경계 상황**

- **같은 입력이면 같은 결과**: 전투 계산은 씨앗과 행동 기록만으로 다시 돌렸을 때 똑같이 나와야 한다(테스트로 확인). 파티원 화면이 서로 다른 결과를 내면 오류로 기록한다.
- 파티원 한 명의 접속이 끊김: 그 사람은 다음 차례부터 자동 전투 규칙으로 움직이고, 돌아오면 다음 턴부터 직접.
- 차례 제한 시간이 지남: 아군 차례는 자동 전투 규칙으로 대신 고르고, 적 차례 입력은 그냥 맞음.
- 같은 적을 둘이 노려 앞사람이 쓰러뜨림: 뒷사람의 기술은 같은 범위의 다음 적에게, 없으면 기력을 돌려주고 취소.
- 합 대상이 그 전에 쓰러짐: 합은 사라지고 기술은 그냥 공격으로.
- 체력이 최대를 넘는 회복, 0 아래로 가는 피해: 각각 최대와 0에서 멈춘다.
- 탐험 중 전투에서 브라우저를 닫음: 전투는 그 턴에 멈춰 저장되고, 다시 들어오면 이어서.

**7. 연결**: 기술 나무(기준표), 동료·부상, 던전, 레이드(기여도), 도감, 숙련도, 주고받기, 유일물(조건 기록).

**8. 표시**: 확정. 단 **아군 차례 제한 시간 60초, 적 차례의 막기 입력은 10초(숫자만 임시)**, 계산식의 숫자는 모두 임시. 기획서의 "적 위력 범위"는 이 문서에서 "하나의 값"으로 바꾼다.

## 던전

**1. 목적**: 안개 낀 격자를 밝혀가며, 더 갈지 돌아갈지를 고민하는 탐험.

**2. 저장하는 값** (진행 중 임시)

| 값 | 내용 |
| --- | --- |
| 탐험 ID, 던전 ID |  |
| 파티 | 참가 캐릭터와 동료, 파티장 |
| 층 번호, 씨앗 | 층 지도는 씨앗에서 만들어져 언제 다시 불러와도 같다 |
| 방 격자 | 방마다 종류, 문 방향, 밝혀짐 / 들어감 / 클리어 |
| 현재 방 |  |
| 열쇠, 폭약 | 0 이상 |
| 압박 수치 | 방을 옮길 때마다 +1. 던전 장치가 이 값을 본다 |
| 쉼터 사용 | 층마다 한 번 |
| 얻은 것 | 이번 탐험에서 얻은 물건·돈 목록 (아직 가방에 들어간 게 아님) |

**3. 시작되는 때**: 던전 입구에서 들어가기를 누를 때. 이때 탐험 분야 피로 +1.

**4. 규칙**

*층 만들기*

1. 방 수는 층마다 8\~15(던전과 깊이에 따라).
2. 반드시 있는 방: 시작방 1, 쉼터방 1, 끝방 1(마지막 층은 보스방, 나머지는 정예방). 있을 수 있는 방: 보물방 0\~1, 비밀방 0\~1, 상점방 0\~1. 나머지는 전투·사건·함정.
3. **시작방에서 끝방과 쉼터방까지는 열쇠·폭약 없이 반드시 갈 수 있다.** 보물방이 있으면 그 층 안에서 열쇠를 하나 이상 얻을 수 있게 둔다. 비밀방은 일반 방 벽에 붙어 있고, 금 간 벽 표시는 눈치가 기준 이상이면 보인다.
4. 지역 이야기와 이어진 방(유일물·단서 방)은 정해진 층에 정해진 확률로 섞인다.

*움직이기*

1. 이동은 **파티장**이 고른다. 파티 전체가 같은 방으로.
2. 새 방에 들어가면 그 방과 옆방 윤곽이 밝혀지고 압박 수치 +1.
3. 전투방은 들어가는 순간 문이 닫히고 전투가 시작된다. 이기면 클리어, 이후 그 방은 지나다닐 수만 있다.
4. 보물방·잠긴 상자는 열쇠 1, 비밀방·금 간 벽은 폭약 1 또는 둔기 「벽 부수기」.
5. 정예방을 클리어하면 다음 층 계단이 열린다. 내려가면 새 층을 만들고 압박 수치는 0으로.

*쉼터 (층마다 한 번)*

- 쉬기(체력·기력 일부 회복) / 손질(수리, 요리 버프) / 귀환 중 하나.
- **귀환**: 얻은 것을 **전부** 가방으로(「주고받기」, 넘치면 우편함). 탐험 끝.

*압박 (던전 장치)*

| 던전 | 압박이 오르면 |
| --- | --- |
| 황도 지하수로 | 낮은 방부터 물에 잠겨 들어갈 수 없음 |
| 카른브룸 갱도 | 문이 하나씩 무너져 막힘(끝방·쉼터로 가는 길은 막히지 않음), 등불 기름 감소 |
| 뮈르가스트 늪 가장자리 | 새 방에 들어갈 때 밝혀지는 범위가 줄어듦 |
| 소프레고 화산 동굴 | 옮길 때마다 기력 감소(물로 막음) |
| 국경 숲길 | 입문용이라 압박 없음 |

*끝*

- **귀환**: 전부 가져감.
- **전멸**: 밖으로 쫓겨남. 얻은 것을 가치가 높은 순으로 줄 세워 **두 번째, 네 번째, 여섯 번째…를 잃는다**(무작위 없이 정확히 절반, 가장 비싼 건 남음). 묶음 물건은 수량의 절반(내림)을 잃는다. 열쇠·폭약은 모두 사라짐.
- **보스 클리어**: 보스 보상과 첫 클리어 보상을 얻은 것에 더하고, 마지막 쉼터 없이 바로 귀환(전부).
- **자동 귀환**: 시작부터 현실 하루가 지나면 다음 접속 때 전부 가져간 것으로 처리.

**5. 결과**: 전리품이 가방으로, 도감·숙련도·부상이 바뀌고, 탐험 데이터는 지운 뒤 일생 기록에 한 줄.

**6. 경계 상황**

- 방 사이에서 접속을 끊음: 그 자리에 저장. 파티는 모두 다시 모여야 진행.
- 파티원 한 명만 나감: 그 사람은 쉼터에 도착하는 순간 귀환한 것으로 처리(그때까지 얻은 것 중 자기 몫 전부). 남은 사람은 계속.
- 얻은 것의 몫 나누기: 전리품은 줍는 순간 줍는 사람 몫으로 정해진다(파티 공용 없음). 전멸 시 절반 잃기도 사람마다 따로.
- 한 명만 쓰러짐: 남은 사람이 계속. 쓰러진 사람은 다음 쉼터의 쉬기로 일으키거나, 여명기도로.
- 하루 계산이 탐험 중에 돌아감: 탐험은 그대로 이어진다. 달 행동과는 상관없음.
- 피로가 높은 상태로 들어감: 전리품 양에 보상 곡선이 적용된다. 첫 클리어 보상은 줄지 않음.

**7. 연결**: 전투, 주고받기, 피로, 부상, 동료, 유일물·단서, 도감, 지도(던전 이름 공개).

**8. 표시**: 확정. 방 수, 압박 단계, 쉼터 회복량은 숫자만 임시.

## 캐릭터 생성과 성장기

**1. 목적**: 도서관에서 태어나 15세까지 자라 세계에 나오기까지.

**2. 저장하는 값**

| 값 | 내용 |
| --- | --- |
| 생성 단계 | 요청 / 승인 대기 / 기본 정하기 / 성장기 / 상세 설정 / 최종 승인 대기 / 살아 있음 / 죽음 |
| 굴림 씨앗 | 생성마다 하나. 새로고침해도 같은 결과 |
| 남은 굴리기 | 0\~3 |
| 기본 | 이름(전체에서 겹치지 않음), 성별, 청한 재능 3, 태어난 지역·장소 |
| 타고난 재능 | 0\~1, 공개 여부 |
| 성장기 진행 | 나이(0\~15), 지나간 사건, 고른 교육 |

**3. 시작되는 때**: 홈에서 생성 요청. 캐릭터가 죽은 뒤.

**4. 규칙**

1. 생성 요청 → GM 승인.
2. 이름·성별을 정하고, 굴리기 3번 중 원할 때 멈춘다. 굴리기는 "전체" 또는 "능력치만".
3. 청한 재능 셋을 고른다(12가지 중).
4. 태어날 지역·장소는 인구 비례 무작위(중앙대륙이 높고 팔군도가 낮음). 타고난 재능은 표에서 굴림(유물 관련 셋은 표에 없음), 비공개로 저장.
5. 성장기: 0\~15세를 몇 단계로 빠르게 지나며, 단계마다 무작위 사건 하나와 교육 선택 하나. 중앙대륙 밖 출신은 순례자·이단 심문관 사건이 나오지 않는다.
6. 15세 상세 설정: 사건에 살 붙이기, 성격·외형, 성장기 인물(인물 목록으로 들어감). 귀찮으면 자동.
7. GM 최종 승인(반려하면 상세 설정으로 돌아감) → 세계에 등장. 그 달 몫 행동을 온전히 받고, 태어난 곳과 살아온 곳은 지도 3단계.

*죽음*: 건강이 0이 되면 죽는다. 일생 기록이 「이방인들의 서가」에 책으로 꽂히고, 계정은 도서관으로 돌아가 새로 태어날 수 있다.

**5. 결과**: 살아 있는 캐릭터가 하나 생긴다.

**6. 경계 상황**

- 굴리기 중 새로고침: 씨앗이 같아 같은 결과. 남은 횟수는 줄어든 채.
- 성장기 중 접속 끊김: 단계마다 저장, 이어서.
- 같은 이름: 생성 단계에서 거절.
- GM 승인 대기가 길어짐: 대기 중엔 도서관 화면에 머문다(달 행동 없음).

**7. 연결**: 재능, 지도, 인물·동료, 일생 기록, 유일물(죽을 때), GM 패널.

**8. 표시**: 확정. 성장기 단계 수와 사건 표는 숫자만 임시. **계정당 살아 있는 캐릭터는 하나. 죽으면 유일물은 「유일물」의 풀림 규칙대로.**

## 출신

**1. 목적**: 어디서 태어났는지가 세계의 대우를 바꾼다.

**2. 저장하는 값** (캐릭터)

| 값 | 비고 |
| --- | --- |
| 출신 | 제국(황도, 네 팔) / 팔군도(여덟 섬, 섬 이름까지) / 적국(브라켄, 라이젠부르크, 아스텔라). 태어날 때 정해지고 바뀌지 않음 |
| 제국 거주민 | 있음 / 없음. 팔군도·적국 출신이 얻을 수 있음 |

**3. 시작되는 때**: 검문, 세금, 직업 승진, 의뢰 받기, NPC 대화.

**4. 규칙**

|  | 제국 땅에서 | 팔군도에서 | 적국 땅에서 |
| --- | --- | --- | --- |
| 제국 출신 | 검문 쉬움, 성당 의뢰 모두 열림, 인두세 냄 | 검문 보통, 일부 NPC가 경계 | 검문 엄격, 군적 없으면 전선 근처 불가 |
| 팔군도 출신 | 검문 때 짐을 더 자주 엶, 인두세 없음 | 보통. **고향 섬**에선 팔 때 값 +10%, NPC 친밀도 시작이 높음 | 보통 |
| 적국 출신 | 검문 엄격(밀수 발각 확률 증가), 기사 서임·사제 서품·관리 승진 불가, 일부 성당 의뢰 불가 | 보통 | **고향 나라**에선 제국 출신이 제국에서 받는 대우와 같음 |

- **제국 거주민**: 팔군도·적국 출신이 제국에 현실 30일 이상 살고, 신용 기준을 넘고, 교구에 이름을 올리면 얻는다. 얻으면 제국 땅 검문이 "보통"이 되고 인두세를 내며, 기사 서임·관리 승진이 열린다(사제 서품은 제국 출신만).
- 관세는 출신이 아니라 **물건**에 붙는다(「시장·무역」).
- 출신에 따라 일부 NPC 대사와 처음 친밀도가 다르다.

**5. 결과**: 검문 판정, 세금, 직업 길, 의뢰 목록, NPC 반응이 바뀐다.

**6. 경계 상황**

- 이미 막힌 직업에 있는 기존 캐릭터: 데이터 이전 때 확인해서, 있으면 제국 거주민으로 시작한다.
- 제국 거주민이 된 뒤 고향으로 돌아감: 고향 우대는 그대로 남는다.
- 파티 검문: 파티원마다 따로 판정한다.

**7. 연결**: 캐릭터 생성(태어날 곳), 이동(검문), 시장(세금·매매), 직업(승진 제한), 퀘스트(의뢰 조건), 장면.

**8. 표시**: 확정. 10%, 30일, 발각 확률 차이는 숫자만 임시.

## 숙련도·나무·재능

**1. 목적**: 오래 걸려 쌓이는 성장과, 그 성장을 빌드로 바꾸는 나무.

**2. 저장하는 값**

| 값 | 범위 · 비고 |
| --- | --- |
| 기술별 숙련도 | 0\~100, 소수 둘째 자리까지 |
| 벽 통과 | 기술별 60 통과, 80 통과 (참/거짓) |
| 나무별 찍은 칸 | 칸 ID 목록 |
| 쓴 점수 | 나무별 가지·뿌리 (남은 점수는 저장하지 않고 늘 계산: 숙련도에서 나온 점수 − 쓴 점수) |
| 장착 | 기본기 셋, 궁극기 하나, 보조 하나, 유일 기술(기본기 칸 하나 차지) |
| 재능 | 청한 3, 타고난 0\~1(공개 여부), 얻은 목록 |
| 재능 진행 | 얻은 재능 조건마다 카운터(받아치기 성공 수, 생포 수 등) |

**3. 시작되는 때**: 배우기(주 행동), 전투 승리, 나무 찍기·초기화, 재능 조건 카운터가 바뀔 때.

**4. 규칙**

*숙련도*

1. 배우기 1회 증가량 = 구간 기준(0\~30: 4, 30\~60: 2, 60\~80: 1, 80\~100: 0.25) × (1 + 재능·스승·교본 보너스) − 이번 달 반복 감점.
2. 벽: 60을 통과하지 않았으면 59.99에서, 80을 통과하지 않았으면 79.99에서 멈춘다. 남은 증가량은 버린다.
3. 벽 시험(스승, 훈련장 교관 대련, 사건)에 성공하면 통과 표시.
4. 전투 승리: 쓴 기술마다 +1, 이번 달 그 기술 한 번까지. 벽 규칙 똑같이.

*점수와 칸*

- 가지 점수 = 숙련도 ÷ 4 (내림) + 진화 재능 보너스, 뿌리 점수 = 숙련도 ÷ 10 (내림).
- 칸을 찍는 조건: 바로 앞 칸을 찍었다 + 같은 갈림길의 다른 쪽을 찍지 않았다 + 남은 점수가 있다 + (숨은 칸이면) 여는 조건을 채웠다.
- 줄기는 점수 없이 숙련도 문턱(1, 10, 30, 50)에서 열린다.
- 초기화: 마을에서 돈을 내면 그 나무의 찍은 칸이 모두 빠지고 점수가 돌아온다. 장착은 비워진다.
- 장착 규칙: 기본기 셋은 들고 있는 무기의 나무(방패를 들면 방패 나무와 섞어서), 궁극기는 끝까지 찍은 루트에서 하나, 보조는 보조 나무에서 하나.

*재능*

- 타고난 재능: 재능마다 정해진 공개 조건을 채우면 공개.
- 얻은 재능: 관련 카운터가 바뀔 때마다 조건을 확인하고, 채우면 그 자리에서 얻고 알림. 진화 재능은 보너스 점수나 교차 갈래를 함께 연다.

**5. 결과**: 숙련도·점수·칸·재능이 바뀐다.

**6. 경계 상황**

- 벽에 막힌 채 배우기: 행동은 쓰이고 숙련도는 그대로. 화면에 "벽"이라고 미리 알린다.
- 진화 재능 두 개를 한 번에 달성: 둘 다 준다. 순서는 정의 데이터의 순서.
- 정의 데이터에서 칸이 바뀌거나 없어짐: 나무에 버전 번호를 두고, 버전이 바뀌면 영향을 받은 칸만 빼고 그 점수를 돌려준다. 알림을 띄운다.
- 진화 재능으로 받은 점수가 있는 상태에서 초기화: 재능 점수도 돌아온다(사라지지 않음).

**7. 연결**: 달 행동, 전투, 기술 기준표, 재능 효과, 데이터 이전.

**8. 표시**: 확정. 증가량과 보너스는 숫자만 임시.

## 직업

**1. 목적**: 일하기로 돈과 경력을 쌓고, 단계를 올라 자리와 권한을 얻는다.

**2. 저장하는 값**

| 어디 | 값 | 비고 |
| --- | --- | --- |
| 정의 | 직업 | 직업서 11개(기사, 항해·무역, 농부, 성직자, 의원·약초사, 상인, 용병, 사냥꾼·길잡이, 음유·광대, 학자·필사가, 여관 주인) + 조직(카르텔, 해적단, 잔향극단) + 관리 + 장인 + 나라별 직업(뮈르가스트의 영매, 아스텔라의 별 사제). 직업마다 다섯 단계의 이름, 일터, 단계별 월급, 관련 숙련도, 추가 조건, 승진 시험 |
| 정의 | 상위 자리 | 4·5단계의 자리. 지역·조직마다 몇 자리인지(예: 라인펠트 기사단장 1, 로스 알토스 카포 1) |
| 세계 | 자리 주인 | 자리마다 주인(NPC 또는 플레이어), 앉은 날 |
| 세계 | NPC 후보 | 자리마다 기다리는 NPC 후보와 승진 점수 |
| 캐릭터 | 주 직업 | 직업 ID, 단계 1\~5, 경력 |
| 캐릭터 | 부업 | 직업 ID, 단계 1\~3, 경력 (없을 수 있음) |
| 캐릭터 | 예전 직업 | 그만둔 직업마다 남은 경력, 단계 |

**3. 시작되는 때**: 일하기(주 행동), 승진 시험, 직업 바꾸기, 하루 계산(자리 정리).

**4. 규칙**

*일하기*

1. 그 직업의 **일터**가 있는 구역에서만. 직업이 없으면 어디서든 날품(일당만, 경력 없음).
2. 주 직업: 단계별 월급 전부, 경력 +1, 관련 숙련도 조금. 부업: 월급 70%, 경력 +1, 관련 숙련도 조금.
3. 경력은 직업을 합쳐 한 달 2까지(「세계 시계」의 이번 달 경력).
4. 가끔 일터 사건 장면.

*승진 (1→2→3단계)*

- 조건: 경력 기준 + 관련 숙련도 기준 + 직업별 추가 하나(기사 평판, 상인 신용, 카르텔 그 조직 의뢰 수, 성직자 교리 시험 등).
- 조건을 채우면 **승진 시험**(결투, 시험 장면, 사건)이 열리고, 통과하면 단계 +1.
- 부업은 3단계까지만 오른다.

*상위 자리 (4·5단계)*

- 자리 수가 정해져 있고 처음엔 NPC들이 앉아 있다. 주 직업으로만 오를 수 있다.
- **승진 점수** = 경력 + 관련 숙련도 + 직업별 추가(평판 등). 3단계에서 4단계 조건을 채우면 그 자리의 후보가 된다.
- **빈자리**: 자리가 비면(NPC의 은퇴·죽음·사건, 플레이어가 내려옴) 하루 계산 때 후보(플레이어와 NPC 후보 모두) 중 승진 점수가 가장 높은 쪽이 앉는다.
- **도전**: 자리 주인에게 도전 사건(결투, 추대, 선거 장면)을 걸 수 있다. 이기면 자리를 바꾼다. 같은 자리 도전은 한 번에 하나씩.
- **자리 지키기**: 그 직업이 주 직업이고, 매달 일하기를 한 번 이상(자동 처리 포함). 현실 30일 접속하지 않거나 주 직업을 바꾸면 자리를 내놓고 3단계로.

*직업 바꾸기*

- 주 직업을 다른 직업으로 바꾸면, 그만둔 직업은 예전 직업으로 남는다: **경력 절반**(내림), 단계는 그 경력으로 갈 수 있는 단계까지(최소 1), 상위 자리는 내놓는다.
- 예전 직업으로 돌아가면 남은 경력과 단계에서 다시 시작한다.
- 주 직업과 부업은 서로 바꿀 수 있다(부업이 주 직업이 되면 3단계 제한이 풀린다).

*내려가기*

- 평판이 크게 떨어지거나 조직을 배신하는 사건: 한 단계 강등. 용병이 계약을 깨면 용병 직업 자체를 다시 가질 수 없다.

*단계의 보상*

- 월급, 신분 동료, 조직 기술(조직 직업), 권한(기사 서임 → 인두세 면제, 부제 → 교구 명부 열람 등), 칭호.

**5. 결과**: 지갑, 경력, 단계, 자리, 권한이 바뀐다.

**6. 경계 상황**

- 두 플레이어가 같은 빈자리의 후보: 승진 점수가 높은 쪽. 같으면 후보가 된 날이 빠른 쪽.
- 도전 중에 자리가 비어버림: 도전은 취소되고 빈자리 규칙으로.
- 하루 계산의 자동 처리 일하기: 주 직업 일터에 있지 않아도 자동 처리분은 주 직업으로 친다(월급 70%).
- 강등으로 상위 자리에서 내려옴: 그 자리는 빈자리가 된다.
- 이름 없는 다섯 날: 일하기 없음(달 행동 없음).

**7. 연결**: 세계 시계(달 행동, 경력 상한), 숙련도, 주고받기(월급), 동료(신분 동료), 재능·조직 기술, 퀘스트(가문 퀘스트의 승진 조건), 데이터 이전(기존 직업 매핑).

**8. 표시**: 확정. 월급, 경력 기준, 70%, 자리 수는 숫자만 임시.

**기존 캐릭터**: 전바섬 기사 2단계(종자), 볼카누스 카르텔 2단계(시카리오), 아스테리스 관리 1단계(서기), 정동 팔머 잔향극단 2단계(단원), 제르노바엘 성직자 1단계(수련자), 카멜 날품, 메멜·하우레스는 옛 직업 그대로.

**새 직업 셋** (단계 이름과 숫자는 임시)

| 직업 | 다섯 단계 | 일터 | 관련 숙련도 | 상위 자리 |
| --- | --- | --- | --- | --- |
| 장인 | 풀무지기 → 견습 → 장인 → 공방장 → 대장인 | 공방(카른브룸 여섯 공방, 각 도시의 대장간) | 대장일 | 카른브룸 여섯 공방의 공방장. 바이스 공방장 자리는 바이스가르드(NPC)라 도전 사건이 2장과 이어진다 |
| 영매 | 등불지기 → 견습 영매 → 영매 → 연맹 원로 → 연맹장 | 영매의 집, 네벨하임 영매 연맹 | 안개 읽기(새 생활 기술), 기도 보조 나무를 영매식으로 씀 | 네벨하임 연맹 원로·연맹장 |
| 별 사제 | 별 세는 아이 → 노래꾼 → 별 사제 → 별을 읽는 자 → 별의 대사제 | 아스텔라 별의 신전 | 노래, 별 읽기(새 생활 기술) | 별을 읽는 자·대사제 |

- 영매와 별 사제는 그 나라 출신이거나 그 나라 거주민만 가질 수 있다. 제국 땅에서 별 사제로 일하면 이단으로 본다(검문·의뢰에 불리).
- 장인은 누구나 가질 수 있지만, 카른브룸 공방은 외지인을 받지 않아 초대(공방 추천)가 있어야 그곳 일터를 쓴다.

## 동료와 부상

**1. 목적**: 함께 싸우는 NPC와, 죽지 않는 대신 다치는 규칙.

**2. 저장하는 값**

| 어디 | 값 | 범위 · 비고 |
| --- | --- | --- |
| 캐릭터 | 동료 목록 | 동료 ID, 종류(이야기·용병·신분·내 사람·짐승·일꾼), 친밀도(용병은 신뢰) 0\~100, 열린 기술, 성향 |
| 동료 | 부상 | 없음 / 경상 / 중상, 회복 시각 |
| 동료 | 흉터 | 개수, 마지막 중상 시각 |
| 용병 | 계약 | 계약금, 끝나는 달 |
| 캐릭터 | 플레이어 부상 | 건강 임시 감소량, 굳는 시각 |

**3. 시작되는 때**: 동료를 얻을 때, 전투에 데려갈 때, 쓰러질 때, 하루 계산.

**4. 규칙**

*데려가기*

- 혼자면 둘, 파티면 플레이어 한 명당 하나. 부상 중인 동료는 데려갈 수 없다.
- 배치는 파티장, 성향(공격 / 지키기 / 지원)은 주인이 전투 전에.
- 동료는 자기 장비를 들고 다닌다(바꿔줄 수 없음).
- 친밀도가 정해진 단계에 닿을 때마다 기술이 하나씩 열린다.

*얻기*

- 이야기 동료: 사건 완료로. 신분 동료: 직업 단계가 오르면. 짐승: 조련·사냥 기술, 길들이기.
- 용병: 여관·용병 길드에서 계약금을 내고(「주고받기」), 끝나는 달까지. 끝나기 한 달 전에 알림.
- 내 사람: 인물 목록에서 친밀도 70 이상 + GM이 전투 능력을 한 번 승인.

*부상 (동료)*

- 체력 0으로 쓰러짐: 흐트러진 상태였거나 보스 광역기면 **중상**, 아니면 **경상**.
- 경상: 다음 하루 계산 때 회복. 약초·음식으로 바로 회복 가능.
- 중상: 현실 3일 뒤 회복. 의원(돈)이나 의술 기술로 1일로 줄일 수 있다.
- 흉터: 마지막 중상에서 현실 7일 안에 또 중상이면 흉터 +1(능력치 조금 감소, 고유 대사·칭호).
- 용병이 중상: 위로금을 요구한다. 신뢰 30 미만이면 계약을 끝내고 떠난다(남은 계약금 일부 반환). 이야기 동료와 내 사람은 떠나지 않는다.

*부상 (플레이어)*

- 쓰러지면 건강이 임시로 깎인다. 현실 3일 안에 치료하면 돌아오고, 지나면 굳는다(최대치가 아니라 현재 값이 내려간 채로 남음).
- 건강이 0이 되면 죽음(「캐릭터 생성」).

**5. 결과**: 동료의 상태와 계약, 플레이어의 건강이 바뀐다.

**6. 경계 상황**

- 탐험이나 레이드 도중 계약이 끝남: 그 탐험·전투가 끝날 때까지 유지.
- 전투 중 동료가 쓰러짐: 그 전투에서 빠지고, 끝난 뒤 부상 판정.
- 이야기 동료가 사건 때문에 잠시 떠나 있음: 목록엔 있고 데려갈 수 없음으로 표시.
- 중상 회복 시각이 하루 계산과 겹침: 시각 기준으로만 판단(하루 계산과 무관).

**7. 연결**: 전투, 던전, 주고받기, 인물 목록, 의술, 직업 단계.

**8. 표시**: 확정. 회복 시간, 흉터 기준, 신뢰 30은 숫자만 임시.

## 이동과 지도

**1. 목적**: 현실 시간이 걸리는 이동, 직접 몰면 짧아지는 길, 밝혀가는 지도.

**2. 저장하는 값**

| 어디 | 값 | 비고 |
| --- | --- | --- |
| 정의 | 길 | 출발·도착 지역, 땅길/바닷길, 기본 시간(분), 위험도, 검문·통행세 지점, 사건 표 |
| 캐릭터 | 현재 위치 | 지역 + 구역 |
| 캐릭터 | 지도 | 지역별 1\~3단계, 길별 지나간 적 있음 |
| 캐릭터 | 이동 중 | 경로, 탈것, 출발 시각, 남은 시간(분), 멈춘 사건 |
| 캐릭터 | 탈것 | 걷기 / 노새 / 말 / 수레 / 마차 / 배(작은·상선·큰 배) |
| 캐릭터 | 면허 | 작은 배 / 상선 / 큰 배 |

**3. 시작되는 때**: 플레이어가 목적지를 고르고 출발할 때.

**4. 규칙**

1. **출발 조건**: 짐 무게가 탈것 한도 이하, 배라면 면허와 항해술, 적국이라면 군적. 하나라도 안 되면 출발 불가와 이유.
2. **걸리는 시간** = 길의 기본 시간 × 탈것 배율 × 지도 단계 배율(1단계 2배, 2단계 1.3배, 3단계 1배).
3. 출발하면 **남은 시간**이 줄어든다. 화면을 꺼도 계속.
4. **길 위 사건**: 길의 사건 표에서 정해진 간격마다 확인(씨앗 사용). 터지면 그 자리에서 **멈추고**(남은 시간도 멈춤) 다음 접속 때 고른다. 산적·해적은 전투로.
5. **검문 지점**에 닿으면 통행세를 내고(「주고받기」), 밀수품이 있으면 판정(「시장·무역」).
6. **직접 몰기**: 길을 구간으로 나누고, 구간마다 미니게임 점수에 따라 그 구간 시간을 0\~50% 줄인다. 언제든 자동으로 돌아갈 수 있다. 1단계 지역 길에서는 불가.
7. 도착: 위치를 바꾸고, 그 길을 지나간 것으로 표시하고, 도착 지역 지도를 3단계로.
8. 지도 2단계: 지도 상인·길잡이·소문·다른 플레이어가 그린 지도로.

**5. 결과**: 위치·지도·신선도(이동 시간만큼)·지갑(통행세)이 바뀐다.

**6. 경계 상황**

- 이동 중 할 수 있는 것: 가방 보기, 편지, 퀘스트 창. 다른 지역 콘텐츠는 불가. 달 행동은 이동 중에도 쓸 수 있다(배우기·쉬기 등 장소가 필요 없는 것만).
- 사건으로 멈춘 채 며칠이 지남: 그대로 멈춰 있다(손해 없음). 신선도도 멈춘 동안은 세계 하루 단위로만 줄어든다.
- 직접 몰기 중 접속 끊김: 그 구간은 자동으로 마저 간다.
- 파티 이동: 파티장이 출발시키면 모두 함께. 탈것은 가장 느린 사람 기준. 한 명이 이동 중이면 파티 출발 불가.
- 목적지에 도착했는데 거처 생활비가 밀림: 이동과 상관없이 하루 계산에서 처리.

**7. 연결**: 시장·무역·세금, 신선도, 가방(짐 무게), 지도, 퀘스트 추적, 구역 대화, 항해 미니게임(면허 시험).

**8. 표시**: 확정. 길별 기본 시간, 탈것 배율, 사건 간격은 숫자만 임시.

## 시장·무역·세금·밀수

**1. 목적**: 하루마다 움직이는 물가와, 그 위에서 돌아가는 무역.

**2. 저장하는 값**

| 어디 | 값 | 비고 |
| --- | --- | --- |
| 정의 | 상품 | 기준가(잎전), 생필품 여부, 무게, 신선도 분류, 제국 금지품 여부 |
| 정의 | 지역 생산·수요표 | 지역별 상품별 기본 생산량·수요량, 계절 배율 |
| 정의 | 세율표 | 검문 지점별 통행세, 품목·지역별 관세, 인두세, 재산세, 위탁 수수료 |
| 세계 | 시장 | 지역별 상품별 재고, 수요, 오늘 가격, 어제 가격, 오늘 플레이어 매매량 |
| 세계 | NPC 상단 | 위치, 실은 물건, 가는 곳 |
| 세계 | 장터 게시판 | 위탁 판매 목록 |
| 캐릭터 | 신용 대출 | 빌린 돈, 이자율, 갚을 달 |

**3. 시작되는 때**: 하루 계산(시장 갱신), 플레이어가 사고팔 때, 검문, 한 해 정리.

**4. 규칙**

*하루 계산의 시장 갱신 (순서 고정)*

1. 생산: 기본 생산량 × 계절 배율 × 사건 배율(GM 사건, 메인 스토리 단계).
2. 소비: 인구 기본 수요 + 전쟁 수요 + 사건.
3. NPC 상단: 길을 따라 한 칸 움직이고, 도착한 시장에서 싼 것을 사서 비싼 곳으로 실어 간다. 길이 사건으로 막히면 멈춘다.
4. 재고 = 어제 재고 + 생산 − 소비 + 오늘 플레이어 판매 − 오늘 플레이어 구매 ± 상단 거래 (0 아래로 내려가지 않음).
5. 가격 = 기준가 × (수요 ÷ 재고)의 완만한 곡선. 기준가의 0.5\~3배 안, 하루 변동 ±15%(생필품 ±5%).
6. 변동이 큰 상품 몇 개로 월보 기사를 만든다.

*사고팔기 (실시간)*

- 살 때 = 오늘 가격 × (1 + 상점 몫) × 신용 할인. 팔 때 = 오늘 가격 × (1 − 상점 몫) × 신선도·품질 배율.
- **한 번에 많이 팔면** 한 개씩 팔 때마다 그 거래 안에서 값이 조금씩 내려간다. 사는 것도 마찬가지로 올라간다.
- 매매는 그 순간 시장 재고에 반영된다(「주고받기」 + 시장 값 동시 쓰기).
- 한 사람이 한 시장에서 하루에 사고팔 수 있는 양에 상한을 둔다(매점매석 방지).

*세금*

- 통행세: 검문 지점을 지날 때. 입항세: 항구에 배로 들어갈 때.
- 관세: 제국 지역 시장에 팔군도 상품을 팔 때, 품목별.
- 인두세: 한 해 정리 때, 제국 안에 사는 캐릭터(기사 면제).
- 재산세: 집마다 매달. 위탁 수수료: 장터 게시판에서 팔릴 때.
- 못 내면: 통행세·관세는 그 길을 못 지나감 / 그 물건을 못 팖. 인두세·재산세는 빚으로 쌓이고 신용이 떨어진다.

*밀수*

- 금지품이나 관세를 피하려는 물건을 숨김 칸(이중 바닥 수레, 숨은 칸 배)에 싣는다.
- 검문에서 발각 판정: 기본 확률에서 눈치·언변·뒷골목 기술·숨김 칸 등급만큼 줄고, 신용이 높으면 뇌물을 낼 수 있다(씨앗 사용).
- 발각: 그 물건 압수, 벌금, 평판 하락. 통과: 그대로.

*장터 게시판 위탁*

- 물건을 올리면 맡겨둔 상태가 된다. 다른 플레이어가 사면 돈은 판 사람 우편함으로, 수수료를 뗀다. 30일 안 팔리면 우편함으로 돌아온다.

**5. 결과**: 시장 값, 지갑, 가방, 신용, 평판이 바뀐다.

**6. 경계 상황**

- 마지막 남은 물건을 두 사람이 동시에 삼: 시장 값 쓰기가 한 번에 하나씩이라 한 명만 성공, 다른 한 명은 "방금 팔렸다".
- 하루 계산 중 사고팔기: 시장 갱신 동안(몇 초) 매매를 멈추고 "장이 바뀌는 중".
- 가격이 0이 되려 함: 기준가의 0.5배에서 멈춤.
- 한 사람이 시장을 크게 흔듦: 매매 상한 + 하루 계산의 이상치 검사로 GM에게 알림.
- 이름 없는 다섯 날: 장터가 닫혀 매매 불가, 시장 갱신은 생산·소비만.

**7. 연결**: 주고받기, 이동(검문), 신선도, 제작, 의뢰 게시판(납품 의뢰), 월보, GM 사건, 거처(재산세).

**8. 표시**: 확정. 모든 배율·확률·상한·이자율은 숫자만 임시.

## 가방·신선도·제작·강화

**1. 목적**: 물건을 들고, 상하지 않게 지키고, 만들고, 키운다.

**2. 저장하는 값**

| 어디 | 값 | 비고 |
| --- | --- | --- |
| 캐릭터 | 몸에 지닌 짐 | 물건 목록, 무게 합. 한도 = 맨몸 한도 + 탈것 한도 |
| 캐릭터 | 창고 | 집이 있는 지역마다 하나, 칸 수는 거처 단계 |
| 진행 중 임시 | 던전 가방 | 탐험 안에서만 쓰는 칸 수 제한 |
| 물건(묶음) | 수량, 신선도 0\~100, 품질 | 신선도·품질이 다르면 다른 묶음 |
| 물건(낱개) | 고유 ID, 강화 단계, 내구도 0\~100, 품질 | 장비·유일물 |
| 캐릭터 | 아는 레시피 | 레시피 ID 목록 |

**3. 시작되는 때**: 줍기·사기·만들기, 이동(신선도), 하루 계산(신선도), 강화·수리.

**4. 규칙**

*짐*

- 무게 한도를 넘으면 이동을 출발할 수 없고, 상시 콘텐츠에서 더 주울 수 없다(우편함으로).
- 던전 안에서는 무게 대신 던전 가방 칸으로 센다. 귀환하면 짐으로 옮기고, 넘치면 우편함.

*신선도*

- 분류마다 줄어드는 속도가 있다: 이동 중엔 이동 시간(분)에 비례, 가만히 있으면 하루 계산 때 하루치.
- 얼음 상자·서늘한 창고·소금 같은 보존 수단이 속도를 줄인다. 안 상하는 물건은 늘 100.
- 0이 되면 "상한 ○○"으로 바뀐다(값 거의 없음, 정원 거름으로만).
- 팔 때와 요리할 때 신선도가 값과 효과에 곱해진다.

*제작*

1. 아는 레시피 + 재료 + 장소(대장간·약방·부엌, 또는 집의 작업대)가 필요.
2. 타이밍 미니게임(망치질 등)을 친다.
3. 품질(하·중·상·최상) = 숙련도 + 재료 등급 + 미니게임 점수. 실패는 없고 품질만 달라진다.
4. 재료를 빼고 결과물을 넣는 것을 한 번에(「주고받기」).
5. 레시피는 책·스승·조합 시도로 얻는다. 조합 시도: 레시피 없이 재료를 넣어 보면, 맞는 조합이면 레시피를 배우고 아니면 재료 일부만 잃는다.

*강화*

- +0부터 +10까지. 단계별 성공 확률과 실패 결과는 Unity 기획서의 「+10 강화표」를 그대로 쓴다(씨앗 사용).
- 불가사리의 이빨만 +10에서 숨은 한도 +20까지 계속된다(「유일물」).

*수리*

- 내구도는 전투마다 조금씩 준다. 0이 되면 부서지지 않고 장비 효과가 절반이 된다.
- 대장간이나 던전 쉼터의 손질로 수리. 돈 또는 재료가 든다.

**5. 결과**: 짐·창고·물건 상태가 바뀐다.

**6. 경계 상황**

- 신선도가 다른 같은 물건: 따로 묶음. 팔거나 쓸 때는 신선도가 낮은 것부터 쓴다(설정으로 바꿀 수 있음).
- 강화 중 접속 끊김: 결과는 씨앗으로 이미 정해진 채 한 번에 저장되므로, 다시 들어오면 결과만 보여준다(다시 굴릴 수 없음).
- 제작 미니게임 중 끊김: 재료는 아직 빠지지 않은 상태. 다시 하면 처음부터.
- 창고가 있는 지역이 아닌 곳에서 창고 열기: 불가(그 지역에 있어야 함).

**7. 연결**: 주고받기, 이동, 시장, 던전, 거처, 요리 버프(전투), 유일물.

**8. 표시**: 확정. 신선도 속도, 무게 한도, 품질 공식, 내구도 감소량은 숫자만 임시.

## 거처

**1. 목적**: 쉬는 곳이자 꾸미는 곳, 여러 지역의 거점.

**2. 저장하는 값**

| 값 | 비고 |
| --- | --- |
| 거처 목록 | 지역마다 0\~1개: 단계(셋집 / 집 / 저택), 빌림 또는 소유, 다음 낼 날 |
| 방과 가구 | 방마다 격자, 놓인 가구(가구 ID, 위치, 방향) |
| 정원 | 칸마다 심은 것, 심은 날, 성장 단계 |
| 방명록 | 다녀간 사람과 한 줄 |
| 밀린 돈 | 거처마다 |

여관(공동 침상·독방)은 거처 목록에 들지 않는다. 거처가 없는 지역에서 하루 계산을 맞으면 그 지역 여관에 묵은 것으로 친다.

**3. 시작되는 때**: 빌리기·사기·올리기, 가구 놓기, 씨 심기·수확, 손님 초대, 하루 계산.

**4. 규칙**

- **하루 계산마다**: 셋집은 월세, 집·저택은 재산세. 그리고 지금 있는 지역에 거처가 없으면 여관비(공동 침상 또는 독방, 고른 쪽).
- **쉬기 효율·보관함**은 지금 있는 지역의 거처 단계를 따른다(없으면 여관).
- **올리기**: 셋집 → 집은 구입, 집 → 저택은 구입 + 신용 기준. 내리거나 팔 수도 있다(판 값의 일부를 돌려받음).
- **가구**: 가구마다 크기가 있고 격자 안에만 놓인다. 일부 가구는 작은 효과(작업대 = 제작 보너스, 서늘한 창고 = 신선도 보존, 동료 숙소 = 동료 회복).
- **정원**: 씨를 심으면 하루 계산마다 성장 단계 +1, 계절이 맞지 않으면 느리게. 다 자라면 수확해서 재료로. 상한 물건은 거름으로 쓰면 성장이 빨라진다.
- **손님**: 같은 지역에 있는 플레이어를 초대하면 그 집이 하나의 구역이 된다(구역 대화 가능). 방명록에 한 줄.

**5. 결과**: 지갑, 거처 상태, 쉬기 효율, 정원 수확물이 바뀐다.

**6. 경계 상황**

- 월세·재산세를 못 냄: 밀린 돈으로 쌓이고 신용이 떨어진다. 셋집은 두 달 밀리면 계약이 끝나고, 가구와 창고 물건은 우편함으로(이때는 30일 보관). 집·저택은 팔리지 않고, 밀린 돈을 다 낼 때까지 창고 꺼내기만 된다.
- 같은 지역에 거처 둘: 불가(지역마다 하나).
- 손님이 와 있는 중에 집주인이 떠남: 손님은 그 지역의 기본 구역으로 옮겨진다.
- 정원 작물이 다 자란 채 오래 방치: 시든다(정해진 날 수 뒤). 시들기 하루 전 알림.

**7. 연결**: 주고받기, 시장(재산세·신용), 신선도(창고), 제작(작업대), 동료(숙소), 구역 대화.

**8. 표시**: 확정. 비용, 성장 일수, 두 달 기준은 숫자만 임시.

## 퀘스트·장면·구역 대화

**1. 목적**: 이야기를 받고, 보고, 고르고, 사람들과 말하는 길.

**2. 저장하는 값**

| 어디 | 값 | 비고 |
| --- | --- | --- |
| 정의 | 퀘스트 | 분류(메인·가문·의뢰·동료), 받는 조건(스토리 단계, 위치, 직업, 재능, 날짜), 단계별 목표, 기한, 보상, 세계 결과 여부 |
| 정의 | 장면 대본 | 줄마다 화자·표정·대사·연출 명령, 선택지와 그 결과 |
| 캐릭터 | 퀘스트 목록 | 퀘스트 ID, 단계, 목표 진행, 받은 시각, 추적 여부 |
| 캐릭터 | 본 장면, 고른 것 | 장면 ID, 선택 결과 |
| 캐릭터 | 단서 수첩 | 단서 ID 목록 |
| 세계 | 세계 한 번 사건 | 사건 ID, 진행 중인 파티(잠금), 결과, 결과를 낸 사람들 |
| 세계 | 구역 대화 | 구역별 최근 대화, 7일 보관 |

**3. 시작되는 때**: 퀘스트 받기, 목표에 관련된 일이 생길 때, 장면 열기, 말하기.

**4. 규칙**

*퀘스트*

1. 받는 조건을 모두 채우면 받을 수 있다. 메인은 스토리 단계가 되면 자동으로 들어온다.
2. 목표 종류: 가기, 처치, 생포, 모으기, 납품, 만나기, 장면 보기, 숙련도 도달, 기록 카운터(가문 퀘스트 막 조건).
3. 관련된 일이 생길 때마다 목표 진행을 갱신한다(처치 수, 모은 수 등).
4. 단계의 목표를 다 채우면 다음 단계, 마지막 단계면 완료: 보상(「주고받기」, 보상 출처 ID = 퀘스트 ID + 단계).
5. 포기는 의뢰만 가능. 메인·가문은 포기 없이 멈춰둘 수만 있다. 기한이 지난 의뢰는 실패로 닫힌다.

*세계 한 번 사건* (볼프람 정예전 같은 것)

1. 한 파티가 시작하면 **잠금**: 끝날 때까지 다른 파티는 시작할 수 없고 "누군가 싸우는 중"이 보인다.
2. 결과가 나는 순간(볼프람 생포 또는 쓰러짐)에만 세계에 기록. 전멸·도망은 결과가 아니어서 잠금만 풀리고 다시 도전할 수 있다.
3. 결과가 기록되면 모두의 퀘스트가 그 결과에 맞는 다음 단계로 넘어가고, 월보에 실린다.
4. 잠근 파티가 전투 중 모두 접속이 끊겨 현실 1시간 동안 돌아오지 않으면 잠금이 풀린다.

*장면*

- 대본은 위에서 아래로 한 줄씩. 선택지는 고른 결과를 **장면이 끝날 때 한 번에** 적용한다(친밀도, 단서, 표시, 퀘스트 진행).
- 중간에 닫으면 아무것도 적용되지 않고, 다음에 처음부터 다시 본다. 이미 본 장면은 다시 볼 수 있지만 결과는 다시 적용되지 않는다.
- 연출 명령: 등장, 퇴장, 표정, 흔들림, 배경, 효과음, 컷인, 물건·버프 주기. 일러스트가 없는 인물은 회색 실루엣(체형별).

*구역 대화*

- 같은 구역에 있는 사람만 보내고 받는다. 파티도 마찬가지. 같이 움직이는 동안(같은 던전 층·배·길)은 한 구역.
- 한 줄 길이 제한, 짧은 시간에 너무 많이 보내면 잠시 막힘.
- "/표정" 명령, 귓속말(같은 구역의 한 사람).
- 들어오면 최근 몇 줄을 지난 대사로. 7일 지난 대화는 지운다.
- 신고와 말 막기, GM은 대화 기록을 볼 수 있다.

**5. 결과**: 퀘스트 진행, 세계 결과, 단서 수첩, 친밀도, 대화 기록이 바뀐다.

**6. 경계 상황**

- 같은 목표를 두 퀘스트가 셈: 둘 다 진행된다.
- 보상 받기 직전에 가방이 가득: 넘친 몫은 우편함.
- 세계 한 번 사건의 결과가 정해진 뒤 진행 중이던 다른 사람: 그 사람은 결과를 보는 장면으로 넘어간다.
- 장면 도중 하루 계산: 장면은 영향 없음.
- 구역을 옮기는 중에 보낸 말: 보낸 순간의 구역에 남는다.

**7. 연결**: 주고받기, 전투, 던전, 이동(추적), 스토리 단계(GM), 월보, 인물·동료, 유일물(숨은 장면).

**8. 표시**: 확정. 잠금 풀림 1시간, 보관 7일, 길이 제한은 숫자만 임시.

## 반복 의뢰

**1. 목적**: 의뢰 게시판에 매일 새 일이 올라와, 상시 콘텐츠와 경제와 이야기를 잇는다.

**2. 저장하는 값**

| 어디 | 값 | 비고 |
| --- | --- | --- |
| 정의 | 의뢰 틀 | 종류, 들어갈 빈칸(대상·장소·수량), 등급 1\~5, 보상 공식, 기한, 조건(직업·출신·스토리 단계), 의뢰인 대사 틀 |
| 정의 | 장소별 의뢰인 | 장소마다 이름 있는 의뢰인 NPC 몇 명 |
| 세계 | 게시판 | 장소마다 오늘 걸린 의뢰 목록(틀 + 채운 빈칸 + 의뢰인 + 기한) |
| 캐릭터 | 받은 의뢰 | 의뢰 ID, 진행, 받은 날 |

**3. 시작되는 때**: 하루 계산(게시판 새로 걸기), 받기·완료.

**4. 규칙**

*의뢰 종류*

| 종류 | 하는 일 | 빈칸을 채우는 곳 |
| --- | --- | --- |
| 토벌 | 지역 적 처치 | 지역 적표, 등급 |
| 현상금 | 정해진 적을 생포(살려 오면 보상 큼) 또는 처치 | 지역 정예, 도적 |
| 채집 | 약초·재료 모아 오기 | 계절과 지역 채집표 |
| 납품 | 물건 가져오기 | **시장에서 재고가 모자란 상품**(보상 = 오늘 시세보다 높게) |
| 배달 | 편지·짐을 다른 장소·지역으로 | 길, 신선도 있는 물건이면 기한이 짧음 |
| 호위 | 상단·순례자와 함께 이동 | 길, 길 위 사건이 전투로 |
| 수색 | 던전의 특정 방·물건 찾기 | 지역 던전 |
| 일손 | 대장간·약방·부엌 등에서 만들어 주기 | 제작 레시피(직업 조건이 붙기도) |
| 정보 | 소문 모으기, 사람 찾기 | 지역 소문표 |
| 공연·치료 | 노래·곡예, 환자 돌보기 | 보조 나무 기술 |

*하루 계산의 게시판 갱신*

1. 장소마다 게시판 크기(도시 8, 마을 4)만큼 채운다. 기한이 지난 것은 내리고, 받힌 것은 그대로 둔다.
2. 무게를 줘서 틀을 고른다: 지역 특색(뮈르가스트는 채집·수색, 소프레고는 납품·현상금), **시장 상태**(모자란 상품은 납품 의뢰), 계절, **스토리 단계**(1장 소문 단계면 늪 약초·실종 수색 의뢰가 많아짐), GM 세계 사건.
3. 등급은 지역 위험도에서. 등급마다 권장 숙련도를 함께 보여준다.
4. 빈칸을 씨앗으로 채우고, 그 장소의 의뢰인 하나를 붙인다.

*받기·완료*

- 동시에 진행할 수 있는 의뢰는 5개.
- 목표를 채우면 의뢰인에게 돌아가 짧은 장면(의뢰인 대사 틀) 뒤 보상(「주고받기」, 보상 출처 ID = 게시판 의뢰 ID).
- 보상: 돈(등급 × 기준 품삯 × 걸리는 정도), 재료, 신용·평판 조금, 그 지역 NPC 친밀도 조금. 경력은 오르지 않는다(경력은 일하기만).
- **피로**: 「의뢰」를 콘텐츠 분야 하나로 센다. 그날 완료한 수가 늘수록 돈 보상이 보상 곡선대로 줄어든다(재료·친밀도는 줄지 않음).
- 기한을 넘기면 실패(보상 없음). 등급 4 이상 의뢰를 실패하면 그 의뢰인 친밀도가 조금 떨어진다.
- 가끔 완료 뒤 같은 의뢰인의 **후속 의뢰**가 열리고, 그 끝에 소문이나 단서가 있다.

*각자 따로*

- 게시판의 의뢰는 **사람마다 따로** 받는다. 누가 받아도 다른 사람의 게시판에서 사라지지 않는다.
- 같은 의뢰는 한 사람이 한 번만(받은 의뢰 목록으로 확인). 파티원이 같은 의뢰를 받았으면 함께 진행하고 각자 보상을 받는다.
- 토벌·현상금의 대상은 사람마다 따로 나타난다(한 사람이 잡아도 다른 사람의 대상은 남음).

**5. 결과**: 게시판, 받은 의뢰, 지갑·가방, 시장(납품이 재고를 채움).

**6. 경계 상황**

- 납품 의뢰를 받은 뒤 시장 재고가 채워짐: 의뢰는 기한까지 그대로 유효.
- 배달·호위 길이 사건으로 막힘: 막힌 동안 기한이 멈춘다.
- 받은 의뢰의 장소에 갈 수 없게 됨(전선 등): 벌칙 없이 포기할 수 있다.
- 이름 없는 다섯 날: 게시판을 새로 걸지 않는다.

**7. 연결**: 시장, 전투, 던전, 이동, 제작, 보조 나무, 스토리 단계, 피로, 퀘스트 창, 도감.

**8. 표시**: 확정. 게시판 크기, 동시 5개, 보상 공식은 숫자만 임시. **게시판의 의뢰는 각자 따로 받는다(한 사람이 받아도 다른 사람 게시판에서 사라지지 않음).**

## 레이드와 기여도

**1. 목적**: 여럿이 함께 넘는 큰 싸움과, 지원 역할까지 공정하게 매기는 기여도.

**2. 저장하는 값**

| 어디 | 값 | 비고 |
| --- | --- | --- |
| 세계 | 메인 레이드 | 보스 ID, 열림 / 닫힘, 성공 시각, 성공 파티 |
| 세계 | 반복 레이드 | 이번 주 보스, 다음 교대 시각 |
| 세계 | 도전 기록 | 사람마다 한 판의 최고 기여 점수와 그 판의 세부(피해, 흐트러짐, 막아준 피해, 받아치기·피하기 성공) |

**3. 시작되는 때**: GM 스위치(메인 레이드 열기), 하루 계산(반복 레이드 교대), 파티가 도전할 때.

**4. 규칙**

*도전*

- 파티 단위. 여러 파티가 **동시에** 도전할 수 있다.
- 전투 자체는 「전투」 규칙 그대로. 판이 끝나면 사람마다 그 판의 기여 점수를 계산해, 그 사람의 최고 기록보다 높을 때만 바꿔 쓴다(**더하지 않음**).

*도전 횟수*

- 메인 레이드는 **캐릭터마다 5번**까지 도전할 수 있다.
- 판에 들어가는 순간 **파티원 모두** 1번씩 쓴다(파티장만이 아님). 이기든 지든, 도중에 나가든 똑같이 쓴다.
- 횟수가 남은 사람만 파티에 들 수 있다.

*기간과 라디아타*

- 메인 레이드는 열린 날부터 **정해진 기간** 동안만 도전할 수 있다(현실 14일, 숫자만 임시).
- **라디아타 개입**: 판에 들어간 파티원 **전원이 5번째 도전**이고, 그 판이 패배하기 직전(마지막으로 서 있는 플레이어가 쓰러지는 순간)이면 라디아타 등장 연출이 나온다. 그 판은 패배로 끝나지만 **부상 없이** 물러나고, 기여 점수는 기록된다. 레이드는 기간 동안 계속된다.
- **기간이 끝났는데 성공 파티가 없으면 토벌 실패**: 라디아타가 그르지엔을 처치하는 장면이 모두에게 열리고, 스토리 단계는 "토벌 후(실패)"로 넘어간다. 칭호 「안개를 걷은 자」는 없고, 기여 등급 보상은 그대로 준다. 늪 등불은 주인 없이 노인의 오두막에 꺼진 채 놓인다. 안개는 걷히므로 생포한 볼프람은 그대로 돌아온다. 월보에는 라디아타의 소문이 실린다. 이 결과는 세계 표시로 남는다: 플레이어가 토벌하면 새 마녀가 정상으로, 라디아타가 처치하면 그가 원념 일부를 흡수해 새 마녀가 약하게 태어나고 라디아타가 강해진다. 이후 장의 원탁 장면과 라디아타의 강함이 이 표시를 본다.

*기여 점수*

- 기여 점수 = 준 피해 + 흐트러짐 × a + 막아준 피해(지키기·치료·버프) × b + 받아치기·피하기 성공 × c. a, b, c는 역할 사이 균형이 맞게 정의 데이터에서 정한다.
- 등급(금 / 은 / 동 / 참가)은 점수의 절대 기준으로 나눈다(다른 사람과의 순위가 아님).

*메인 레이드 끝*

1. 기간 안에 어떤 판이 이기는 순간, 레이드 상태를 "닫힘"으로 바꾸는 쓰기를 **한 번에 하나씩**만 허락한다. 먼저 기록된 판의 파티가 성공 파티.
2. 같은 때 싸우던 다른 판은 그대로 끝까지 싸우고, 기여 점수는 기록되지만 성공 파티는 아니다.
3. 닫히는 순간 모든 도전자에게 등급 보상(보상 출처 ID = 레이드 ID + 등급), 성공 파티에 칭호 「안개를 걷은 자」.
4. **늪 등불**(꺼진 채): 성공 파티 안에서 **그 성공한 판**의 기여 점수가 가장 높은 사람. 같으면 준 피해가 많은 쪽, 그래도 같으면 판을 먼저 확정한 사람.
5. 스토리 단계를 "토벌 후"로 넘기는 건 GM 스위치가 아니라 레이드 닫힘이 자동으로 한다(월보 특집 포함).

*반복 레이드*

- 현실 7일마다 다음 보스로 교대. 그 주에 처음 이기면 주간 보상, 그다음부터는 반복 레이드 분야 피로가 적용된 일반 보상.

**5. 결과**: 기여 기록, 보상, 칭호, 유일물, 스토리 단계.

**6. 경계 상황**

- 두 판이 거의 동시에 이김: 레이드 상태 쓰기는 한 번에 하나라 먼저 들어온 쪽만 성공 파티.
- 이긴 판의 결과가 다시 계산했을 때 다름(「검증」): 성공 처리는 그대로 두고 GM 패널에 띄운다.
- 도전 중 레이드가 닫힘: 그 판은 끝까지 싸우고 등급 보상만.
- 성공 파티의 1위가 이미 다른 장신구 유일물을 들고 있음: 등불은 가방에 들어오고, 장착만 "장비 하나" 제한을 따른다.

**7. 연결**: 전투, 퀘스트·세계 한 번 사건, 주고받기, 유일물, 월보, GM 스위치.

**8. 표시**: 확정. a·b·c, 등급 기준, 교대 7일은 숫자만 임시. **레이드 기간 14일, 도전 5번은 숫자만 임시.**

## 유일물

**1. 목적**: 하찮은 물건을 오래 쓴 한 사람에게만 정체가 드러나는, 서버에 하나뿐인 물건과 기술.

**2. 저장하는 값**

| 어디 | 값 | 비고 |
| --- | --- | --- |
| 정의 | 유일물 | ID, 하찮은 물건(또는 기술) ID, 조건 종류와 목표 수, 반응 지점, 효과, 숨은 장면, 장비/기술 |
| 세계 | 등록부 | 유일물 ID → 상태(아직 없음 / 주인 있음), 주인, 얻은 때, 주인의 마지막 접속 |
| 캐릭터 | 조건 진행 | 유일물 ID마다 카운터, 본 반응 |
| 낱개 물건 | 평범해짐 표시 | 누군가 정체를 밝힌 뒤의 하찮은 물건 |

**3. 시작되는 때**: 조건에 해당하는 일이 생길 때(받아치기 성공, 생포 등), 장착할 때.

**4. 규칙**

1. 조건은 **하찮은 물건을 장착한 채**(기술이면 그 기술을 장착해서, 무기면 그 무기로) 해당하는 일을 할 때만 센다. 카운터는 물건이 아니라 **캐릭터**에 쌓인다.
2. 카운터가 반응 지점(보통 3분의 1, 3분의 2)을 처음 넘을 때 작은 반응을 한 번 보여준다.
3. 목표 수에 닿으면 등록부를 **한 번에 하나씩만** 쓴다: 상태가 "아직 없음"이면 내가 주인이 되고, 하찮은 물건이 유일물로 바뀌며, 숨은 장면이 열리고, 도서관에 이름이 오른다(주인은 숨김).
4. 이미 주인이 있으면: 내 하찮은 물건은 평범해지고 카운터는 멈춘다. 다른 사람들의 하찮은 물건도 다음에 불러올 때 평범해진다.
5. 한 사람은 유일물 **장비 하나 + 기술 하나**만 장착할 수 있다(갖는 건 제한 없음).
6. 유일물은 **거래·판매·우편함으로 넘길 수 없다.**

*특별한 것*

- **불가사리의 이빨**: 조건이 카운터가 아니라 강화다. +10에서 「+10 / ??」, 숨은 한도 +20까지 단계마다 30%(씨앗). +20에 닿는 순간이 목표 도달이고, 등록부 규칙은 같다.
- **그르지엔의 등불**: 레이드 보상으로 "꺼진 늪 등불"을 받는 순간 등록부에 주인이 정해진다(다른 사본이 없음). 조건(체력 10% 아래에서 살아남기 50번)을 채우면 불이 켜지며 효과가 드러난다.
- **강습 기동 + 강화 갑주 조각**: 둘은 서로 다른 유일물. 둘 다 장착하면 세트 효과지만 장비 하나·기술 하나 제한을 둘 다 쓴다.

*풀림*

- 주인이 **죽거나**, 현실 **30일 동안 접속하지 않으면** 유일물이 풀린다. 등록부는 "아직 없음"으로 돌아가고, 도서관 이름은 남는다("한때 누군가 지녔다").
- 주인의 유일물은 다시 하찮은 물건으로 돌아간다. 불가사리의 이빨은 녹이 슬어 +0으로, 유일 기술은 하찮은 기술로.
- 평범해졌던 다른 사람들의 하찮은 물건이 다시 살아나고, 그 사람들의 카운터가 이어서 센다.
- 그르지엔의 등불처럼 사본이 없는 것은 정해진 자리(뮈르가스트 노인의 오두막)에 꺼진 채 놓이고, 처음 줍는 사람이 조건에 도전한다.
- 풀리기 3일 전에 주인에게 알림(30일 미접속일 때).

**5. 결과**: 등록부, 물건, 숨은 장면, 도서관 목록이 바뀐다.

**6. 경계 상황**

- 두 사람이 같은 순간 목표에 닿음: 등록부 쓰기가 하나씩이라 먼저 들어온 쪽이 주인.
- 하찮은 물건을 팔거나 넘김: 카운터는 내게 남는다. 새 하찮은 물건을 다시 차면 이어서 센다.
- 조건 일이 전투 판정 오류로 잘못 셌을 수 있음: 하루 계산의 검증에서 다르게 나오면 GM 패널에 띄운다.

**7. 연결**: 전투, 강화, 레이드, 장면, 도서관, 주고받기(넘김 금지), 캐릭터 생성(죽음).

**8. 표시**: 확정. **풀림 규칙 확정, 30일은 숫자만 임시.**

## 유물 적성과 동화도

**1. 목적**: 시험을 버텨 얻는 유물의 힘과, 그 대가로 서서히 사람에서 멀어지는 길.

**2. 저장하는 값** (캐릭터)

| 값 | 범위 · 비고 |
| --- | --- |
| 신체 적성, 마력 친화 | 있음 / 없음 |
| 맞는 유물 형태 | 형태 ID(검·도끼·망치·곡괭이 등 50종 이상 중 하나), 첫 시험 성공 때 정해짐 |
| 적응도 | 0\~100 |
| 완전한 적성 | 있음 / 없음 |
| 동화도 | 0\~100, 완전한 적성을 얻을 때 0에서 시작 |
| 경계 결과 | 없음 / 내려놓음 / 넘어감 |
| 마지막 시험 시각 | 같은 유물 재시험 간격용 |

**3. 시작되는 때**: 유물을 처음 만질 때(던전·사건), 유물 기술을 쓸 때, 하루 계산.

**4. 규칙**

*시험*

1. 유물을 처음 만지면 시험. 무기형·슈트형 유물은 **신체 적성**, 그 밖(분석·공업)은 **마력 친화**를 시험한다.
2. 판정 = 건강·정신력과 유물 등급의 비교(씨앗). 실패: 부상 또는 폭주(건강·정신력 손실), 같은 유물은 현실 하루 뒤에 다시 시험할 수 있다. 성공: 그 축을 얻는다.
3. 첫 성공 때 맞는 유물 형태가 정해진다. 맞는 형태의 유물을 쓰면 더 강하다(다른 형태도 쓸 수는 있음).

*적응도*

- 유물 기술을 쓸 때마다 오른다. 25 / 50 / 75 / 100 단계마다 유물 효과가 커진다.
- 축이 하나도 없으면 유물 기술을 쓸 수 없다.

*완전한 적성과 동화도*

1. 두 축을 모두 얻고 적응도 100이면 **완전한 적성**(얻은 재능). 동화도 0에서 시작.
2. 유물 기술을 쓸 때마다 동화도 +. 인물 목록에 친밀도 70 이상인 사람이 있으면 절반만 오른다.
3. 하루 계산 때, 그달 유물 기술을 한 번도 안 썼으면 동화도 −.
4. 30 이상: 정신력 최대치 −10, 하루 계산마다 친밀도 1씩 저절로 감소. 60 이상: 정신력 최대치 −20, 일부 사람 사이 선택지(구혼, 위로하기 등)가 닫힘, NPC 대사가 낯설어짐.
5. 90에 닿으면 **경계 사건** 장면이 열리고, 끝낼 때까지 동화도는 90에서 더 오르지 않는다.
   - **내려놓기**: 완전한 적성을 잃고 적응도 75로, 동화도 0.
   - **넘어가기**: 고유 칭호와 아주 강한 유물 효과. 정신력 최대치 감소와 닫힌 선택지가 영구히 남고, 동화도는 90에 고정.

**5. 결과**: 적성·적응도·동화도·정신력 최대치·선택지가 바뀐다.

**6. 경계 상황**

- 정신력 최대치가 줄어 현재 값이 최대를 넘음: 최대에 맞춰 내린다.
- 경계 사건 장면을 닫고 나감: 결과는 장면 끝에 적용되므로 아무것도 바뀌지 않고, 다음에 다시 열린다.
- 내려놓은 뒤 다시 완전한 적성: 다시 얻을 수 있고, 동화도는 0부터.
- 제국 안에서 유물을 지니고 검문을 지남: 유물은 금지품이라 밀수 판정(「시장·무역」).

**7. 연결**: 전투(유물 기술), 던전(유물 조각), 재능, 인물 친밀도, 장면, 밀수.

**8. 표시**: 확정. 오르내리는 양, 시험 기준은 숫자만 임시.

| --- | --- |
| 적 도감 | 적 ID → 만남 여부, 이긴 수 |
| 물건·물고기·약초 도감 | ID → 처음 얻은 때 |
| 지역 소문 | 소문 ID 목록 |
| 칭호 | 칭호 ID 목록, 걸고 다니는 칭호 하나 |

**3. 시작되는 때**: 적을 만나거나 이길 때, 물건을 처음 얻을 때, 소문을 들을 때, 칭호 조건을 채울 때.

**4. 규칙**

- **적 도감 단계**: 만남 → 처음 봄(이름·모습만, 의도엔 기술 이름만, 위력·저항 "???"), 1번 이김 → 위력·저항, 5번 → 행동 성향·약점·드롭, 15번 → 서식지와 설명문 + 완성 보상.
- 사냥꾼 직업, 학식·예민한 감각 재능이 있으면 각 단계가 한 단계 빨리 열린다(2번째 단계를 1번 이김에 등).
- 생포도 이긴 수로 센다. 자동 전투로 이긴 것도 센다.
- **물건 도감**: 처음 얻는 순간 등록. 묶음·낱개 상관없이.
- **칭호**: 정의 데이터의 조건(도감 완성 수, 지역 지도 3단계, 레이드 성공 등)을 채우면 얻는다. 걸고 다니는 칭호는 구역 대화의 이름표 옆에 보인다.
- 첫 발견·완성 보상은 피로의 영향을 받지 않는다.

**5. 결과**: 도감과 칭호가 채워지고, 전투 화면의 "???"가 드러난다.

**6. 경계 상황**

- 파티 전투에서 이김: 참가한 플레이어 모두에게 센다(동료 제외).
- 정의 데이터에 새 적이 추가됨: 도감에 "???" 칸이 생긴다. 완성 보상 기준은 그때의 목록.
- 같은 칭호 조건을 이미 채운 상태에서 칭호가 새로 생김: 다음 하루 계산 때 소급해서 준다.

**7. 연결**: 전투, 주고받기(첫 획득), 지도, 레이드, 재능(빠른 공개), 구역 대화.

**8. 표시**: 확정. 단계 기준 1/5/15는 숫자만 임시.

## 하루 계산 (GitHub Actions)

**1. 목적**: 매일 자정, 세계가 한 달 흐르는 모든 계산을 정해진 순서로 한 번씩.

**2. 저장하는 값** (세계)

| 값 | 비고 |
| --- | --- |
| 마지막으로 처리한 날짜 키 | 「세계 시계」와 같은 값 |
| 진행 단계 | 오늘 계산이 어느 단계까지 끝났는지 |
| 실행 기록 | 날짜, 걸린 시간, 성공 / 실패, 이상치 수 |

**3. 시작되는 때**: 매일 UTC 15:00(한국 시간 자정)의 예약 실행. 실패하면 GM이 손으로 다시 돌릴 수 있다.

**4. 규칙**

*원칙: 시각으로 정해지는 일은 불러올 때 계산한다*

이동 남은 시간, 동료 회복, 거래 10분, 레이드 잠금 1시간, 자동 귀환처럼 **시각만 보면 되는 일**은 하루 계산에 넣지 않고, 그 데이터를 불러오는 순간 시각을 보고 처리한다. 하루 계산은 **하루 단위의 일**만 한다. 그래야 하루 계산이 늦어도 그런 일들이 밀리지 않는다.

*순서*

1. 계산 중 표시를 켜고 시장 매매를 멈춘다.
2. **백업**: 전체 데이터를 공개되지 않는 곳에 저장(공개 저장소에 올리지 않는다).
3. 마지막 날짜 키부터 오늘까지 빠진 날마다 차례로:
   1. 달력 +1, 필요하면 한 해 정리
   2. 모든 캐릭터의 달 넘어감
   3. 생활비·월세·재산세·여관비
   4. 가만히 있는 물건의 신선도 하루치, 정원 성장
   5. 동화도 감소, 용병 계약 끝 확인, 친밀도 자동 감소(동화도 30 이상)
   6. 시장 갱신(「시장·무역」 순서), NPC 상단
   7. 반복 레이드 교대(7일마다)
   8. 월보 자동 기사
   9. 새로 생긴 칭호 소급
4. **검증**: 그날 장부와 입력 기록을 같은 계산 코드로 다시 돌려 비교. 다르거나 비정상적으로 늘어난 값을 GM 패널에.
5. **정리**: 7일 지난 구역 대화, 끝난 임시 데이터, 기한 지난 우편.
6. 날짜 키를 오늘로, 계산 중 표시를 끈다.

**5. 결과**: 세계가 하루(한 달) 흐른다.

**6. 경계 상황**

- **도중에 실패**: 단계마다 진행 단계를 기록한다. 다음 실행은 끝난 단계를 건너뛰고 이어서 한다. 모든 단계는 **두 번 돌아도 결과가 같게**(같은 날짜 키에 한 번만 적용) 만든다.
- 실패하면 GM 패널에 "하루 계산 실패"와 이유를 띄운다.
- 며칠 밀림: 3번의 반복으로 하루씩 차례로 메운다.
- Firebase 접근 키는 GitHub의 비밀 값(Secrets)에만 두고 코드에 쓰지 않는다.
- 예약 실행은 몇 분 늦게 시작될 수 있다. 그동안 화면은 이전 달로 보여도 되고, 계산 중 표시가 켜지면 달 행동만 막힌다.

**7. 연결**: 세계 시계, 주고받기(검증), 시장, 거처, 신선도, 동료, 동화도, 레이드, 월보, 칭호, GM 패널.

**8. 표시**: 확정.

## GM 패널

**1. 목적**: 세계가 자동으로 돌아가는 동안, GM이 이야기를 움직이고 문제를 바로잡는 곳.

**2. 저장하는 값**

| 값 | 비고 |
| --- | --- |
| GM 권한 | 계정 목록. 보안 규칙이 이 목록으로 정의·세계 쓰기를 허락 |
| GM 행동 기록 | GM이 바꾼 모든 것 한 줄씩(누가, 언제, 무엇을, 전 값, 새 값) |
| 알림함 | 하루 계산 실패, 이상치, 검증 불일치, 신고, 승인 대기 |

**3. 시작되는 때**: GM이 패널을 열 때.

**4. 규칙**

| 메뉴 | 하는 일 |
| --- | --- |
| 스토리 | 장 단계 스위치. 올리기 전에 "이 단계에서 바뀌는 것"(의뢰·대사·월보·레이드)을 미리 보여주고 확인 |
| 세계 사건 | 시장 배율, 길 막기, 지역 생산 변화를 기간과 함께 투입. 끝나는 날 자동 해제 |
| 시장 | 가격 고정·해제, 하루 전 시장으로 되돌리기 |
| 정의 데이터 편집기 | 기술·나무, 적, 아이템·레시피, 효과, 재능, 퀘스트, 장면 대본, 동료, 던전, 유일물. 저장 전에 검사(스키마, 기준표 계산, 빠진 연결)를 통과해야 하고, 저장하면 버전이 오른다 |
| 미리보기 | 장면 대본, 적 조합 전투(시험 전투), 던전 층 생성(씨앗 지정) |
| 승인 | 캐릭터 생성·최종 승인, 내 사람의 전투 능력 |
| 알림함 | 위의 알림. 이상치는 장부 해당 줄로 바로 이동 |
| 장부 검색 | 캐릭터·기간·물건으로 찾기 |
| 대화 | 구역 대화 기록, 신고 처리, 말 막기 |
| 월보 | 자동 기사 고치기, 손으로 쓴 기사 더하기 |
| 되돌리기 | 백업에서 **한 캐릭터만** 특정 날로 되돌리기 |
| 공지 | 전체 알림 |

**5. 결과**: 스토리·세계·정의 데이터·캐릭터가 GM 손으로 바뀌고, 모든 변경이 GM 행동 기록에 남는다.

**6. 경계 상황**

- 정의 데이터를 바꿨는데 진행 중인 전투·탐험이 그 데이터를 쓰고 있음: 진행 중인 것은 **시작할 때의 버전**으로 끝까지 가고, 다음부터 새 버전.
- 스토리 스위치를 잘못 올림: 바로 이전 단계로 한 번 되돌릴 수 있다(그 사이 생긴 의뢰 진행은 남음).
- 되돌리기, 가격 되돌리기, 스토리 되돌리기는 두 번 확인한다.
- GM 계정도 자기 캐릭터로 플레이할 때는 일반 플레이어와 같은 규칙을 따른다(패널 밖에서는 특권 없음).

**7. 연결**: 모든 시스템.

**8. 표시**: 확정.

## 데이터 이전

**1. 목적**: 옛 사이트의 캐릭터를 새 시스템으로 한 번에, 빠짐없이, 한 번만 옮긴다.

**2. 저장하는 값**

| 값 | 비고 |
| --- | --- |
| 옛 데이터 | Firebase 내보내기(2026년 11월), 구글 시트 재능. 읽기 전용 보관 |
| 이전 기록 | 캐릭터마다 이전 여부, 옮기지 못한 것 목록 |

**3. 시작되는 때**: 새 사이트를 열기 전, GM이 한 번 실행.

**4. 규칙**

1. 옛 `store`의 키를 캐릭터 이름별로 묶는다(기본, 인물, 지갑·가방, 기술 배치, 서사, 성장기 등).
2. 변환(기획서 「기존 데이터 이전」의 표를 그대로):
   - 숙련도: 환산(옛 0\~30 → 0\~25, 30\~60 → 25\~45, 60\~80 → 45\~60, 80\~100 → 60\~75, 60 벽 통과 인정). 점수는 새 규칙으로 계산.
   - 기술 → 무기·보조·전용 나무로(레이피어+펜싱 → 세검, 스틸레토 → 단검, 해적식 검투술 → 곡도, 그라비다드 칼다레 → 칼다레 가문 무기 나무와 일루시오네스, 곡예 → 잔향(정동 팔머) 등).
   - 재능: 청한 재능은 시트, 타고난 재능은 사이트 GM 데이터 우선(볼카누스 검의 재능 공개). 진화는 얻은 재능으로.
   - 정해둔 예외: 토마소 친밀도 70, 볼카누스 가주 계승 없음, 제르노바엘은 사제 수련자 데이터로, 타고난 재능은 시트의 꿰뚫는 눈(드묾, 비공개).
   - 지갑 → 잎전 정수, 가방 → 새 물건 ID, 인물·친밀도·서술·성장기 기록 → 그대로, 스탠딩 그림 → 별도 저장소.
   - 가본 지역 → 지도 3단계. 모든 캐릭터를 세계 달력의 현재 달에 맞춘다.
3. **지난 삶 요약**: 전투·스토리·월간 기록에서 일생 요약을 만들어, 첫 장면의 책으로.
4. **검사**: 만든 캐릭터가 모두 스키마를 통과해야 한다. 짝이 없는 기술·물건은 버리지 않고 "옮기지 못한 것" 목록으로 GM에게.
5. **시험용 환경에 먼저** 옮기고, 플레이어마다 "내 캐릭터 확인" 화면으로 보여줘 이상을 받는다. 고친 뒤 실제 환경으로.
6. 옮기지 못한 것으로 생긴 손해는 창립 특전으로 메운다.

**5. 결과**: 새 사이트에 캐릭터 8명, 옛 데이터는 읽기 전용 보관.

**6. 경계 상황**

- 다시 실행: 이미 옮긴 캐릭터는 건너뛴다(덮어쓰지 않음). 다시 옮기려면 GM이 그 캐릭터의 이전 기록을 지운 뒤.
- 시트와 사이트가 다른 값: 위의 우선순위대로, 다른 점은 이전 기록에 남김.
- 옛 데이터의 이상한 값(음수, 빈 이름): 이전 기록에 남기고 기본값으로.

**7. 연결**: 캐릭터, 숙련도·나무·재능, 동료(토마소), 지도, 장면(지난 삶 요약), GM 패널.

**8. 표시**: 확정.

## UI와 모바일

화면의 기준은 [UI 시안](https://claude.ai/artifact/G1wH8fDiZFq8fKXUhvpjHH)(PC, 1280×720)이다. 모바일 시안은 따로 만들지 않고, 아래 규칙으로 PC 화면을 바꾼다.

**공통 결**: 밤의 도서관 바탕, 찢어진 원고지 종이, 무채색 선, 강조는 촛불 금빛 하나. 전투·던전은 목판화 빗금과 장마다 포인트 색 하나. 제목·대사는 명조, 숫자·메뉴는 고딕. 스탠딩은 허벅지까지의 반신.

**모바일로 바꾸는 규칙** (화면 너비 768px 아래)

1. **종이를 세로로 쌓는다.** PC에서 나란히 놓인 종이(목록 · 내용 · 옆 정보)는 위에서 아래로 한 줄씩. 목록이 있는 화면은 목록을 먼저 보여주고, 하나를 누르면 내용 화면으로 넘어간다(뒤로 가기로 목록).
2. **상단 띠는 두 줄로 접는다.** 윗줄에 돌아가기와 장소 이름, 아랫줄에 숫자 칸(행동·피로·지갑 등)을 가로로 밀 수 있게. 아이콘 메뉴(메뉴·알림·편지·퀘스트·월보)는 화면 아래 고정 띠로 옮긴다.
3. **주요 버튼은 화면 아래에 고정**한다(이어하기, 출발, 받기, 팔기, 찍기 등). 엄지가 닿는 자리.
4. **누르는 것은 44px 이상.** 글씨는 PC보다 한 단계 작게 하되 대사는 그대로.
5. **장면·구역 화면**: 스탠딩은 하나만 크게(말하는 사람), 나머지는 대사창 위의 작은 얼굴로. 대사창은 화면 아래 40%. 선택지는 대사창 위에 세로로.
6. **전투**: 위에 적 6칸, 가운데 판정 바, 아래에 아군 6칸, 맨 아래 기술 패널(가로로 밀기). 적의 의도는 적 칸 아래 꼬리표로 붙이고, 화살표 대신 대상 이름을 쓴다.
7. **던전**: 방 화면을 위에, 작은 지도는 오른쪽 위 접힌 버튼(누르면 펼침), 가방은 아래 띠.
8. **기술 나무·지도**: 손가락으로 끌고 두 손가락으로 확대한다. 칸이나 장소를 누르면 설명 종이가 아래에서 올라온다.
9. **표**(시세표, 숙련도 등)는 첫 칸을 고정하고 가로로 밀 수 있게.
10. **미니게임**(판정 바, 막기, 피하기, 낚시, 수레, 항해, 공연)은 화면 아무 데나 누르는 방식으로 두고, 키보드 표시는 숨긴다.
