# 용어 ↔ 코드 이름

명세서 「용어집」의 낱말 하나에 코드 이름 하나. 코드(변수·함수·칸 이름)는 이 표의 영어 이름만 쓰고,
정의 데이터의 **값**은 한국어 낱말을 그대로 쓴다(예: `"damageType": "자상"`).
새 낱말을 코드에 쓰게 되면 먼저 이 표에 한 줄을 더한다.

| 낱말 | 코드 이름 | 비고 |
| --- | --- | --- |
| 정의 데이터 | defs | |
| 기술 기준표 | skillTable | |
| 단계 | tier | 기본 공격 / 1단계 / 2단계 / 3단계 / 궁극기 |
| 위력 | power | 판정 배율까지 곱한 한 타의 힘 |
| 위력 성격 | potency | 약함 / 보통 / 강함 |
| 타 | hit | 타수 = hits |
| 범위 | range | 단일 / 휩쓸기 / 전체 |
| 효과 | effect | 무게(weight): 가벼운 / 무거운 |
| 효과 예산 | effectBudget | |
| 개성 보정 | personality | 위력에 곱하는 배율 |
| 쿨다운 | cooldown | 턴 수 |
| 기력 | energy | 전투 안의 자원만 |
| 판정 | judgement | 빗나감 / 보통 / 좋음 / 완벽 |
| 연계 역할 | role | 여는 / 잇는 / 끝내는 |
| 피해 타입 | damageType | 자상 / 관통 / 파열 |
| 자세 | stance | 타수 자리에 쓰는 값 `"자세"` |
| 숙련도 | mastery | |
| 나무 | tree | |
| 줄기 | stem | |
| 뿌리 | root | 칸 = slot |
| 칸 | node | 나무의 칸. 종류(kind): 기본기 / 보완 / 갈림길 / 끝갈래 / 궁극기 |
| 기본 공격 | basicAttack | 변형 = variant |
| 갈림길 축 | axis | |
| 숨은 칸 | hidden | |
| 루트 | route | 기본기에서 궁극기까지 한 줄 |
