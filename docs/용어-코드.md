# 용어 ↔ 코드 이름

명세서 「용어집」의 낱말 하나에 코드 이름 하나. 코드(변수·함수·칸 이름)는 이 표의 영어 이름만 쓰고,
정의 데이터의 **값**은 한국어 낱말을 그대로 쓴다(예: `"damageType": "자상"`).
새 낱말을 코드에 쓰게 되면 먼저 이 표에 한 줄을 더한다.

| 낱말 | 코드 이름 | 비고 |
